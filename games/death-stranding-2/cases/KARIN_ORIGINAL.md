# 案例：Karin_Original 替换山姆

> **范围：** 一个 VRM 模型（套头衫校服、短裙、长袜，带狐耳、尾巴、双马尾）替换玩家外观 Porter，外观表的其余 6 套也指向她。两个版本：无表情（v34）、有表情（v34f）。
> **证据边界：** `DS2.exe` 1.0.48.0，id-daemon `ds2_pc_mi_022` / `Decima_pack_ds2`，Odradek 1.0.49.0 类型表。
> **状态：** `runtime-confirmed-scoped`。逐项见下表：几何、外观表、物理、装备靴、腐蚀修复有用户或 agent 的实机确认；表情只确认了张嘴；淋浴发型、过场替身、待机脖子未解决；发行安装器装的版本在提交时还没有实机。
