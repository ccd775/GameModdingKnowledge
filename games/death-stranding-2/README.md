# Death Stranding 2: On the Beach（死亡搁浅 2：冥滩之上，PC）

## 范围

这里整理 PC 版主角替换的可复用合同。材料来自一个项目：用 Karin_Original（VRM，套头衫校服版，带狐耳、尾巴、双马尾）替换主角山姆（Sam）。

- 改的是玩家外观 Porter（`DSPlayerBodyVariant` 组 50107 → 网格组 50108）。外观表的其余 6 套（Suit、PrivateRoom、Suit2、Naked2、Jacket、Naked）用链接表全部改指 Porter，所以不论存档里是哪套外观，玩家都是 Karin。
- 引擎是 Decima（Nixxes 移植）。和西之绝境（`games/horizon-forbidden-west/`）同一套流图与 id-daemon 工具家族，但打包、链接表、着色器变量和玩家组件都要按 DS2 重新确认。
- 发布：2026-10-31 的 v34，两个版本：
  - 无表情版（`karin_v34`）：Karin 自己的脸在身体网格里，没有表情；
  - 有表情版（`karin_v34f`）：Karin 的脸放进山姆的脸皮网格，眨眼、张嘴走游戏的 RigLogic 面部绑定。
- 发行方式：一个安装脚本在用户自己的游戏文件上打补丁，先按组核对再写，见 [验证与发布](VALIDATION_AND_RELEASE.md#发行包)。

证据边界：`DS2.exe` FileVersion **1.0.48.0**（发售版的 RUNE 破解副本，带 Steam 模拟器），快照时间 2026-10。Steam 版（App `3280350`）同期已到 Patch 1.9 / 1.10；Odradek 的 DS2 类型表说明 1.0.48 → 1.5.68 只改了 UI / 灯光 / 遥测相关的 RTTI，网格、蒙皮、流式类型没变。

- 组号、对象下标、网格 / 贴图编号、原版计数和哈希都是 1.0.48.0 的 `build-sensitive` 值；
- 缩放、权重分区、粒子选择、杠杆偏移、眨眼强度这些是 `case-derived`。

## 核心方法

- **只改 Porter 自己的组，Karin 放进现有槽位。** 用 id-daemon 的 `ds2_pc_mi_022` 按组导入 ascii 网格和 DDS 贴图，`Decima_pack_ds2` 把产物打进一个新包并改写流图。工具不加对象、不加骨，所以：
  - 头（脸、头发主体）→ 身体网格里手套材质的图元；身体和衣服 → 身体材质图元；脚和鞋 → Porter 的靴子网格；
  - 裙子和尾巴 → Porter 长外套的网格（借它的 146 个 `Cloth_PBD` 粒子摆动）；
  - 狐耳、刘海、侧发 → 山姆头发模型的 LodMesh `50121:82`（借 34 个 `Hair_PBD` 粒子）；
  - 有表情版的脸 → 山姆脸皮 LodMesh `50120:1` 的 LOD2（`50120:186`，240 个面部关节）。

  其余 Porter 网格保留原版的顶点数和索引数，所有顶点塌缩到一点。
- **工具不更新的字段由 `patch_core.py` 补**：`StreamingDataSource.Length`、SkinInfo 顶点数、图元和网格包围盒、逐骨包围盒；另外还有部件隐藏标志、逆绑定矩阵（眼睑杠杆、耳朵粒子）、投影开关、单字段补丁（头发 PBD 体）和材质变量改名（时间雨腐蚀）。
- **共享资源用链接表重指，不复制。** 流图之外的 `streaming_links.stream` 存着每个对象的指针记录。`relink.py` 在原位改写记录（等长，不够长时用零值 varint 补齐），用它来：
  - 把 6 套外观改指 Porter；
  - 把山姆的 30 个头发部件、11 个面部部件改指已塌缩或 Karin 的网格；
  - 把装备靴的 46 个部件改指装着 Karin 鞋子的鞋面；
  - 重定向靴子材质和淋浴发型变体的贴图集。
- **玩家组 31123（130 MB 核心）只换 stream。** 往装备靴、头发里写网格时，把顶点和三角形补齐到原网格的计数。这样工具重写出的核心与原版逐字节相同，可以不进包。同一规则也用来塌缩场景替身的头发（组 12706、6744）。
- **物理全靠借粒子**：裙子跟外套的 `Cloth_PBD`，双马尾跟背包带的 `Belt_PBD`，耳朵、刘海、侧发跟头发的 `Hair_PBD`。耳朵靠缩放粒子的逆绑定矩阵，只取粒子的平移，避开发带末端的转动杠杆。见 [物理](PHYSICS.md)。
- **表情靠游戏的 RigLogic。** 先把面部绑定矩阵解出来，按 Karin 自己的形态键拟合每顶点的关节权重；眼睑用“绑定偏移杠杆”把小角度放大成闭眼。见 [表情](FACE.md)。

## 证据纪律

沿用本库的五级证据（`reference-inferred` → `runtime-confirmed`）。本作的教训：

1. **“发灰”连续五次猜错，换成对照才找到原因。** 长存档里 Karin 的身体、衣服、双马尾一片灰绿，耳朵、刘海、鞋却干净。改涂装 UV（三种取法）、清 Mask_Alpha、关涂装组件、换细节贴图都没用，有的还更糟。最后两步定位：原版同一存档同一位置，山姆也一样脏；再对比材质变量，只有变灰的材质带 `CorrosionRate`（时间雨腐蚀）。改名这个变量的绑定后用户确认「完全都不灰了」。见 [材质与磨损](MATERIALS_AND_WEAR.md)。
2. **“没有物理”可能是状态，不是版本。** v31 截图里耳朵不动，v27 动；两版头发槽逐字节相同。回到 v27 动的那个场景（长存档室内），v32 的物理也回来了。
3. **一个症状可能有几个来源，要逐个排除。** 淋浴时出现山姆的湿发：玩家组的 4 套头发、剧情替身 12706、私人房间场景 6744 都塌缩了，头发还在；用户最后决定不追。见 [排障手册](TROUBLESHOOTING.md#淋浴时的山姆湿发未解决)。
4. **校验已装的 mod 要读包，不要读游戏目录。** 本项目的 `Graph(<游戏目录>)` 会自动改读干净根目录里的原版流图，用来校验安装就等于校验原版。要传 `graph_path` 和 `overrides={0x80: 包}`（`verify_pack.py` 的做法）。
5. **用户的描述要和原始素材对上。** 淋浴截图顶上的白色褶皱，一开始被当成头饰；渲染 Karin 的头部后才确认那是她的银白头发，黑色湿发才是山姆的。
