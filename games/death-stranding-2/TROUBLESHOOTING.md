## 淋浴时的山姆湿发（未解决）

私人房间淋浴时，Karin 的衣服还在，耳朵、刘海消失，头上出现山姆的黑色湿发（长发丝、脸边绒毛）。用户 2026-10-31 决定不再追。已排除：

| 版本 | 假设 | 结果 |
| --- | --- | --- |
| v28（links v11） | 淋浴发型变体 HairApv（31123:199 → `ReplaceTextureSet 31123:32822`）把头发部件换成山姆的另一张图集 31301 → 改指 67704 | 仍有 |
| v32 | 玩家组 31123 的 4 套头发（`ArtPartsModelResource 31123:38907`，部件 3800 / 4000 / 15014 / 13272）→ 塌缩 16 个网格 | 仍有（逐字节确认两个图元都改了） |
| v33 | 剧情替身 12706（`SpawnSetup 12706:4` 带 `DSPlayerTakeOverStateComponentResource`，模型只有 16 个头发部件，骨架 12715；被约 21 个场景组引用）→ 塌缩 48 个网格 | 仍有 |
| v34 | 私人房间场景 6744（玩家演员 + 用 Porter 数据生成的替身 + 头发演员 6744:433，`DSCoverToOtherEntityEventResource` 在帧 240–2038 把替身的覆盖模型复制到背包演员和头发演员）→ 塌缩 23 个网格 | 仍有 |

其它排除：HairApv 只换贴图集和 3 个发色变量，不换网格；外骨骼覆盖模型 50111:7 没有头发；场景 44 / 4270 / 7830 / 12705 藏的是 50121:0，它们生成的是 12706、Lou 的兜帽 12710、搬运工衣服 12712；43739 是碰撞触发；PrivateRoom 身体 40437 用的是山姆自己的网格（若是它，用户会看到山姆的身体）；组 700 的头发演员接收的是山姆 NPC（58941）的覆盖模型，不是玩家的。

没查完的方向：

- 按字符串找淋浴场景（`scan_strings.py` 扫全部核心包，开始了但被叫停）；
- 用 67704 / 67705 贴图的大组 3、500、772、2778 里的头发模型；
- 头发不一定来自网格（可能是另一类头发渲染组件）。

确认方法：渲染 Karin 的头部（她的头发是银白色带黑丝带），和截图对照，先排除“其实是她自己的头发”。
