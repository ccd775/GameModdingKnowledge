# 材质与磨损

## 1. 材质通道（Porter 材质）

| 槽 | 内容 | 注意 |
| --- | --- | --- |
| 颜色（身体 `0x10`、手套 `0x180`、靴子 `0x8`） | RGB 颜色，A = Mask_Alpha | Mask_Alpha **不是**污渍开关，参与底色：v24 置 0 后 Karin 的鞋变黑，灰层照旧。保持 255 |
| 法线 | RG 法线，B = “粗糙度”，A = 反射率 | **B 实际是光滑度**（值越大越亮）：原版 Porter 布料中位数 82、山姆脸 156；Karin 布料 170 时裙子 / 袜子高光集中，改 60 后哑光（v6 实机） |
| 外套材质（套 50110:9，键 `47CD`） | E8 颜色 BC1 2048；D 法线 RG + 光滑度 B（原版中位数 67）+ 反射 A（约 50）BC7 2048；E 细节遮罩 RGB + 曲率 A（约 125）BC7 1024；13 AO R + mask alpha G（都约 255）BC1 2048；54 杂项 BC1 2048；5C alpha BC4 512；FA 亮度 16×16（原版 159，不改） | |
| 贴花 | 外套贴花套 50110:11 的 12（BC1 1024）B 通道是不透明度；身体的贴花遮罩 50110:220 | 置 0，否则山姆外套的标志会印在 Karin 身上 |

装备靴鞋面材质原来绑贴图集 67690（键 `AC0`）。67690 在 31123 里只被靴子用，但过场的山姆组（500、34853、67632、4167、39984）也用它，所以改为绑定变体集 31225:22（键 `A15`，只被 31123 和 4167 用），Karin 的鞋页放进那里。

## 2. UV 组

身体、外套、靴子的材质有 3 套 UV（Half），只有 UV0 是贴图坐标：

- **UV1**：贴花 / 细节层的坐标。原版大多数顶点约 (0.93, 0.17)，少数在 −15…10。
  - v12–v14 把 Karin 的页面 UV 复制进去，贴花纹理（按扣、铆钉的圆点）就铺满了白色尾巴，阴影里最明显（用户报告“一排黑色圆点”）；
  - v15 取山姆最近顶点的 UV1，又印上了山姆外套背后的标志笔画；
  - v16 写原版中位数常量，干净（agent 实机）。
- **UV2**（脸是 UV1）：角色涂装图集，见下一节。

## 3. 涂装（泥、血、雨湿）

- 组件：31123:131 `DSPlayerMeshPaintComponentResource`。污渍类型有沙尘、泥（按地面）、河水、焦油、雪、冰柱、火烧、血（刀伤 / 枪伤 / 爆炸）、雨滴、背包碰撞；淋浴、洗脸、温泉清洗。`PaintAll` 换算成 24 个关节周围 0.3 m 的球体。记录随存档保存、读档后重画。
- 每个可涂实体一个 `DynamicMeshPaintComponentResource`（20 个，3 层，16–256 px），在 UV 空间画。
- 所有角色材质都绑同一套污渍细节贴图 `cm_paint_*`（血 75954、泥 / 水 / 损伤 / 手印 75956、烟灰 / 焦油 75966、雪 / 沙 78778、烧焦 78780），多角色共用，不能改。
- 头发和脸另有允许沾污的遮罩（头发 67706:0 `sam_hair_def_v00_paint_alpha`，脸 67648:7）；身体、外套没有。
- 做法：Karin 的涂装 UV 写到图集外“离原版图块最远的角 ±2”（`paint_corner`）。涂装没在她身上留下斑块；这一项单独的实机效果和下面的腐蚀混在一起，没有分开评价。

## 4. 时间雨腐蚀（长存档里的“发灰”）

### 症状

长存档（第 17 章、46 小时）里 Karin 的身体、衣服、皮肤、双马尾、头顶一片均匀的灰绿，带纤维状颗粒凹凸；耳朵、刘海、侧发和装备靴的鞋干净；私人房间淋浴后全身的灰完全消失。

### 被证伪的方案

| 版本 | 假设 | 结果 |
| --- | --- | --- |
| v22 | 涂装 UV 压到 (0,0)，保守光栅化让全身共用一个像素 → 移到 (−4,−4) | 没变化 |
| v23 | (0,0) 离图块太近，读到渗出的脏 → 每个网格取最干净的角 | 没变化 |
| v24 | Mask_Alpha 是污渍开关 → 置 0 | 仍灰，鞋变黑 |
| v25 | 31123 的 20 个涂装组件 `UsePaintLayerCount` 3 → 0 | 仍灰，包 295 MB |
| v26 | 换思路：让耳朵刘海也一起变灰（放回头部页） | 全部变灰，但没有物理 |
| v27 | 打开头发的涂装遮罩 | 有物理但仍白 |
| v28 / v29 | 灰层是四张细节贴图（74406 细绒法线、74411 纤维法线 + 遮罩、74419 颗粒法线 + 斑点、79289 泥块法线 + 细胞）→ 在 Karin 全部材质上换成全零的 4×4 `75978:0` | v28 裙子“变干净”是误判（裙子本来就深）；v29 全身变**深色**：这四张贴图只决定灰层的样子，不决定盖不盖 |

### 定位

1. **原版对照**：还原原版，同一存档同一位置，山姆的衣服也被灰绿尘土大面积覆盖、靴子发灰 → 是游戏自带的状态，不是 mod 的错。
2. **材质变量对比**：材质 `VariableBindings` 里的 `CorrosionRate`（VariableIDHash `852864580`；`DSEquipmentShaderControlResource 31123:5046` 用的就是这个名字）出现在身体、手套、外套、Porter 靴、装备靴的材质里，头发和脸没有。这和“身体、外套、双马尾灰，耳朵、刘海从不灰”完全吻合。淋浴顺带把它清零；装备靴各自记腐蚀（新换的靴子干净）。名字的哈希算法不是 crc32、crc32c、fnv1a、murmur3_32，也不是 murmur3_x64 的低位，是靠对比找到的。

### 修法（v31，用户：「现在完全都不灰了」）

`patch_core.py` 的 `rename_vars`：在 50108、50110 的所有 render effect 里，把 `VariableIDHash 852864580` 改成 `852864581`（着色器侧的 `BindingNameHash` 不动；50108 改了 35 个 effect，50110 改了 15 个）。游戏按 ID 找不到这个变量，就不再驱动，材质保持 0。

- 装备靴在 31123（stream-only，核心不改），仍会像普通靴子一样腐蚀。
- 有表情版的脸用山姆皮肤材质，不带 `CorrosionRate`，雨天变暗是另一回事（晒伤 / 湿润层，见 [表情](FACE.md#4-阴影与天气)）。

## 5. 教训

- 先做对照（原版同一存档、清洗前后），再改数据。连续三次推断失败就该停下来做对照，而不是第四次猜。
- 着色器（DXIL）剥了名字，读不出变量的含义；比较“哪些材质有、哪些没有某个变量”，和症状的分布对上，比读着色器有效。
- 改一个全局资源（细节贴图）只会改“样子”；“盖不盖”由运行时状态加材质变量决定。
