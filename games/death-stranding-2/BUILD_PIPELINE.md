# 构建流程

命令和参数见 [便携包](../../portable-kits/death-stranding-2/README.md)。数值是 Karin_Original 的 `case-derived` 值，组号和网格号是 1.0.48.0 的 `build-sensitive` 值。

## 1. 准备（每个游戏版本一次）

1. `setup_cleanroot.ps1` 建干净根目录。
2. `export_group.ps1` 导出要用的组（每个 LOD 一个子目录，并把工具写出的核心存成 `<名>.core.pristine`）：Porter 50108（`7e9d`，LOD0–2）、外套 50110、头发 50121（LOD0–3）、脸 50120（LOD2–4，有表情版）、玩家组 31123（装备靴）、场景替身 12706 / 6744；Porter 的其余组 50109 / 50113 / 50116 只需要 pristine 核心和塌缩用的导出。
3. 骨架 ascii：工具导出某个组时会写出它用到的 `KEY_skel_<序号>.ascii`，统一放进 `work\skeletons`。31123 的 LOD3 导出里，18 个 PBD 关节的绑定姿势和 LOD0–2 不同，单独存成 `B6B_skel_474_lod3.ascii`。
4. `prep_ref.py` 汇总参考数据到 `ref.json`：身体骨架 50118 的名字、父子关系和绑定世界矩阵（由每个 Porter 网格的逆绑定矩阵求，骨架资源里没有绑定姿势），每个槽网格的关节表，以及每个网格的哪个图元用哪种材质（按颜色贴图判断）。外套、头发、脸的关节表也在里面。
5. `hair_used.py` 把头发骨架（`1A0C`）上所有头发网格（50121 / 67700 / 50120 全 LOD）的 UV0 栅格化成 512 掩码，膨胀 2 格：图集里山姆的头发卡片用到 72%，剩下的空格放 Karin 的耳朵和刘海。
6. 有表情版另外跑 `face_motion.py`（RigLogic 解码，见 [表情](FACE.md)）。

## 2. `build_ds2.py`：从 VRM 到 ascii

### 槽位

| 槽 | Karin 的部分 | 目标 | 贴图 |
| --- | --- | --- | --- |
| head | 脸（无表情版）、头发主体、双马尾 | 身体网格 144 / 73 / 392 的手套材质图元 | 页 A → 手套颜色 `0x180` |
| body | 其余身体和衣服 | 身体网格的身体材质图元 | 页 B → `0x10` |
| R / L | 脚和鞋 | Porter 靴子 218 / 364 / 90、453 / 614 / 194；另写进装备靴鞋面（`--boot-ref`） | 页 B → 靴子 `0x8`；装备靴走 31225:22 |
| coat | 裙子、尾巴 | 外套 50110:234 / 124 / 73 的 prim 0 | 页 C → 外套材质 `E8` 等 |
| hair | 狐耳（整个 `kemomimi`）、刘海、侧发（`Hair_front*`、`Hair_side_L/R` 骨链触到的三角形） | 头发 LodMesh 50121:82（LOD0–3 = 85 / 38 / 27 / 56）的 prim 0 | 放进头发图集 67704 的空格 |
| face（`--face`） | `Body / Karin_Face` 图元 | 山姆脸皮 50120:186 / 229 / 45（LOD2–4） | 页 F → 脸部贴图组 67673 |

每个槽三级 LOD 写同一份网格（不减面）。其余 Porter 网格（50108 / 50109 / 50110 / 50113 / 50116 的 LOD0–2）和 50121 的其它网格全部塌缩。

### 拟合与权重

- TPS 拟合到身体骨架 50118：整体 1.3 倍，头部刚性，手部逐骨刚性，肩部向 Sam 的上臂移 30%、下沉 2 cm（`--shoulder-fit 0.3 --arm-drop 2`）。
- 遮挡剔除：长袜里的腿、被衣服包住的皮肤（`COVER_RULES`），距离按源模型尺度。
- 权重按身体分区从 Sam LOD0 的顶点继承；颈部按高度在两节颈骨之间分配；不在目标网格关节表里的骨转给最近的允许祖先（导入工具只能用网格自己 `JointIndexList` 里的骨）。
- 布料、背包带、头发粒子的权重见 [物理](PHYSICS.md)。
- 几何修补：裙子双面（复制反向三角形、法线取反），因为低机位从下往上会看到裙子内侧；尾巴 Phong 细分 2 级（912 → 14 592 三角形），因为低模的弧面在游戏阴影里会切出黑块。
- 三角形绕序与 glTF 相反（构建时自动判定），UV `v = 1 - v_glTF`。

### 贴图页

- 页 A（头）缩放 0.656，页 B（身体）0.82，都是 2048；页 C（外套，2048）放裙子和尾巴。
- 材质通道按游戏的含义填，不按名字（见 [材质与磨损](MATERIALS_AND_WEAR.md)）：法线包平坦，“粗糙度”通道其实是光滑度（皮肤 115、衣服 60、头发 100、鞋 90；衣服 170 时裙子和袜子高光集中），AO 255、反射率 48、细节遮罩 / 杂项 0、曲率 115、亮度 159；贴花遮罩（50110:220、外套贴花套 50110:11 的 12）置 0。
- 头发图集：把 Karin 的块首次适配进空格（缩放 0.754，25 块），颜色、alpha、平法线贴进原版 `A60` 贴图，其余贴图取原版中位数；**Karin 块以外的 alpha 全部置 0**，所有用这张图集的山姆头发卡片（玩家的、过场替身的）都变透明。
- `make_dds.py` 按原版槽位的尺寸和格式转 DDS（导入工具只替换同尺寸的 mip）。

### 额外 UV 组（`extra_uvs`）

身体、外套、靴子材质有 3 套 UV，脸有 2 套，只有 UV0 是 Karin 的页面坐标：

- 全零的组保持 0；
- 落在 [0,1] 的组是角色涂装图集（泥、血、雨湿）：写成“离原版图块最远的图集角 ±2”（`paint_corner`），三角形完全在图集外，wrap / mirror / clamp 采样都落在干净的角上；
- 其他组（贴花 / 细节层坐标）写原版的中位数常量。

## 3. 其他构建步骤

- **塌缩**：`gen_collapse.py` 对整组（可 `--only` 选网格）生成塌缩任务，`--stream-only` 标记只换 stream。`collapse()` 让每个子网格的所有顶点移到一点、全权重挂在一根骨上，保持计数。
- **装备靴**：Karin 的鞋按名字把关节号换成骨架 31123:301 的号（Porter 靴和道具靴 6 个关节的逆绑定矩阵完全相同），补齐到 ItemId 11 鞋面各级的计数，stream-only 导入。
- **场景替身头发**：31123 的 4 套头发（`SHOWER_HAIR`）、12706（48 个网格）、6744（23 个网格）全部塌缩，stream-only。

## 4. `make_mod_ds2.ps1`：导入、补丁、打包

1. 清空工具目录的产物，按 `jobs.json`（构建）加塌缩任务导入每个网格，核对 `success!` 的次数等于图元数。
2. 按 `textures.json` 导入贴图，核对替换了 mip。
3. stream-only 组：核对工具写出的核心与 pristine 逐字节相同，删掉。
4. 其余组：`patch_core.py` 按 pristine 补字段（见 [技术合同](TECHNICAL_CONTRACTS.md#6-导入工具不更新的字段)）；50108 隐藏面部模型的部件（有表情版保留 302 / 43）；50108、50110 把 `CorrosionRate` 改名；67699 写字段补丁（`fields.json`）。
5. 收集 `.core` 和 `.stream`，`pack.ps1` 调 `Decima_pack_ds2`（文件序号 0x80）出 `package.18.00.core.stream` 和流图。

`build_karin.ps1` 把整条链串起来，再把指定的链接表拷进输出目录。构建要脱离 SSH 运行（`wmic process call create`），否则 SSH 断线会杀掉构建；日志最后一行写 `BUILD-DONE <退出码>`。

## 5. 链接表（`make_links.py`）

每个版本都从原版链接表重新生成，不叠加。v13（无表情）/ v13f（有表情）的内容：

| 段 | 改动 |
| --- | --- |
| v5 | 50121 的 12 个头发部件 `MeshResource` → `50121:82`（Karin 的耳朵 / 刘海 / 侧发） |
| v6 | 外观表 6 套 → Porter 50107:0 |
| v7 | 内衬 50108:595 的 LOD3/4 → 已塌缩的 LOD2；面部模型 11 个部件（有表情版 10 个，留 43）→ 595；50120 的 18 个头发部件 → `50121:82` |
| v8f | 有表情版：脸皮 50120:1 的 LOD0/1（带 ZivaRT）→ LOD2 `50120:186` |
| v9 | 赤脚部件 50108:57 / 35 → Karin 的鞋 LodMesh 153 / 282（脱下装备靴时显示） |
| v10 | 装备靴 ItemId 11–18 的 46 个部件 → 鞋面 15523 / 8554；3 个 2 字节记录改指 LodMesh 的三级网格；鞋面 6 个材质的 67690:0 / 67690:1 → 31225:22 / 27；换色变体 20 / 93 / 94 的贴图集 → 31225:22 |
| v11+ | 淋浴发型变体 `31123:32822.TextureSet`（HairApv）→ 67704:0，让它换图集时仍是 Karin 的块 |

v11 / v12 的细节贴图实验段只在对应版本号里生效，留作记录（见 [材质与磨损](MATERIALS_AND_WEAR.md#4-被证伪的方案)）。

## 6. 输出与安装

- 开发：`install.ps1 -Name <名>` 用输出目录的三个文件替换游戏的流图、`package.18.00.core.stream` 和链接表（首次运行先备份），`-Restore` 还原。只在游戏关闭时装。
- 发行：`make_release.py` 生成 manifest，安装器在用户的游戏文件上打补丁，见 [验证与发布](VALIDATION_AND_RELEASE.md#发行包)。
