# 排障手册

| 症状 | 原因 | 处理 |
| --- | --- | --- |
| 进游戏看不到新身体，头发、耳朵、尾巴都没有 | 存档穿的不是目标服装（本项目在穿另一套服装的存档上测了四个构建） | 先确认服装；脸和头发的包对所有服装生效，可以用来判断包是否加载 |
| 完全没有物理（编辑器里明明在动） | Kawaii 按 USkeleton 建链，网格独有骨不被模拟 | 链改到游戏骨架已有的配件链上，父骨一致（[Kawaii 物理](KAWAII_PHYSICS.md) §1） |
| 以为有物理，用户说没有 | 凭停步、跳跃的单张截图下了结论 | 诊断 ×2 标记或 F12 连拍（[验证与发布](VALIDATION_AND_RELEASE.md) §3） |
| 腿太长、上身短，鞋底很厚 | Animation 平移重定向：关节位置来自 EVE 的动画 | 后处理 AnimBP 里用加性 ModifyBone 改比例（[角色替换](CHARACTER_REPLACEMENT.md) §3） |
| 裙子从里面看是空的 | 源 VRM 单面；MI 的静态开关改不了 | 网格里复制反向面并取反角法线 |
| 裙子在尾巴根高度鼓起一圈 | 原样复制的 EVE 胶囊比新身体大，静止关节每帧被推出 | 按被模拟关节拟合胶囊半径 |
| 跑动时裙子和身体之间露缝 | 腰带段被模拟，绕腰线摆动 | 髋关节以上不模拟 |
| 跑动、弓步时臀部从裙子穿出 | 胶囊只挡关节；关节之间的布倾进身体 | 髋关节以上复制皮肤权重，物理从髋关节开始 |
| 加角度限制后穿模更严重 | 角度限制在碰撞之后执行，把推出的关节拉回腿里 | 腿边的裙链不加角度限制 |
| 宽站姿、半蹲时大腿从裙片穿出 | Kawaii 径向推出，抬起的大腿可能把一片裙子压在下面；没有 BoneConstraints | 前面和侧面裙摆部分跟随大腿权重，并按身下皮肤补足（[Kawaii 物理](KAWAII_PHYSICS.md) §4） |
| 弓步时后腿从裙子后侧穿出 | 后片没有跟随 | 后伸、外展驱动的辅助骨（BoneDrivenController） |
| 包体比上一版小，进游戏没物理 | AnimBP 脚本中途报错，但打包步骤照样跑完 | 打包前检查成功标记 |
| 导出工具读到的还是原版网格 | 导出工具只读游戏本体，不加载 `~mods` | 在 UE 编辑器里或直接解析自己的容器 |
| 编辑器脚本找不到文件（`builds_x.py`） | `-script=` 吃掉反斜杠路径里的 `\u` | 路径用正斜杠 |
| 导入后材质槽错乱 | 重导入保留旧槽列表；Python 设的材质偶尔不持久 | 先删再导入，导入后再指定材质，打包后校验 |

## 已被证伪的假设

- 「r3 / r4 物理在工作」：依据是单张截图，被诊断标记推翻。物理从 r13 起才真正运行。
- 「看不到头发是材质或 ClipMask 的问题」：其实是存档穿着别的服装。为此做的材质、槽位二分都建立在错误前提上。
- 「网格独有骨在运行时会被覆盖」：诊断标记显示它们可写；问题只在 Kawaii。
- 「穿模是权重问题」（r15 之后）：刚性裙子在 Blender 里各种姿势都不穿，问题出在物理。
- 「给紧身段加角度限制能挡住穿模」（r16）：弓步时更糟。
