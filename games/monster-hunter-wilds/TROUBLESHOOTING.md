# 排障手册

## 症状 → 定位表

| 实机症状 | 最可能的成因 | 先查什么 |
| --- | --- | --- |
| 厂商 logo 后一直黑屏，游戏不崩溃 | 装备 MDF 引用的贴图拿不到 → 装备构建挂起 | REFramework 版本与日志；原版字节放回原版路径的负对照 |
| 只装 BoneSystem 能进，装 mod 就黑 | 同上；不要先怀疑 BoneSystem 或 Mesh | 「MDF 只引用原版贴图」对照组 |
| 旧 mod 在游戏更新后也黑屏 | exe 更新让旧 REFramework 的加载能力失效 | 日志里的 `sha3_rsa_code_start` / 有无 `LooseTextureLoader` |
| 贴图 PAK 装了但完全不生效 | 旧 REFramework 的未加密 PAK 绕过失效，PAK 被忽略 | 更新 REFramework，改走散装贴图 |
| 收刀时武器看不见 | 2 号部位缺 `Spine_1/2_WpConst`（背负）或 5 号缺 `Hip_WpConst` | 对部位 Mesh 做骨名扫描，对照原版 |
| 大集会所正常，进入其他任何地图都崩溃 | 占位件删掉了引擎挂点骨（投射器 `Slg_*`、武器挂点） | 同上；投射器部位保留原版 |
| 奔跑时大腿根穿出裙摆 | 大腿碰撞胶囊按平均截面拟合，比外表面小约 3 cm | 按外表面上半段重拟合，再做静止间隙封顶 |
| 布料有明显集中的高光 | NRRO 用了引擎 NullNRRO（粗糙度 0.5） | 自带常量 NRRO，布料 ≈ 0.9 |
| 游戏更新后身体全黑、只剩少量自发光 | 装备 MDF 合同变了（1.042：`Base_Equip` → `Base_Equip_NoMultiBlend`） | 对比新旧原版 MDF 的 MMTR/贴图槽/属性/GPBF |
| 启动时弹「无法连接至服务器 R1152-AAA-AAA2」 | 离线/网络，与 mod 无关 | 按 F 关闭；只装 BoneSystem 也会出现 |
| RE Mesh Editor 报 `Streaming mesh file is missing` | 只抽了 base Mesh | 同时抽取 `natives/stm/streaming/...` 版本 |
| 背上武器陷进衣服 | 挂点照搬了原版局部偏移 | 按「挂点到外层背表面」原版间距放置 |

## 已被证伪的捷径

- **「T2b 只放 MDF 就黑屏，所以是 MDF 字段错了」**：只放 MDF 时，它仍然引用那几张
  加载不了的贴图。本例据此改了脸部叠加层的标志位（r5），仍然黑屏。真正能隔离 MDF 的
  是「MDF 只引用原版贴图」的对照组 —— 它进了标题。
- **「贴图放错了路径（普通路径 vs streaming）」**：r4 把贴图挪到与参考 mod 相同的
  streaming 路径，仍黑；换新 REFramework 后两种放法的本质问题都不存在。
- **「改成原版式 base + streaming 双文件就行」**：旧 REFramework 下连原版字节都不行；
  新 REFramework 下单文件即可。
- **「打成 PAK 就绕过去了」**：旧 REFramework 下 PAK 被忽略，放在主链或 sub 链都一样。
- **「隐藏部位只要 root/COG/Hip 三骨就够」**：会丢武器与投射器挂点，导致武器消失和
  野外崩溃。
- **「碰撞体按身体平均截面拟合就行」**：对要推开布料的碰撞体不成立。
- **「BoneSystem 配置多写几个键更保险」**：本例后来收敛到参考 mod 的 6 个键；多余的键
  没有带来任何可观察的作用。

## 反复出现的元错误

1. **先改内容、后查环境。** r1–r5 连续五版都在改 mod 文件，而同一环境下连原版字节
   都加载不了。黑屏类问题的第一步应当是正对照 + 加载器负对照 + 旧 mod 参考对照，
   三者跑完再决定改不改内容。
2. **二分没有考虑文件之间的引用。** 按文件二分时，要列出每个文件引用了谁；带引用的
   文件单独测试时，要么同时提供被引用对象，要么把引用改成原版对象。
3. **把用户验收当成全量验收。** 「验收通过」对应的是用户实际试过的场景；表情、全部
   武器种类、全部地图等未被单独报告的项目要写成「未单独签收」。

## 环境相关

- 项目放在云同步目录时，部分文件是云占位符，首次读取可能超时或失败；构建前确认源
  文件已水合。
- 多台机器共用同步目录时，同步冲突会生成「冲突文件」副本；提交公共仓库前逐个排除。
