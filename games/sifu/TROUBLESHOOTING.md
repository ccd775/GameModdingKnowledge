# 排障手册

除标注外均为本项目实测。

## 1. 构建与打包

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 实机整个人发暗、看不出贴图（测试 1–4） | UE Python 取出的材质槽结构体是副本，改完写回的还是原值；烘焙后的网格每个槽 `Material: null` | 建新的 `SkeletalMaterial` 列表整体 `set_editor_property("materials", …)`，断言读回；pak 用 CUE4Parse 核对每个槽的路径 |
| 修复后第一次实机（测试 5）仍偏暗 | 未查明，之后的构建没有复现 | 记录；再出现时先做 pak 读回检查 |
| commandlet 日志里没有 Python 的输出 | `LogPython` 的普通输出不进 commandlet 日志 | 脚本把结果写 JSON（`ue_build_out.json`），日志只过滤错误和 `_DONE` |
| UE 导入后多出一根根骨（UE 的规则，构建脚本一直遵守，未实际踩到） | FBX 的骨架对象不叫 `Armature` | 骨架对象命名为 `Armature`（UE 只剥这个名字的根节点） |
| 构建脚本断言槽数 > 11 | 第 2、3 套服装按槽号覆盖 11 以上 | 合并材质，可见槽放 0–10 |
| 烘焙进 pak 后游戏原件被盖掉（设计时规避，未发生） | 占位资产被收进 pak | `cook_pak.ps1` 只收目标网格和自己的资产目录 |
| `SifuExport anim` 抛异常 | 帧号 ≥ numFrames | 先看输出里的 `frames=`，帧号取小于它的值 |
| pak 检查报 FAIL，但 pak 是对的 | Git Bash 里读 Windows Python 的输出带 `\r`，目录名比较失败 | `tr -d '\r'` |
| Blender 后台预览写到磁盘根目录被拒（Permission denied） | 输出用了相对路径，落到了磁盘根目录 | 输出一律写绝对路径 |
| Blender 后台运行时加载了别的插件、行为不同 | 用户配置里装了第三方插件 | `-b --factory-startup` |
| `bake_ao.py`：`'NoneType' object has no attribute 'nodes'` | 网格上有没开节点的占位材质 | 烘焙前对所有材质 `use_nodes = True` |
| SSH 卡在密钥交换 | 远端大流量 BT 下载 | 停下载或重启远端 |

## 2. 实机外观与物理

| 症状（用户反馈或 agent 截图） | 原因 | 处理 |
| --- | --- | --- |
| 双马尾 / 尾巴像钟摆一样来回晃 | 重力全开而驱动太弱；PhysX 角阻尼只作用在质心惯量上，线阻尼又只有 0.5 | 降重力、按加速度驱动公式定刚度和阻尼、线阻尼 8（[物理](PHYSICS.md) §2） |
| 跑步前倾时腰腹露出一大块 | 源模型把上衣下摆绑在 `spine_03`、下面的皮肤在 `spine_01` | 皮肤、上衣、内衣、裙腰统一套 W 的躯干分布（[角色拟合](CHARACTER_FIT.md) §3） |
| 跑步时大腿侧面切进裙子 | 渲染裙在代理里面；大腿胶囊偏细 | 代理贴内包络；锥形胶囊按 95 百分位半径 |
| 裙子松垮、腰部有缝 | 腰部的圆形脊椎胶囊把代理顶环推开 | 裙摆碰撞只留骨盆 / 腿 / 手臂 |
| 偶尔透出臀部、大腿根、肚子、裆部 | 代理后面什么都没有，运动中向内塌 | backstop（插件实现），裙腰前部跟皮肤 |
| 少数姿势（技能预览里的踢腿）大腿侧面露一点肉 | UE 4.26 NvCloth 没有连续碰撞，粗网格被快速踢腿穿过 | 11 环 + `SolverFrequency` 240 |
| 眼珠从来不转 | 面部阶段把眼片的眼骨权重丢了 | 眼片统一 0.12 眼骨权重（[角色拟合](CHARACTER_FIT.md) §5） |
| 双马尾用 NvCloth 时发束被撕成碎条 | 体积发束在 mesh-to-mesh 映射下撕裂 | 否决；改用骨链 |

## 3. 多模型构建（离线发现）

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 长袖、袖绳在静止姿势就甩进腿里或身后（转了 59°） | T→A 重摆时跟着手臂一起转 | profile `hang` 回正 |
| 外套下摆、长袖在动作预览里直接穿过腿 | 静止时与腿重叠的刚体对被关掉了碰撞 | 新式链保留大腿 / 小腿碰撞；袖子 `rscale` 0.12 |
| 某片下摆跟着别的部件动（PicodraTech OuterB 跟着口袋绳） | 「最深后代路径」走进了别的分支 | 显式 `path` + `subtree` |
| 预览里衣服下面露出本该被遮住的皮肤 / 夹克遮罩掉的躯干 | 源模型靠透明贴图隐藏，游戏的衣服材质不透明 | 删除图集 alpha < 0.05 的面（`cull_alpha`） |
| 手里 / 嘴里的道具在空手动作和表情时穿模（Karin_Y 的两把苦无） | 道具绑在手 / 头上，游戏动作不知道它们 | `drop_meshes` 去掉 |
| 不同来源的骨名对不上（`UpperLeg.L` / `UpperArm_L` / `LeftUpperArm` / `Toes.L`） | 各源模型命名不同 | `source_prep.canonical()` 统一成 VRM 名，顶点组同步改名 |
