# 表情

仁王2 的表情是骨骼驱动的：脸那次绘制带 128 个条目的调色板，眨眼、张嘴、眉毛都由面部骨的矩阵变化完成。KarinN2 把 Karin 的脸画在这次绘制上（宿主 B，IB `834bff26`），权重直接写成脸调色板的条目号。
骨号和条目号是 `[B]`，拟合方法是 `[I]`。

## 1. 面部权重迁移（`face_weights`）

- 源：Karin 的 `Karin_Face` 材质（3379 个顶点）。`Karin_Alpha` 叠加层要混合，没有带。
- 对齐：在 Karin 和原版脸上各取 5 个特征点（左右眼表面中心、鼻尖、嘴、下巴），每个坐标轴单独做「缩放 + 平移」的最小二乘。
  - 本案例 `[C]`：缩放 (0.76, 1.08, 0.77)，特征点残差 ≤ 1.1 cm；正脸顶点到原版脸最近点的距离中位 0.49 cm、95 分位 3.08 cm。
  - build1 的早期版本取的眼部、嘴部特征点不准，迁移距离中位 4.5 cm；换成上面 5 个特征点的最小二乘后才对上。
  - 深度方向变化很小时（侧脸轮廓不明显），Z 的缩放取 X、Y 的平均，避免病态。
- 迁移：对齐后每个 Karin 顶点取原版脸最近的 4 个顶点，按距离反比混合它们的权重；离得越远越多地落到头骨（距离 0.6 cm 以内全取迁移权重，2.0 cm 以外全取头骨）。
- 虹膜：按 UV 区域识别，全部刚性跟头（眼球转动没有做）。下巴以下、靠后的顶点 0.3 颈 + 0.7 头。
- 允许负权重：f16 量化后最后一个权重补足，使总和精确为 1。

## 2. 眨眼

### 2.1 被否定的方案：放大眼睑骨权重（build1d）

- 做法来自仁王3（本库 `games/nioh-3/FACE.md`）：游戏眨眼时上眼睑骨移动约 1.3 cm，Karin 的眼睑闭合要走约 4.5 cm，就把眼睑骨的权重放大到 3 倍左右，头骨取负的余量保持静止姿势不变。
- 实测（agent 60 fps 录装备界面的脸）：30 s 里 8 次眨眼，每次只闭到约 1/3。游戏的眼睑骨绕**原版眼球**的支点转，把 Karin 更大更靠前的眼睑往前推，而不是往下压（`runtime-rejected`）。

### 2.2 形态键眨眼（build2a → 2b）

- Karin 的眼睑顶点（闭眼形态键位移 ≥ 0.05 cm 的 1130 个顶点，不含虹膜）改为刚性跟头骨，不再受眼睑骨影响。
- 计算着色器 `blink_b.hlsl` 在脸的主 pass 里运行（脸的 VS `7439d16e…` 设 `$kn2_facevs = 1`）：
  1. 读这次绘制的 `vs-cb0`（脸调色板）；
  2. 把左 / 右主眼睑骨在原版眼睑重心处的位置变换到**头骨空间**，取它向下的位移 d；
  3. 闭合量 `a = saturate((d − Z) / (D − Z))`，`D = 1.4 cm` 为完全闭合，`Z = 0.08 cm` 是静止时的抖动（死区）；
  4. 每个顶点 `位置 = 静止位置 + a × 闭眼形态键位移`（按顶点所在的左右侧取对应的 a），写进一个可当顶点缓冲用的 `RWByteAddressBuffer`；
  5. 宿主 B 的 `vb0` 换成这个动态缓冲（影子 pass 用静态的 `vb0`）。
- `D`、`Z` 在 `karin.ini` 的 `[ResourceKN2_B_prm] data = 1.4 0.08 0 0`，改完按 `F10` 生效：D 越小越容易闭眼。
- **哪根骨是眨眼骨要实测**。build2a 按位置选了条目 16 / 17，它们眨眼时根本不动，形态键一次都没触发（`runtime-rejected`）。
  - 用一个只在脸 VS 上运行的计算着色器把每帧的脸调色板连续写进环形缓冲，转储后看各条目的位移：条目 24 / 25 在完整眨眼时下落约 1.6 cm，32 / 33、34 / 35 与它们同步；16 / 17 静止。
  - build2b 改用 24（左，+X）/ 25（右）：60 fps 录像里 30 s 眨眼 11 次，每次完全闭合。用户：「我观察了一下：眨眼是正常了」（`runtime-confirmed`）。

## 3. 其它表情

- 张嘴、眉毛等由迁移来的权重跟着游戏的面部骨走（下颌是脸调色板的条目 96）。没有专门检查过关卡里的喊声、受伤、过场表情。
- 视线：虹膜刚性跟头，眼球不转。

## 4. 前提

- 只对制作时那张脸生效：宿主 B 按原版脸的 IB 匹配，换了脸型（不同的脸模型）IB 就不同，Karin 的脸不会画，原版脸也不会隐藏。
- 角色编辑器里具体选了哪一项（脸型、眉毛等）还没有记录下来；测试存档来自 Nexus 的 PerfectStarterSave（仁王2 mod 95）。
