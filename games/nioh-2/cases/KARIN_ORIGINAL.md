# 案例：Karin_Original → 仁王2 女性主角（2026-11-07 → 11-10）

游戏 1.25（PC 首发版），Nioh 2 Mod Enabler 1.1（3DMigoto 1.3.16）。源模型：Karin_Original 的 FBX（与本库仁王3 项目同一个文件），不随本库发布。

**用户需求**：用 Karin_Original 做一套角色替换 Mod，「装配表情和物理」。用户提供了 Mod Enabler 和一份社区新手存档（Nexus 仁王2 mod 95，可以直接覆盖测试机的存档），允许参考社区资料。
后来要求「提供可再部署mod包」，又要一个像浪人崛起、仁王3 那样的改存档小工具，并说明要用什么发型和脸；最后问 Steam 版能不能用。

## 1. 工具链

- 新写：K300 归档读取 `n2lnk.py` / `ktpack.py`（只读）、帧分析解析 `fa_parse.py` / `fa_mesh.py`、跨绘制骨号 `bones.py`、关节求解 `n2_skel.py`、贴合 `n2_conform.py`、构建器 `n2_build.py`（网格、贴图、全部着色器和 ini）、编译检查 `c46.py`、离线物理测试台、换装器 `n2_miaomiao.py`。
- 复用：仁王3 / 浪人的 `g1m_tool.py`（只用于归档里的模型搜索）、仁王3 项目导出的 Karin 源数据、仁王3 换装器的加解密代码。
- 社区资料：3DMigoto 源码（1.3.16，查自定义资源和命令列表的行为）、aluigi `nioh.bms`、RDBExplorer-nioh2、Mawpius/3d-fixes、alfizari/Nioh-2-Save-Editor（存档偏移和护甲 ID）。
- 游戏在另一台测试机上：文件走 SSH，界面操作走用户会话里的远程输入；截图在远端裁剪、转 JPEG 再拉回；录像用 ffmpeg 在远端录。

## 3. 每一轮的原因与教训

- **找不到模型就换层**：归档路线卡住后，3DMigoto 绘制替换绕开了模型格式，代价是一切都按哈希识别、依赖游戏版本。
- **整屏黑**：不是 Karin 的问题，是挂了全屏 PS；之后只挂角色网格的 PS，并且隐藏某个部件前先看它用哪个着色器画。
- **眨眼**：照搬仁王3 的权重放大失败，原因是游戏眼睑骨的转动支点和 Karin 的眼睛不在一处；形态键方案把「游戏驱动多少」和「Karin 怎么闭」分开了。眨眼骨按位置猜错了一次，实测才对。
- **刘海飘进脑袋**：问题在绘制顺序，不在权重。装备界面看不出来，只有关卡里出现。
- **马尾拉长、裙子耷拉**：借来的物理骨不是为这个部件做的。自己算的链能保证段长、限幅和碰撞。
- **裙子穿模**：裙子要和它盖住的皮肤一起动；腰胯皮肤会跟着脊椎转，不只是骨盆。
- **狐耳不动、尾巴不动**：离线测试的动作太温和（瞬停、骨盆固定），而且漏测了尾巴。每条链单独测，用减速、扭胯这类更像游戏的动作。
- **布条**：没定位就回答，猜错了。之后先在帧分析里找到具体的绘制再答。
- **护胫**：README 第一版写「楯无护胫」，其实是存档里楯无护胫的外观被改成了隼护胫。做换装器时读存档才发现。

## 4. 交付

- `KarinN2` build5（27 个文件），测试机上 26 个文件与发行包一致（发行包多一个 README）。用构建包重建与发行包逐字节一致（README 除外）。
