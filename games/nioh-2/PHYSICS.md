# 物理

3DMigoto 不能给游戏加物理链，也不能读写游戏的布料模拟。KarinN2 的次级物理全部由 Mod 自己的计算着色器 `sim_a.hlsl` 每帧算一次，结果写进合并调色板 B 的模拟骨，由宿主 A 画出来。
参数是 `[C]`（Karin 专属，60 fps 调校）；方法是 `[I]`。

## 1. 被否定的方案：借原版的物理骨

- build1–2b：双马尾跟左右围巾链（全局骨 g75–79 / g86–90），裙子前片跟袴的前片链（g23–25 / g26–28），侧面和后面跟骨盆 / 大腿；狐耳、尾巴刚性挂在头和骨盆上。
- 结果（`runtime-rejected`）：
  - 围巾从胸口挂下来，绕身体甩大弧，转身时双马尾被瞬间拉长（用户：「转身的时候，马尾会被短暂地剧烈拉长」）；
  - 飘带站定时下垂，裙子前片跟着耷拉，穿过骨盆和大腿；
  - 狐耳、尾巴「没有可见物理」。
- 结论：别的部件的物理骨长度、挂点和摆幅都不是为这个部件做的，借来只能凑合。

## 2. 弹簧链模拟（`sim_a.hlsl`）

- 一个线程算一条链，`[numthreads]` 覆盖 23 条链；`CustomShaderKN2_Sim` 带 `max_executions_per_frame = 1`，在宿主 A 的主 pass 里 `MergeA` 之后运行。
- 状态：`RWStructuredBuffer<float4>`（每条链的粒子位置、上一帧位置、上一帧锚点矩阵）；读锚点用调色板 B 的镜像 `RWStructuredBuffer`（Mod Enabler 的编译器拒绝多分量类型 UAV 读，[技术合同](TECHNICAL_CONTRACTS.md) §2 / [构建流水线](BUILD_PIPELINE.md) §8）。
- 每帧每条链：
  1. 根节点跟着锚点（一根游戏骨，或裙子的权重场，§3）刚性走；
  2. 其余粒子做 Verlet：速度乘 `CH_DAMP`，加重力 `CH_GRAV`；
  3. **惯性**：锚点自己这一帧的位移里，有 `1 − CH_INERTIA` 的份额直接带着粒子走（0 = 完全跟随，1 = 完全被甩在后面）；被甩开的距离每帧最多 `CH_LAG` 厘米（限制翻滚、闪避时被甩飞）；
  4. **回弹**：向刚性姿势（链随锚点不动时的位置）拉回，力度从根 `CH_K0` 线性变到尖 `CH_K1`；
  5. 碰撞：3 次迭代，把粒子推出各碰撞体（球或胶囊），每条链只碰 `CH_COL` 位掩码里的那些；
  6. 长度约束：每节长度固定为静止长度（**不会被拉长**）；每节和静止方向的夹角不超过 `acos(CH_COSMAX)`；
  7. 骨骼矩阵：每节按最小弧旋转把静止方向转到当前方向，再沿这一节轻微拉伸到下一个粒子；写成模拟骨的本帧和上一帧矩阵（游戏的运动模糊 / TAA 也要上一帧）。
- 一帧一步，按 60 fps 调校：更高帧率下摆动更快、更硬。
- 静止段长要取「权重场蒙皮后的静止位置」之间的距离，不能取 Karin 原骨架的关节距离：两者不同时，链一开始就被拉向错误长度，离线测试里裙子大面积穿模（build4 开发中发现并改正）。

| HL / HR | 鬓发 | 头 g8 | 3 | 0.30 / 0.20 | 0.88 | 0.4 | 300 | 3.0 | 35° | 头、下巴、胸 |
| K0 … K8（16 条） | 裙摆 | 权重场 | 2 | 0.25 / 0.15 | 0.85 | 0.5 | 300 | 1.8 | 40° | 骨盆、胯、臀、左右大腿 |

- 共 23 条链、58 根模拟骨。调色板 B 66 根（模拟骨 + 头、胸、骨盆、大腿等 8 根普通骨），调色板 A 60 根。
- 裙子：Karin 的 16 条裙链（`Skirt_0`、`Skirt_1_L` … `Skirt_7_R`、`Skirt_8`），只模拟下面两节（`_001` 关节是支点）；腰部那一节保持权重场的权重。
  锚点是**权重场**：每个关节按权重场在该点给出的骨骼混合来走（腰部是身体，越往下大腿越多），所以不受扰动时裙子正好是 build3 那套不穿模的蒙皮，弹簧只在上面叠加滞后和摆动。
- 碰撞体 `[C]`（球或胶囊，半径 cm；离链静止粒子太近时缩到最近粒子距离的 90 %）：头 12、下巴 7.3、胸 14、骨盆 14、胯（左右 ±8 cm 的胶囊）12、臀 12、左 / 右大腿（髋 → 膝的胶囊）11。

- 狐耳第一版按「瞬间停下」调，离线摆 10° 以上，游戏里几乎不动：游戏的停步是约 0.3 s 的减速（`runtime-rejected`）。按游戏里录到的减速曲线重调后通过。
- 尾巴在 build4 离线报告里漏测了：裙子测试台把骨盆 g0 固定不动，而尾巴就挂在 g0 上，摆幅只有 3°。build5 给测试台加了跑步时的胯部扭动（偏航 8°、横滚 4°），再调软。

## 5. 离线测试台（便携包 `checks/`、`simcheck/`）

- `checks/simtest.py`：双马尾 / 尾巴，跑动、180° 转身、侧闪。
- `checks/eartest.py`：狐耳，带减速的停步、120° 转身、前冲，统计摆角和回弹次数。
- `simcheck/`：
  - `common.py` / `test2.py` / `xfer.py` / `harm.py` / `adapt.py` / `v2.py` / `v3.py`：裙子权重场的推导和静止穿模测试——合成的腿部姿势（站、走、跑、冲刺、侧踢、后踢、深蹲）做 LBS，
    再叠加游戏里抓到的脊椎相对骨盆的转动（中位 12°，最大 30°），在（角度，高度）网格上量皮肤有没有跑到裙子外面；
  - `simpy.py`：`sim_a.hlsl` 的逐行 Python 移植，加上调色板 B 网格的蒙皮；
  - `anim.py` / `anim2.py` / `anim5.py`：用合成动画驱动 `simpy.py`（对称步态；带 70° / 30° 步幅的减速跑、停步、120° 转身、侧闪），报告每组链的最大摆角和皮肤穿出的帧；
  - `rest_check.py`：静止时（一次复位步）的裙子和 build3 权重场蒙皮对比；
  - `tailtune.py`：尾巴尖在跑 / 停 / 转身时的摆角、静止下垂、伸进大腿胶囊的深度，比较几组参数。
- 测试动作要比游戏更狠：游戏里跑步抬腿超过 50°（裙子测到 75° 冲刺、95° 抬膝），停步是减速而不是瞬停，跑步时胯部会扭。
- 测试台通过后，再用游戏里 30 fps 的录像逐帧看耳尖、尾巴尖：隔 0.4 s 的截图看不出回弹。

## 6. 已知限制

- 双马尾只碰头、胸、骨盆，狐尾只碰骨盆、臀和大腿；极端动作时可能穿过手臂或腿。
- 裙摆的静止位置跟着大腿：大步跑、深蹲时两腿之间的裙摆被拉伸，深蹲时大腿可能从裙摆下面露出来；膝盖抬过胯这类动作仍可能轻微穿模。
- 不和别的角色、场景、武器碰撞。
- 一帧一步，没有子步；帧率越高越硬。
