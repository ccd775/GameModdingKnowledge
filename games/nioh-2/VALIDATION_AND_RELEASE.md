# 验证与发布

## 1. 离线闸门

每个构建都要过：

- 构建器的断言：每个调色板 ≤ 85 根骨、每个记号都有源绘制、宿主 A 顶点数 < 65536。
- `c46.py <d3dcompiler_46.dll> *.hlsl`：7 个计算着色器全部用 Mod Enabler 自带的编译器编译通过（fxc 通过不算）。
- `check_skin.py`：用帧分析那一帧的真实矩阵蒙皮，叠在原版角色上，身体、手指、脸对齐。它只重建调色板 A，build4 起的输出跑不了（[构建流水线](BUILD_PIPELINE.md) §4）；那之后蒙皮的检查靠裙子 / 物理测试台和实机。
- 脸：`build_report.json` 里特征点残差、正脸迁移距离（本案例中位 0.49 cm）；离线渲染闭合量 0 / 0.5 / 1 的脸，0 时与静止一致、1 时完全闭眼。
- 物理：改了哪条链就测哪条，每条链都要有自己的数字（[物理](PHYSICS.md) §4–5）：
  - 裙子：`simcheck/rest_check.py`（静止，各合成姿势无皮肤穿出）、`simcheck/anim5.py`（减速跑、停步、转身、侧闪：摆角和穿出帧）；
  - 尾巴：`simcheck/tailtune.py`；双马尾：`checks/simtest.py`；狐耳：`checks/eartest.py`。
- 改了隐藏 / 挂钩：在帧分析里确认要隐藏的每个 IB 都由已挂钩的着色器画（[技术合同](TECHNICAL_CONTRACTS.md) §2）。
- 重建：用构建包重建一遍，和上一个发行包逐字节比较，只有预期的文件变了（例：build4 → build5 只有 `karin.ini` 和 `sim_a.hlsl`）。

## 2. 实机闸门

1. 游戏关闭时放好 `Mods\KarinN2`，和发行包逐个比哈希。改过着色器就删掉旧的编译缓存。启动；UAC 提示不替用户同意。
2. 标题画面、装备界面：角色完整、脸正常、没有原版部件。**装备界面的绘制顺序和关卡不同，这一步不能判断帧对齐。**
3. 读档进关卡：
   - 站定：正面、两侧、背面，裙腰平整、没有原版布条、头发不穿脸；
   - 朝镜头跑：刘海留在额头上；急转身：双马尾不拉长；
   - 30 fps 录像逐帧看狐耳、尾巴、双马尾的摆动和停下后的回弹（隔 0.4 s 的截图看不出来）；
   - 待机眨眼：60 fps 录像，数一段时间内的眨眼次数和闭合程度（本案例用虹膜红色像素的占比找下凹）。
4. 用户实际玩过、给了反馈才算 `runtime-confirmed`；agent 截图、录像只算 `runtime-load-pass`。
   - build4、build5 的效果由用户自己在游戏里看：agent 通过 SSH 部署，build4 在游戏里按 `F10` 重载并确认能正常加载；用户在玩的时候不发桌面动作。

## 3. 发行包

- 内容：一个 `KarinN2\` 文件夹，放进 `<游戏目录>\Mods\`。
  - `karin.ini`；
  - 7 个计算着色器：`merge_a.hlsl`、`merge_s1.hlsl`、`merge_s2.hlsl`、`sim_a.hlsl`、`blink_b.hlsl`、`tick.hlsl`、`stamp.hlsl`；
  - `meshes\`：`karinA.vb` 和 4 个 IB、`karinB.vb0` / `vb1` / `karinB_face.ib` / `karinB_blink.buf`；
  - `textures\`：4 张 BC7 2048 颜色贴图、5 张常量贴图；
  - 手写的 `README.md`（前提、安装、调参、已知限制）。共 27 个文件。
- 前提写进 README：Mod Enabler；女性主角、长马尾、制作时那张脸；五件护甲的外观都是隼套装（两种改法：铁匠「外观变更」，或者用换装器）。
- 调参不用重建：物理在 `sim_a.hlsl` 顶部（每个数组 23 项，顺序写在文件第二行），眨眼阈值在 `karin.ini` 的 `[ResourceKN2_B_prm]`，改完按 `F10`。裙子权重在 `meshes\karinA.vb` 里，要重建。
- 换装器单独发一个 ZIP：单文件 EXE、README、第三方许可（pawREP MIT、alfizari Apache-2.0 全文，以及 Python、Tcl/Tk、NumPy、PyInstaller）、源码。EXE 没有代码签名。
- 交付前：发行包与测试机上的文件逐个比哈希；`d3dx.ini` 的开发改动全部改回；测试改过的存档恢复原样。

## 4. 游戏版本与 Steam 版

- 本项目只在 **1.25**（标题画面「Version 1.25」，`nioh2.exe` 2021-02-05，PC 首发版）上做过和测过。Steam 版会自动更新，之后至少出过 1.25.1（2021-02）、1.27（2021-03）、1.27.1、1.27.2（2021-04）、1.28（2021-09）和 1.28.6（2021-12），补丁里有性能和 DLSS 相关改动。
- Mod 依赖的都是游戏数据，和发行渠道无关：
  - 15 个着色器哈希（11 个角色 PS、布料 VS、两个影子 VS、脸 VS）和蒙皮 VS `73278b6e` 的 cb0 布局；
  - 护甲、脸、发型的 IB 哈希；
  - Mod Enabler 的 `CommandListN2General`。
- 补丁要是重新编译了这些着色器或改了模型，Mod 在新版本上**不会生效**：显示原版角色，不会崩溃。是否变了没有核实（1.28 的文件不在手边，Nexus 和 SteamDB 的页面拒绝抓取）。状态：`hypothesis`，等 Steam 版玩家实测。
- 让新版本也能用：请玩家在 `d3dx.ini` 里把 `hunting` 改成 1，在装备界面按一次 `F8` 抓帧，把 `FrameAnalysis-*` 里的日志和 `vs-cb0` 转储发回来；新哈希**加进**挂钩表和隐藏表，旧的保留，一个包同时支持两个版本；cb0 行数变了还要改合并着色器的常量。
- 换装器基本不受补丁影响：存档格式是固定布局，社区编辑器 alfizari/Nioh-2-Save-Editor 面向当前 Steam 版，用的偏移相同（`reference-inferred`）。它不改账号 ID；开着 Steam 云时可能提示冲突，选本地那份。
- 想用 1.25 的 Steam 用户可以在 Steam 控制台用 `download_depot` 下载旧版本（未验证）。

## 5. 未测场景

- 过场动画、神社、多人、其它武器架势下的大动作；
- 高于 60 fps 时的物理手感（一帧一步，会更快更硬）；
- 张嘴、喊声等眨眼以外的表情；
- 别的发型 / 脸 / 护甲外观（按设计会显示原版部件）；
- Steam 当前版本；别人的存档和没拿到过隼套装的存档。
