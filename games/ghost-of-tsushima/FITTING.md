# 拟合与绑定

坐标约定：GoT 空间单位为 cm，x 前、y 左、z 上。Jin 的绑定姿势是 T-pose。源模型从 glTF 空间（y 上）换到 GoT 空间，再整体放大 1.45 倍。

## VRM 读入

- **VRM 1.0：** 人形骨骼表在 `VRMC_vrm.humanoid.humanBones`（字典）。
- **VRM 0.x：** 骨骼表在 `VRM.humanoid.humanBones`（列表），有两处和 1.0 不同：
  - **拇指命名错开一节。** 0.x 的 `thumbProximal` 对应 1.0 的 `thumbMetacarpal`，`thumbIntermediate` 对应 `thumbProximal`。
  - **朝向相反。** 0.x 模型朝 −Z，要把世界矩阵左乘 `diag(−1, 1, −1)` 转成 1.0 的朝向。

  读入时统一转成 1.0 的命名和朝向，下游代码就不用再区分。
- **glTF 0.x 导出器会让同一 mesh 的多个图元共用一个顶点缓冲。** 每个图元要按自己的三角形压缩出自用的顶点，否则容量统计和剔除都会算错。
- **不导入的材质：** 半透明叠加材质（眼睛高光、腮红一类，`Karin_Alpha`）没有合适的槽位，直接跳过。

## 拟合目标（TPS）

先确定一组「关节 → 目标位置」，再用 3D 薄板样条（TPS）把整个网格平滑变形过去：

- **动画最依赖的关节落在 Jin 的关节上：** 髋、膝、踝、肘、腕、手指。
- **骨盆保持 Karin 自身形状**，相对两个髋关节平移。裙摆和腿的相对位置因此与源模型一致。
- **脖子保持原长。** 颈根放在 Jin 颈关节（12）下方 `neck_drop` = 5 cm 处，Jin 的头部转轴（17）于是落在她较大的头部内部（眉眼附近）。硬对齐颈、头关节会把脖子拉长到 12 cm，源模型只有 7.8 cm。
- **躯干承担剩余长度差。** 从髋到颈均匀拉伸，本例约 1.18 倍；截面保持 1.45 倍。
- **头部刚性。** 蒙皮在头部子树上的顶点（脸、头发、兽耳）按头部权重比例直接走头部的刚性映射，不经过空间变形。否则垂到肩部的发束会被躯干拉伸扯成片状。
- **控制点包括三类：** 关节点、骨段轴线上的采样点、以及骨段周围的环形点。手和脚刚性，挂件跟随各自的人形祖先移动。
- **环形控制点放在皮肤半径上：** 取该骨主导顶点径向距离的 30% 分位，上限 0.35 倍骨长；手指仍用 1 cm。
  - 旧做法取 0.35 倍骨长，小腿上的环达到 14 cm，越过中线伸进了另一条腿。
  - Jin 两脚比 Karin 站得开，两条腿的映射互相拉扯，把腿横向撑宽到 1.12–1.52 倍、胸部撑宽到 1.09–1.18 倍。
  - PicodraTech profile 从剔除之前的完整网格上量半径。Original profile 仍在剔除后量（`ring_radii = culled`），这样才能保持它的回归 md5，不要去「修正」它。
- **合并过的服装骨架**（`ctrl_policy = skinned`）要筛掉会拖拽身体的节点：
  - 只取有蒙皮的非人形节点。PicodraTech 的骨架里挂着其他服装遗留下来的整套无蒙皮手臂骨。
  - 头部子树里低于脖子的节点（垂到腿边的发尾、耳机线）不参与。
  - 躯干子树里低于髋关节的节点（外套下摆）按骨盆映射，不按脊柱外推。
- **法线和切线：** 法线用混合后雅可比矩阵的逆转置变换；切线按 UV 重算。
- **TPS 的边界：** 它只能控制控制点附近的形状。离骨骼远的宽松布料（腿套下摆、厚底鞋底）实际按全局比例走。这类区域要用显式的区域映射，见下文「脚与着地」。

## 肩部：转轴不匹配（本作最重要的一条）

Jin 的上臂绕 499 / 546 转动，转轴在 y ≈ ±18.2 cm、z 147 cm。Karin 的肩关节拟合目标在 y 9.8–10.9 cm、z 约 145 cm，位于转轴内侧 7.3–8.4 cm。

手臂绕转轴下垂角度 a 时，相对转轴 (dy 向外, dz 向上) 的点会抬高：

```text
rise = dz·(cos a − 1) − dy·sin a
```

所以，转轴内侧的点（dy < 0）和下方的点（dz < 0）都会被抬起来。无论在 T-pose 下把手臂根部放在哪里，都无法同时兼顾 T-pose 和下垂姿势：

| T-pose 根部位置（外移比例 / 下沉 cm） | 手臂下垂时的结果 | 证据 |
| --- | --- | --- |
| 0 / 5（Karin 自身肩宽） | 根部翻到她自己肩关节上方约 10 cm | Original：宽松毛衣盖住，实机外观正常；PicodraTech：露肩，实机明显**耸肩** |
| 0.5 / 8 | 根部约高 4–5 cm，实测肩头皮肤抬高 3–4 cm | PicodraTech 实机：**尖锐凸起** |
| 1 / 8（放在转轴下方） | 不翻起，但躯干的肩部皮肤被拉成水平台面 | 离线：**方肩**（未上实机） |
| 1 / 0（对齐转轴，Original v2）；约 0.5 / 0（Original v3，半宽 14.5 cm） | 翻起少或不翻起，但肩宽接近 Jin | Original 实机：**宽肩 / 男性肩宽** |
| 0.5 / 8，外加只削皮肤的上臂权重 | 皮肤不再翻起，但袖套边和外套领口照样翻起 | PicodraTech 实机：**尖刺** |

**有效做法：按下垂姿势反解绑定位置**（`--arm-hang`；PicodraTech profile 默认 75°，Original profile 默认不开，以保持它的回归 md5）。

1. 躯干按 Karin 自己的肩形拟合（外移 0、下沉 0）。
2. 上臂用一个相似映射（旋转 + 轴向拉伸 + 截面 1.45 倍）放置，使它绕 Jin 转轴下垂 `a` 度后，根部正好落在她自己的肩关节上，肘部仍对齐 Jin。
   - 根部位置：`root = pivot + Rᵀ·(shoulder − pivot)`；
   - 75° 时，这个位置在 T-pose 下约为转轴正下方 8.7 cm。
3. 只要顶点有一个权重落在被该姿势带动的骨骼上，就逐顶点解一次：

   ```text
   Σ_k w_k S_k x = Σ_k w_k S_k X_k
   ```

   - `S_k` 是 Jin 在下垂姿势下的蒙皮矩阵：绕转轴旋转，其余骨骼为单位阵。
   - `X_k` 是目标位置：上臂节点骨用上臂映射的位置，其余骨用躯干拟合的位置。
   - 解出的 `x` 就是新的绑定位置。结果是：纯躯干顶点不动，纯上臂顶点落在上臂映射上，混合顶点在该姿势下与 Karin 自己的下垂形状完全一致。
   - 法线用 `L⁻¹` 处理混合后的法线，其中 `L = Σ w_k R_k`。
4. 上臂权重的沿骨插值要用上臂映射后的位置来算。

这样做的代价和限制：

- 条件数：最坏情况（w = 0.5）的最小奇异值是 `cos(a/2)`，所以 CLI 把角度限制在 ≤ 120°。接近 180° 时解会发散，而且不会报错。
- 偏离拟合角时有残差：约为 `8.4·sin(δ)` cm。实测 82°（站立）时根部高出她的肩关节约 1 cm，在身体内部，渲染看不出。
- 上举或攀爬时，肩部皮肤会向手臂拉伸，程度和 T-pose 拟合时相近。
- 肘部的混合顶点会在两种截面之间插值，理论上可能出现折痕，离线未见。

**未采用（推理否决，没有实测）：改骨架把转轴内移。** 没有公开证据表明改骨骼位置在游戏里生效；而且两只手会各向内偏约 8 cm，会破坏双手握刀。

## 脚与着地

- **保留原鞋形（`own_feet`）。** 脚趾目标取 Karin 自己的踝→趾偏移，不拉伸到 Jin 的脚趾关节。拉伸会让鞋长多出 13%，实机显得鞋大。Jin 的脚趾骨只负责弯折鞋底前部。
- **鞋子大小（`foot_scale`）用一个绕 Jin 踝关节的均匀相似变换控制。**
  - **显式混合，不能只交给 TPS：** 挂在小腿、脚、脚趾链上的顶点（鞋、腿套、袜口）按 `链权重 × smoothstep(2t − 1)` 混合进这个相似变换，t 沿 Karin 的膝→踝方向；也就是从小腿中点开始渐入，到踝处全量。
  - **雅可比要带混合梯度项：** 加上 `(F − P) ⊗ ∇b`，法线才会随着锥度倾斜。
  - **反例：** 只通过 TPS 传递 foot_scale 时，鞋实际只到约 1.29 倍（名义 1.2），腿套下摆仍是 1.45 倍，像喇叭一样罩住变小的鞋。
- **着地抬高：**
  - `lift = 地面 − 鞋底最低点`。地面取 Jin 脚部和原版草鞋 LOD0 的最低点，为 0.78 cm；鞋底最低点只统计脚部权重大于 0.5 的顶点。
  - 抬高量按「髋→踝」的斜坡分摊给大腿和小腿，不要只压在小腿上，否则小腿会变短。
- **厚底鞋的代价：** 鞋底到踝的距离大于 Jin 的 8.2 cm（1.45 倍时 14.5 cm，1.3 倍时约 12.9 cm）。于是 Jin 的踝转轴落在鞋内、网格脚踝下方约 4.7 cm 处，膝盖网格也高出膝关节约 2.3 cm。深蹲、屈踝、踮脚的离线渲染都未见异常。

## 权重映射

按每个源关节的人形祖先分派：

- **躯干（hips / spine / chest / upperChest）：** 按顶点高度在脊柱链 3 / 4 / 5 / 7 / 10 上做 hat 插值。
- **颈：** 在 12 / 14 上插值。
- **头：** 17。
- **上臂、前臂、小腿：** 沿 Jin 的骨段在主骨和扭转骨之间做 hat 插值，节点表见 [格式合同](FORMATS.md)。
- **大腿：** 按沿骨位置 t（0.10 / 0.35 / 0.60）的关键帧在主骨和两根扭转骨之间分配。
- **尾巴，以及骨盆下的非人形节点：** 3（骨盆）。
- **裙摆类骨骼**（Original 的 `Skirt*`；PicodraTech 外套下摆 `OuterA–D`、`Pocket String`）：
  - 腰头按高度跟随脊柱；
  - 下摆最多有 45% 跟随同侧大腿，在裙摆高度范围内按 smoothstep 过渡，左右用 y 的 sigmoid 区分。
  - **开襟外套只让髋关节前方的下摆跟随大腿**（x 方向 sigmoid，宽 3 cm），后摆随骨盆。否则骑马时后摆会翻到座下。
- **量化：** 每个顶点取前 4 个权重，丢弃小于 0.5/255 的，再归一化；写成 u8，骨骼 0 的权重隐含。
