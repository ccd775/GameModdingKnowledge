# 容量、剔除与贴图页

8 个 LOD0 部件共 46477 个顶点、5 张贴图页。容量表见 [格式合同](FORMATS.md)。

- Karin_Original 源模型约 34.0k 顶点；剔除长袜下的皮肤、再把身体切成两块（切口会复制顶点）后，写入 32.6k，直接放得下。
- PicodraTech 源模型约 58.3k 顶点，要按下面的顺序依次压下来。

每一步都保留原始网格：PicodraTech 的环形控制点半径在剔除之前的完整网格上量。

## 1. 剔除被遮住的几何

**射线锥判定：** 对每个顶点，沿法线方向和法线周围 40° 锥面上的 6 个方向各射一条射线，共 7 条；7 条都在距离 d 内碰到遮盖网格，就认为该顶点被包住。三个顶点都被包住的三角形删掉。实现上用 scipy `cKDTree` 预选候选三角形，再做 Möller–Trumbore 求交。

规则表是 `(被遮网格, 遮盖网格, d)`：

| 被遮网格 | 遮盖网格 | d | PicodraTech 删除的三角形 |
| --- | --- | --- | --- |
| 身体皮肤 | 袜子、短裤、上衣、袖套、鞋、外套、腿环、脸部网格 | 7 cm | 11602 |
| 袜子 | 鞋（袜子伸进鞋里的部分） | 4 cm | 748 |
| 袖套 | 外套（外套袖子里的部分） | 7 cm | 1551 |
| 头皮 | 头发、兽耳、头饰 | 3 cm | 570 |

- **Original 用的是更简单的规则：** 删掉袜口 1 cm 以下的腿部皮肤三角形，共 2640 个，范围与模型 `kisekae_*` 形态键标出的区域一致。
- **删除的原因：** 被遮住的皮肤单独蒙皮，弯膝、深蹲时会从袜子或短裤里穿出来。Original v3 的「膝盖皮肤穿出长袜」就是这个问题。

## 2. 拆出手

把手从身体网格里拆出来，放进布料槽，**手不参与减面**。第一次审查时发现手被减了面，列为阻断项。

## 3. QEM 减面（只减布料、鞋和躯干皮肤）

- **算法：** 半边折叠，只折叠内部顶点。以下顶点锁定不动：
  - 与其他顶点位置重合的顶点（UV 接缝）；
  - 开放边和非流形边上的顶点；
  - 没被三角形用到的顶点。
- **误差二次型不按面积加权。** 按面积加权时小三角形的误差近乎为零，折叠集中到手指上，手指被削成坑洼状。
- **每次折叠都要通过以下检查：**
  - link 条件：两端点恰好有 2 个公共邻点；
  - 不产生重复面：拿折叠后的新三角形去比对顶点周围已有的面；
  - 法线点积 ≥ 0.8；
  - UV 朝向不翻转；
  - 三角形质量 ≥ 0.08；
  - 对权重差异加惩罚，系数为 4。
- **按槽位联合减面：** 同一槽位里所有可减的网格共用一个堆，减面自然落在代价最低的地方。
  - 多块槽位（thigh 的 4 块）按高度切块时，切口两侧会复制顶点，所以要留 5% 顶点、2% 三角的余量。
  - 不能减面的 profile 不留余量，这样才能保证旧 profile 的输出逐字节不变。
- **PicodraTech 的结果：**

| 槽位 | 顶点（前→后） | 三角（前→后） |
| --- | --- | --- |
| chest | 16492 → 14039 | 23038 → 18132 |
| thigh | 15825 → 12945（切块后各块合计 13572，差值是切口重复的顶点） | 25009 → 19249 |
| details | 3941 → 3317 | 6068 → 4820 |

  各网格的顶点保留比例：外套 85%、鞋 78%、上衣 74%、短裤 72%、袜子 80%、躯干皮肤 79%、手 100%。

## 4. 贴图页

每个槽位只有一张漫反射页（2048，details 是 1024），但源模型往往每种材质各有一张图。

- **Original：** 每套材质正好对应 Karin 的一张原图，按 2048 全分辨率写入；underwear 在 1024 页里 1:1 裁剪。
- **PicodraTech：按 UV 岛重新拼页。**
  1. 用并查集求 UV 岛，每个岛换算成源图上的像素矩形（外扩 2 px），重叠的矩形合并。
  2. 所有矩形用同一个缩放比例（≤ 1）做货架式排布，间隙 4 px。
  3. **精确重采样：** 用 `Image.resize(box=…)`，采样框与 UV 映射使用同一个变换（裁剪区域边缘外扩填充）。像素和 UV 必须经过同一变换，标记测试的误差为 0 px。
  4. **重采样前把源图 alpha 设为 255。** 透明像素里残留的 RGB 会渗进颜色。
  5. 空白区域做 push-pull 填充，防止 mip 渗色。
  6. 新 UV 的计算：`u = (页内 x + 间隙 + (源像素 − 矩形左边) × 缩放) / 页宽`。
- **PicodraTech 各页的缩放：** 脸 1.0、头发 0.85、外套和鞋 0.54、上衣 / 短裤 / 袜子 / 手 0.50、其余皮肤 0.48。社区 v1.0 包约为 0.25。
