# 案例：Karin_Original 替换 Beta

> **范围：** 用一个 VRM 1.0 模型替换 Beta（模型组 b2c4），再通过 Mod Manager 的 Characters → Beta 来扮演她。模型穿套头衫、短裙、长袜，有兽耳和尾巴。不做服装差分。
> **证据边界：** build `14835813`（1.5.80.0），HFW Mod Manager 0.9.8，h2_pc_mi_091 0.9.1。
> **状态：** `runtime-confirmed`（用户），有范围限制：
> - 1.0.1 的手指修复由用户在过场动画里确认；
> - 1.1.0 的裙摆、双马尾、尾巴摆动由用户实机认可（「还可以」）；
> - 1.1.0 的表情由 agent 在照片模式里确认；对话中的口型没有专门检查。

## 版本轨迹

v1–v3 用 core 的 sha256 前缀标识，v4 起用 mod zip 标识。v4、1.0.1、1.1.0 都发布过。

| 版本 | 改动 | 实机结果（agent 自测） |
| --- | --- | --- |
| v1（core `6c83ac90`） | 首个完整构建：隐藏子网格换成一个极小三角形（即后来的 `--hide tri`），core 没打补丁 | 拒绝：读档卡在黑底暂停菜单，菜单不响应 |
| v2（core `495b8863`） | 6 个 CsNbtGen 部件改为 VsNbt；隐藏改为塌缩；放大包围盒（相对 v1 有 18 个文件不同） | 能读档；模型像从里面往外看 |
| v3（core 同 v2） | 翻转三角形绕序（只改了 10 个 Karin 网格 stream） | 外观正确；阴影里的头发和兽耳呈棕红色 |
| v4 = 1.0.0（mod zip `cf42d34f`） | 头发和兽耳从脸页移到身体页（皮肤材质） | 读档正常；头发、脸、衣服颜色正确；奔跑和转身时肩、裙摆、尾巴正常 |
| v5 = 1.0.1（mod zip `d15921b2`） | 用户报告过场动画里中指和无名指黏连交叉、指骨扭曲 → `--hands rigid`（3 个文件变化） | 用户：「看起来已经好了」 |
| v6（未发布） | `--face rig`（面部绑定）、`--physics pbd`（只有裙子） | 用户：「表情完全没有，裙摆有少量物理」；agent 在照片模式里看到表情生效，但下巴中线有裂缝 |
| v7t（未发布） | 合并重合顶点的权重；尾巴挂 1 个裙摆粒子，双马尾挂 2 个发束粒子 | agent：表情无裂缝，尾巴大幅甩动；用户：「太单一，没有柔软链式物理的感觉」 |
| v7 = 1.1.0（mod zip `b9e7dcdb`） | 双马尾和尾巴沿长度铺到粒子链上（与 v7t 相比只变了 2 个身体 stream） | 用户：「这样还可以吧」 |

- v1→v2 同时改了两处，卡死无法单独归因。SkinInfo 补丁是按机理和参照 mod 的做法认定的主因。
- v4、1.0.1、1.1.0 都已用便携脚本逐字节复现，见 [验证与发布](../VALIDATION_AND_RELEASE.md#复现基线)。
- 用户报告「没有表情」，实际是正常游戏里不触发面部动画，见 [排障手册](../TROUBLESHOOTING.md)。

## 和参照 mod（Karin Final 006）的差异

- **服装颜色。** 参照 mod 的服装颜色在 512 的服装槽里。本案把身体、服装、头发和尾巴拼进一张 2048 的皮肤页，脸单独一张 2048。
- **面部 LOD。** 参照 mod 只换了面部的前两级 LOD。本案 8 级全换，镜头拉远时不会露出 Beta 的脸。
- **SkinInfo。** 修法相同：CsNbtGen 改为 VsNbt。参照 mod 只改了 625 和 109，本案 6 个部件全改。

## 已知限制

- 物理只是借用 Beta 原有的粒子：
  - 裙摆幅度小；
  - 双马尾和尾巴有层次地摆，但不是柔软的长链；
  - 其余头发和兽耳没有物理。
- 不会眨眼。
- 没有半透明叠加层（眼睛高光、腮红）。
- 身体 LOD1 及以上是原版：大约 80 米外可能显示 Beta 的身体。
- 未检查：对话中的口型、战斗、攀爬、游泳。
- **下一步要做真正的长链**，需要逆向 core 里的 PBD 资源：把发束链改长、挪到双马尾的位置，类似蜘蛛侠 2 写 AnimDynamics 段的做法。Odradek 有 HFW 的类型信息，可以作为起点。
