# Agent 入口（Horizon Forbidden West PC）

先读 [README](README.md)，再按当前问题进入对应文档。项目的当前状态在各自的项目目录里，不在这里；本目录只提供方法、数值快照和已被证伪的假设。

## 接手新任务前

1. **核对 build。** 查 Steam `appmanifest_2420110.acf` 的 `buildid`，本目录的快照是 `14835813`。build 变了，下面这些都要重新确认：
   - 组下标 `b2c4`；
   - 网格和贴图编号；
   - `patch_bounds.py` 里按原版数值查找的包围盒和 SkinInfo 计数。这个脚本找不到唯一匹配时会直接退出。
2. **准备干净根目录。** Pack Mods 之后，游戏目录里的流图已经是改过的。导出、导入和 Odradek 都要在一个指向原版流图的干净根目录里运行，做法见 [格式与工具](FORMATS_AND_TOOLS.md#干净根目录)。
3. **先跑复现基线。** 改构建脚本之前，先用旧输入重建，确认输出和上一版逐字节相同，见 [验证与发布](VALIDATION_AND_RELEASE.md#复现基线)。
4. **分清本版改什么。** 几何、权重、材质归属、core 补丁、打包这几类改动的验收口径不同。实机反馈常常同时涉及好几处，要逐项写清哪一项改了什么、用什么证据。

## 硬性规矩（本项目已付过学费）

- **改了顶点数的网格，凡是 SkinInfo 为 `CsNbtGen` 的，都要改成 `VsNbt`**（类型 7→5，`VertexComputeNbtCount` = -1）。漏改的表现是读档卡在黑底暂停菜单。
- **三角形绕序要翻转。** ascii 和游戏都是顺时针，glTF 是逆时针。漏翻的表现是从模型内侧看出去。
- **UV 写成 `v = 1 - v_glTF`。** ascii 的 UV 原点在左下角。
- **头发、兽耳不能放在面部皮肤材质上。** 面部着色器的次表面散射会把阴影里的头发染成棕红色。
- **隐藏子网格用塌缩。** 保留原版的顶点数和索引数，只把所有顶点放到同一点。这是 v2 起的写法，能稳定读档；v1 用的极小三角形和缺失的 SkinInfo 补丁同时出现，没有单独归因。
- **贴图槽尺寸固定。** 导入工具只替换同尺寸的 mip，所以颜色页的尺寸由槽位决定，不能自己选。
- **ascii 里不能出现小写的 `nan`。** 工具只认 `NaN`。写出前要保证数值有限。
- **导入工具最好在干净根目录里运行。** 教程的做法是直接在游戏的 `LocalCacheWinGame` 里运行。本项目改用干净根目录，这样工具产物不会混进游戏目录，Odradek 也能用；代价是要注意不能写入任何硬链接文件。
- **手指必须落在 Beta 的手指骨轴上**（`--hands rigid`，默认）。v4 用 TPS 拟合手指，手指偏离骨轴最多 0.94 cm，而且都偏向相邻手指；过场动画一弯手指，中指和无名指就交叉黏连。检查方法是 `hand_pose.py` 握拳姿势下的互穿顶点数，应为 0。
- **面部绑定的三条底线**（`face_hfw.py`）：
  - 上下唇按唇沿三角形的朝向分开采样。Karin 的嘴缝只有 0.04 cm，按高度区分会把两片唇混在一起，嘴就张不开。
  - 重合顶点必须共用一套权重，否则做表情时中线会裂开。
  - 眼周不接眼睑骨：Beta 的眼睑行程约 1 cm，套到大眼睛上只会抽动。
- **借用 PBD 粒子时，要沿部件长度铺到一条粒子链上**，不要整段挂在一两个粒子上；否则会整根刚性甩动，用户评价「太单一」。
- **h2 导出读的是游戏包，不是工作目录。** 把别人的 mod 文件放进工具目录再导出，得到的仍是原版网格，所以不能靠它查看参照 mod 的权重。
- **Windows Defender 会把 `h2_pc_mi_091.exe` 判为木马（`Wacatac.B!ml`）并删除或拦截它。** 是否放行由用户决定：关实时保护，或加排除项。agent 不得自行关闭防护。实时保护关掉后过一阵会自动恢复，导入前要再查一次。
- **不要声称实机通过。** 离线闸门全绿、复现基线一致，都只是 `offline-accepted`。

## 报告口径

每条结论要归入以下一类：`invariant`、`build-sensitive`、`case-derived`、`hypothesis`、`rejected`。

- 历史失败不删除。新证据只用来收窄旧结论的适用范围，并写明 supersedes 关系。
- 实机结果要绑定到所测包的 sha256。
- 要写明是谁测的：agent 自测和用户确认是两个证据等级。
