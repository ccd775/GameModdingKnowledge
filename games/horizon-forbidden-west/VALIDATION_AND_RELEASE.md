# 验证与发布

## 离线闸门

下面各项都检查最终写出的数据（ascii、core），不检查中间场景。

- **构建报告。** `build_hfw.py` 写出 `fit_report.json`，内容包括：剔除的三角形数、两只脚的抬升量、裙摆高度范围、两张页的缩放 / 块数 / 填充率、脸 / 上身 / 下身的顶点数。改了参数后，先和上一版逐项比较。
- **姿势预览。** `pose_preview.py` 用写出的 ascii 和导出的骨架，对 bind、手臂下垂、手臂上举、下蹲、转头这 5 个姿势做线性蒙皮，输出 OBJ。
  - 在 Blender 里从正、侧、背三个方向看肩、裙摆、尾巴，以及脸和颈的衔接；
  - 这一步能发现权重和拟合问题，发现不了着色、绕序、SkinInfo 问题。
- **握拳测试（`hand_pose.py`）。** 沿 Beta 各手指的屈曲轴（每根手指前三个关节所在平面的法线）弯曲手指，分 bind、放松、握拳三种姿势，对原版 Beta 的上身皮肤和各构建蒙皮。然后统计每根手指有多少顶点进入相邻手指的骨轴 0.45 cm 以内，并输出左手的 OBJ。
  - 合格标准：握拳时为 0，与原版相同；
  - v4 是 69（食-中 13、中-无名 22、无名-小 34），1.0.1 起为 0；
  - 能发现手指偏离骨轴的问题，这类问题只在过场动画里暴露。
- **面部测试（`face_pose.py`）。** 用测试增量驱动 719 的控制骨：下颌加下唇旋转、双唇分开、嘴角上提、额头上移、上眼睑下移。分别对 Beta 原脸（625 sm0）和构建的 lod0_625 蒙皮，输出带 UV 的 OBJ。
  - 合格标准：除眨眼外，两边的最大位移相近；Karin 眨眼时不动；正面渲染没有撕裂和折角；
  - 测试增量不是游戏动画，只能证明跟随的骨骼一致，不能代替实机验证。
- **导入计数。** `make_mod.py` 要求每个网格的 `success!` 行数等于子网格数，每张贴图至少替换了一级 mip；不满足就退出。
- **core 补丁。** `patch_bounds.py` 的每处查找都必须唯一命中，CsNbtGen 部件的类型必须是 7；不满足就退出，不写文件。
- **文件集合。** 输出应为 33 个文件：1 个 core、7 个贴图 stream、25 个网格 stream。和上一版比较文件名集合，多出或缺少文件说明组或 LOD 范围变了。

离线全部通过，只能算 `offline-accepted`。

## 实机测试方法

这是 agent 自测的流程，测完得到的是 `runtime-load-pass`，不等于用户验收。

1. **打包。** 关闭游戏，在 Mod Manager 里点 Pack Mods，关掉 `Packing Complete` 对话框。
   - 判断打包完成：看 `LocalCacheWinGame\package\mod\` 里文件的修改时间是否更新；
   - 管理器是 Qt 程序，用 pywinauto 按窗口标题找到对话框再关，比发按键可靠。
2. **启动。** 打开 `steam://rungameid/2420110`，会先出现启动器窗口。它属于同一个 `HorizonForbiddenWest.exe` 进程。点 Play 后，标题带版本号（`v1.5…`）的游戏窗口才会出现。
3. **按进程 id 找窗口，不要按标题。** 有一次，标题里带「Horizon Forbidden West」的终端窗口被误认成了游戏启动器。
4. **输入。** 游戏按帧轮询按键状态，AHK 这类很短的按键会被丢掉。要用扫描码 SendInput 按住约 120 ms（便携包的 `gamekey.py`），每次发送前确认游戏窗口在前台。
5. **读档。** 主菜单 → 继续 → 等待加载，然后截图（mss 截取可见桌面，游戏必须在前台且不被遮挡）。
6. **检查清单：**
   - 读档是否完成；卡在黑底暂停菜单说明有问题；
   - 正面、背面、侧面的外观；
   - 头发在阳光下和阴影里的颜色；
   - 奔跑和转身时的肩、裙摆、尾巴；
   - 拉远镜头后的脸。
7. **共用机器。** 同一台机器上常有其他会话在测别的游戏。抢前台前先确认没人在用屏幕；游戏失去焦点会自动暂停，按键也可能落到别的游戏里。
   - 各会话约定用一个锁文件 `%TEMP%\claude\game_foreground.lock` 协调前台：
     - 抢前台前先独占创建它，内容写「会话名 + 时间」；
     - 每轮输入不超过 60 秒，结束就删除；
     - 超过 60 秒没更新的锁视为失效。
   - 用户本人也可能在用电脑。如果前台是以管理员权限运行的窗口（例如任务管理器），非管理员进程发的鼠标键盘输入会被拦住，报 `no active desktop` 或 `target window did not become active`。这时不要硬抢，先问用户。
8. **管理器的按钮会随窗口大小移动。** 用户放大窗口后，Pack Mods 按钮从 (851, 903) 移到了 (1789, 1411)，点旧坐标不报错，但不会打包。每次点击前先截一张图确认坐标，点完以 `package.52.00.core.stream` 的修改时间更新为准。
9. **镜头和连拍。**
   - 读档后镜头可能朝天。可以用 SendInput 发相对鼠标位移来调整镜头的俯仰。
   - 看摆动要连拍：在按住移动键的同时按时间点截图，再按 4K 原图裁出角色区域来看，半尺寸的截图看不清。
10. **表情。** 暂停菜单 → 照片模式 → 相机页往下翻 → 面部表情，切换「集中注意」「胜利」「自发」等，裁出脸部对比。照片模式的镜头不跟鼠标转。

本案没有检查：对话中的口型、战斗、攀爬、游泳、远距离身体 LOD。过场动画只确认了手部（1.0.1，用户确认）。

## 发布

- **mod 包。** 33 个 mod 文件、`modinfo.json` 和 `preview.png` 平放在 zip 根目录，不套文件夹，这样能直接拖进 Mod Manager。
  - `modinfo.json` 的字段：`mod_name`、`author`、`version`、`priority`、`description`、`link`、`tags`；
  - 在 `description` 里写明不能和其他替换 Beta 的 mod 同时启用。
- **分发包。** 内容是：原样的 mod zip、`安装说明.txt`、几张预览图、`SHA256SUMS.txt`。
  - 说明文件用 UTF-8 带 BOM、CRLF 换行，Windows 记事本才能正确显示；
  - 压缩时要给文件名打 UTF-8 标志（例如 7-Zip 的 `-mcu=on`），否则中文文件名会按本地代码页存储，在别的系统上变成乱码；
  - 打完包要回读一遍，确认内层 mod zip 的哈希和实测版本一致。
- **对外分享时不打包第三方工具。** Mod Manager 体积约 245 MB，又是第三方工具，说明里只给 Nexus 链接。本案给用户本地的分发包附带了用户自己手里已有的 `加载器.rar`，那只是为了用户方便，不适用于公开分发。
- **版本更新。** 包名和 `modinfo.json` 的 `version` 一起改，`mod_name` 保持不变（例如 `Karin Original`）。这样新版本会落进同一个 mods 文件夹，覆盖旧版。安装说明里加「更新记录」，并同步改写「已知限制」和「已实机检查」两节。
- **许可。** 发布包含有从源模型转换出来的网格和贴图。公开分享前，先确认源模型的许可是否允许再分发；本库不收任何发布包。
