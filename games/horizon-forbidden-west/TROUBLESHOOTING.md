# 排障手册

## 症状定位

| 症状 | 先查 | 本案出现过的原因 |
| --- | --- | --- |
| 读档后停在黑底暂停菜单，菜单不响应 | 改了顶点数的网格里有没有 `CsNbtGen` SkinInfo | v1：面部网格顶点数变了，`VertexComputeNbtCount` 还是原版值 |
| 模型像从里面往外看，只看得到背面 | 三角形绕序 | v2：直接写入了 glTF 的逆时针绕序 |
| 阴影里的头发发红、发棕 | 头发是不是放在面部皮肤材质上 | v3：头发和兽耳在脸页上，面部着色器的次表面散射给它们染了色 |
| 贴图上下颠倒或错位 | UV 的 v 有没有翻转 | — |
| 镜头拉远后出现 Beta 的脸 | 面部 LOD 是否全部写入 | 参照 mod 只换了前两级 |
| 远处出现 Beta 的身体 | 身体 LOD1 及以上 | 本案的已知限制：身体只写 LOD0 |
| 进游戏还是原版角色 | Characters 是否 Activate；改动后是否重新 Pack Mods；mod 是否勾选 | — |
| 导入工具报 `Unhandled Exception`，或不认 ascii | 文件里有没有 `nan`；计数行和实际行数是否一致；开头有没有骨架 | — |
| `success!` 行数少于子网格数 | 子网格数和权重槽数是否和模板一致 | 早期计数时把 `Assets read success!` 也算进去了 |
| 贴图导入报 nothing replaced | DDS 的尺寸和格式是否与槽位一致 | — |
| Odradek 导出 cast 失败 | 游戏流图是否已被打包改写 | 改在干净根目录上运行 |
| 工具找不到资源 | 是否缺少 `streaming_graph.core.org` | 在干净根目录里补上这个文件的硬链接 |
| 工具 ID 对不上 | 用的是组 ID 还是组下标 | 8761 是组 ID，工具要的是下标 `b2c4` |
| 自动化按键没反应 | 按键是不是太短 | AHK 短按被游戏丢掉；改用扫描码按住 120 ms |
| 游戏自己暂停了，或按键进了别的游戏 | 是否有其他会话抢了前台 | 另一个会话在测别的游戏 |
| 管理器一启动就弹 `Failed to initialize offsets` | 游戏目录里有没有 Nukem 的 `winhttp.dll` | 无害，点确定即可 |

## 被否决的做法

- **按包围盒合并 UV 岛（`rejected`）。** 衣服和头发的岛在包围盒上大量重叠，合并后页的缩放只剩 0.51。改为按栅格化足迹合并。
- **把 Karin 的锁骨硬对齐到 Beta 的锁骨关节（`rejected`）。** Beta 的锁骨关节在身体中线的另一侧，对齐后锁骨区会对折。改为保留她自己的锁骨位置，只移动上臂根部。
- **按 z 高度切分上、下身（`rejected`）。** 手垂在腰部以下，会被分进只有 4 个权重的下身网格。改为按主导骨所属的身体分区切分。
- **头发放在面部皮肤材质上（`rejected`，v3 实机）。** 见上表。
- **用 AHK 的短按做游戏内自动化（`rejected`）。** 游戏收不到这种按键。

## 元教训

- **先对比参照物，再猜原因。** v1 卡死后，逐字段对比参照 mod 的 core 和原版 core，很快就找到了 SkinInfo 的改动。凭症状猜，很难猜到 GPU 端的计数。
- **一次只改一类东西。** v1→v2 同时改了 SkinInfo 补丁和隐藏子网格的写法（从删除改为塌缩），所以无法单独归因。下次遇到卡死，应该拆开测。
