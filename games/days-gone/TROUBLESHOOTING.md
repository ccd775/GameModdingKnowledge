# 排障手册

除标注外均为本项目实测。

## 1. 启动与加载

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 启动即崩，`SwapChain->ResizeTarget E_FAIL` | 显示模式取自 Bend 的 `VideoSettings=` 行，4K 独占在远程桌面的虚拟显示器上设不上（与 mod 无关） | 备份 `GameUserSettings.ini` 后改成窗口模式小分辨率（[开发工具](DEV_TOOLING.md) §4） |
| 游戏约 2 秒后退出，退出码 0、没有 dump | UE 4.11 编辑器正开着 `BendGame` 工程 | 先关编辑器 |
| Steam 说游戏已在运行 | 上次崩溃留下的「回報問題」窗口还开着 | 点「不要回報」 |
| 加载时 `LowLevelFatalError ... Invalid BufferCount=0 while reading .../MI_Karin_Face.uasset` | 带内联着色器图的 MI 的导出数据在文件里挪了位置（包头变长） | `retarget_inplace.py` 原地改字符串，包头大小不变 |
| 加载存档时崩溃、没有 dump、事件日志只有崩溃处理器记录 | 未查明；t29 首次启动出现一次，重开正常，之后没有再出现 | 记录；复现时先查 pak 与包头 |
| 加载时栈溢出崩溃（WER ucrtbase c0000005，dump 里同一返回地址重复 8 万次） | 新动画节点插在类字段链尾部，倒序索引错位，状态机姿势链接成环 | 插在链头（[技术合同](TECHNICAL_CONTRACTS.md) §8） |
| 进游戏几秒后变 A-pose | 数组里的 pose 链接（BlendPose 等）没有加 M | 所有深度的 `LinkID` 都加 M |
| 首次 cook 的网格引用自己导入时建的 `_Skeleton` | UE 导入 FBX 自建骨架 | `make_pak.py` 把骨架导入改指游戏的 `deacon_master_Skeleton` |

## 2. 外观

| 症状 | 原因 | 处理 |
| --- | --- | --- |
| 脸上鼻子 / 嘴周阴影发脏 | 导入时计算法线，VRM 自带法线丢失（与 VRM 法线平均点积 0.817） | `dump_loop_normals.py` + `skelmesh_normals.py` 原地写回（0.998） |
| 脸上有迪肯的毛孔 / 凹坑纹理 | 迪肯的材质贴图按他的头部 UV 画 | 换成空白的 `material_roughNonMetal_m`，皱纹贴图换空白 |
| 脸颊上有黑斑 | 藏在皮肤后的 VRM 表情道具在面部关节挤压时穿出来 | `face_rig.py` 删除皮肤后 > 0.5 cm 的道具 |
| 约 3 000 个身体角点法线和绕序相反 | 换装形状键烘焙 + 线性混合蒙皮后的拟合；都在衣服下面 | 不处理（看不到） |

## 3. 面部

| 症状 | 原因 | 处理 |
| --- | --- | --- |
| 眨眼时只有眉毛动，眼睛不闭 | Karin 的眼睑区落在 Head 权重上；迪肯眼睑只动 0.8 cm，Karin 要 3.9 cm | 眼睑骨 + 放大骨 + CopyBone（[面部](FACE_AND_LIPSYNC.md) §2） |
| BoneDrivenController 节点写进去了、游戏里没反应 | 本作里这个节点不执行（连常数位移都不生效） | 改用克隆的 CopyBone |
| 面部动画用 CUE4Parse 解出来全是常数 | per-track 压缩没被正确解码 | `anim_pertrack.py` |
| 对话时嘴几乎不动，下巴却在动 | 上下唇采到同一侧权重，迪肯的唇缝只有 0.1–0.7 cm | 按口型解嘴部权重（[面部](FACE_AND_LIPSYNC.md) §3） |
| 开心 / 使劲 / 伤心表情里 Karin 眯眼 | 眼睑映射线性、不截断，迪肯在这些情绪里眼睑低于睁眼值 | 已知副作用；要改就在 `blink_amp.py` 加截断或减小行程 |
| 改完面部权重后侧发 / 双马尾的顶点权重变了 | 「Head 下面的骨」包含 `KO_*` 头发物理骨 | 面部求解只用 `face_*`、`Jaw`、`lowerPalette_jnt`、`tongue*`，按材质限定区域 |
| Blender 预览里脸上有一块发白的面 | 预览按变形后的几何重算法线；游戏里法线随骨骼蒙皮 | 以轮廓为准，不用处理 |

## 4. 物理

| 症状 | 原因 | 处理 |
| --- | --- | --- |
| PhysX 链的限制 / 锁定 / 驱动全无效果 | 原因未查明（玩家网格上的额外刚体只保住关节位置） | 改走 AnimDynamics |
| 双马尾像钟摆 | AnimDynamics 的锥形限制只约束 X 轴，`KO_*` 骨沿 −Y | 逐骨单刚体节点 + 角度限制 |
| 狐尾垂在两腿之间 | 线性弹簧没有恢复力矩、开了重力 | 角度弹簧、重力 0 |
| 双马尾 / 狐尾抖 | 碰平面或碰限制来回弹 | 去掉不必要的平面、放宽限制、drag 12 |
| 蹲下时尾根附近的裙片快速抽动 | 无限大的大腿平面在大腿屈曲时变成臀下的水平面 | 朝后的件不挂大腿平面 |
| 跑步时裙子侧后方露出臀 / 大腿 | 大腿只推一片；臀部鼓起在平面推之前越过裙片 | 相邻片共享平面、平面贴紧、裙下皮肤内收 2 cm |
| 头发甩动幅度太大（尤其跑步） | 刚度低、限制宽 | 提高 omega、收紧限制（t31） |
| 照片模式里右侧双马尾被拉成一大片 | 未查明；正常游戏不出现 | 退出照片模式即恢复 |
