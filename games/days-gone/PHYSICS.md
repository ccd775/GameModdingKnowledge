# 物理

Karin 的 VRM 有 39 条 spring 链（双马尾、侧发、刘海、耳朵、狐尾、头饰 / 衣服丝带、裙摆 9 个位置共 16 条链）。它们作为 126 根网格专用骨 `KO_*`
进了头部网格（[技术合同](TECHNICAL_CONTRACTS.md) §5）。下面是两条路线：PhysX 刚体（否决）和动画蓝图里的逐骨 AnimDynamics（采用）。

## 1. 被否决：PhysX 物理资产里的额外刚体（t7 → t19，`rejected`）

- 先确认了机制：在 `deacon_master_PhysicsAsset2` 里把左前臂 / 左手设成 `PhysType_Simulated`，用户看到左前臂像布娃娃一样垂下、跟着动作甩
  → 玩家网格上逐刚体模拟是有的。
- `physchain.py` 克隆游戏的 LeftHand 刚体和 spine4←spine2 约束，给 `KO_*` 建了 91 个胶囊刚体 + 91 个约束（限制 + 朝向 / 速度驱动），
  调过：关重力、硬限制（`bSwingLimitSoft` / `bTwistLimitSoft` 在 Bend 的 UE 里默认是软的）、按重力倾斜的锥、按惯量算驱动、
  Karin 尺寸的碰撞体（迪肯的刚体比 Karin 大：头部胶囊伸出脸 4 cm、大腿半径 9.2 vs 6.5）、只对静止时间隙 ≥ 2 cm 的对开碰撞。
- 结论：**这些额外刚体只保住了关节位置**。角度限制、`ACM_Locked`、驱动（加大 100 倍）都看不出效果：锁死的双马尾横着支出去，
  双马尾扫过脸，耳朵拧着，裙摆垂进大腿。原因没找到（`BendDefaultPlayerPawn` 和 `Deacon_VimBlueprint` 里没有碰约束的蓝图调用，
  可能在 Bend 的原生代码里）。**不要再在玩家网格的 PhysX 约束上花时间。**
- 其它发现：VRM spring 的 `gravityPower` 全是 0，形状只靠刚度维持；之前给刚体开了重力。

## 2. AnimDynamics 的坑（UE 4.11 源码：AnimNode_AnimDynamics.cpp、AnimPhysicsSolver.cpp）

- t20 先把迪肯图里已有的 3 个 AnimDynamics（帽衫、包、包尾）改指双马尾和狐尾的链（`abp_dynamics.py`），能用但：
  - 线性弹簧把刚体质心拉向它自己的关节（原长 0、力过支点）→ **没有恢复力矩**，链在重力下只会垂（狐尾垂到两腿之间）；
  - 锥形限制只约束刚体的 X 轴；`KO_*` 骨沿 −Y 指向，绕 X 的摆动是自由的 → 双马尾像钟摆；
  - 链模式里第 2 个以后的刚体，角度弹簧目标和限制坐标系用的是组件空间 / 父刚体坐标系、静止偏移为单位 → 弯曲的链被拉直。
- 平面限制可用：平面挂在一根驱动骨的坐标系里，单侧，作用在质心或球上。

## 3. 采用：逐骨单刚体弹簧节点（`abp_springs.py`）

- **每根 `KO_*` 骨一个单刚体 AnimDynamics 节点**，从根到梢排列。单刚体节点把刚体钉在动画后的关节上，用动画骨的旋转作为角度限制和角度弹簧
  目标的坐标系；每个节点写回自己的骨，下一个节点读到的动画关节已经跟着上一节的模拟走了。
- 参数（每组一个配置，见便携包 `configs/springs_t31.json`）：
  - 刚度 `k = I_pivot · ω²`（盒子质量 1，`I_pivot` 绕支点的转动惯量），`omega` 可按段给列表；
  - 阻尼 `d = 1 − exp(−λ)` 同时作用在线动量和角动量上（绝对阻尼，类似 VRM 的 dragForce）；求解器在 float 里算 `(1 − d)^dt`，`λ` 超过约 13 就失真；
  - 角度限制 `limit`（度，按段给列表）；重力 0；
  - 平面：`radial`（法线 = 从一根竖直轴指向静止质心的水平方向，平面在质心减 margin 处；用于头、胸）和 `thigh`
    （法线 = 从大腿轴 UpLeg→Leg 指向静止质心，平面在 min(radius, 静止距离 − margin)；用于裙摆）；`neighbors` 让相邻两片裙子也受这片的平面推。
- 盒子尺寸默认 2 × 段长 × 2（`width` / `thick` 可改）、`com` 为质心沿骨的位置比例。
- 节点插入方法见 [技术合同](TECHNICAL_CONTRACTS.md) §8。

| t21 | 91 个逐骨节点首版（插在类链尾部） | 加载时栈溢出崩溃 → 插入规则（技术合同 §8） |

| t24 | 去掉双马尾的胸部平面，双马尾加硬 | 侧发好；耳朵可以再软 / 幅度大一点；狐尾好；双马尾经常有点抖；跑步时裙子侧后方张开（伸出的大腿推 6 号片但不推 5 号） |
| t25 | 裙摆大腿平面也用相邻片的法线；裙 omega 16/14/14；耳朵 13 / 12° / 8 | 耳朵好；跑步时侧后方内裤高度仍露肤（臀 / 大腿上部的鼓起在 9 cm 平面推之前就越过了）；双马尾还是抖 |
| t26 | 裙摆平面贴紧（静止距离 − 1 cm）；双马尾去掉平面、omega 10/8/7、drag 12、限制 8/12/12（怀疑抖动来自碰限制 / 平面） | 狐尾太抖；裙子同一位置还露（面积小了）；蹲下时尾根附近的裙片快速抽动 |
| t27 | 狐尾去平面；裙摆拆成前 / 侧 / 后三组；裙下身体皮肤内收最多 2 cm（`skirt_body_shrink.py`，GPU 缓冲原地改） | 「这几项都好了」 |
| t31 | 双马尾 omega 15/13/12、限制 5/7/7（整条最大约 40°，原约 68°）；侧发 omega 15、限制 5/7；头饰丝带 omega 11、限制 10/14 | 用户：头发甩动幅度太大（尤其跑步）→ 改后「看起来可以了」 |

规律：

- **抖动多半来自碰限制或碰平面**，不是阻尼不够；先去掉不必要的平面、放宽限制，再加阻尼。
- **平面是无限大的**：大腿屈到约 90° 时，朝后的大腿平面变成臀下的水平面，把后面的裙片和狐尾往下压向角度限制 → 蹲下时抽动。
  朝后的件不要挂大腿平面。
- 减小甩动幅度优先提高 omega（偏移大约按 1/ω² 变小），再适度收紧限制；drag 已接近上限。
