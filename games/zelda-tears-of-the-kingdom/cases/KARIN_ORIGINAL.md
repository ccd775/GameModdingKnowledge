# 案例：Karin_Original 替换 Armor_1061

- **游戏**：王国之泪 1.2.0，yuzu EA 4176，用户本机。
- **mod**：`00_Karin_Original`。
- **源模型**：Karin_Original FBX。
- **参照**：用户之前的 `03_kalin`（Karin PicodraTech 替换同一套 1061），它提供了基础模型和头盔 pack 的修改。
- **时间**：2026-11-02 → 11-03。

## 时间线

| 版本 | 改动 | 证据 |
| --- | --- | --- |
| v1 | 按段重定向；双马尾 → 后发，面颊发 → Hair_Side，裙摆 16 列 → 8 列；平滑矩阵表重建；贴图、图标、合并的 RESTBL | 实机：头正常；上衣、下装显示 03 的图集 |
| v2 | 材质改名，避开染色动画 | 实机：贴图正确；腰带下露肚子，大腿穿出裙子 |
| v3 | 裙摆按 Link 的裙骨段重新分权重，带一点大腿跟随，身体缩进裙内 | 用户确认裙摆没问题 |
| v4 | 嘴型和眉毛拟合到 Link 的面部骨骼；眼睛不动 | 离线 |
| v5 | 眼部用带符号、可大于 1 的浮点权重眨眼 | 用户：「眼睛会眨眼了」，浮点 / 负权重在实机生效 |
| v6 | 借头部 cloth：面颊发 → 鬓发，刘海 → 吊坠，狐耳 → 耳环吊坠（负权重）。用户的要求：耳朵、刘海、面颊发几乎不动 | 实机：狐耳移动时被放射状拉长 |
| v6b | 狐耳改借鬓发铰链，−0.2 | 用户：「现在狐耳不会放射状拉伸了，但是又有点不够灵活柔软了」，并且刘海走动后一直翘着 |
| v6c | 刘海全部改借鬓发；狐耳 −0.3，加后发负责前后摆 | 用户：「现在耳朵又会在跑动时放射状拉伸了」 |
| v6d | 狐耳去掉后发，只左右摆 | 用户：「可以了」，随后要求做安装包 |
| v7 | 头部缩放 1.30 → 1.40 | 用户：「karin的头是不是比原始模型要小不少？」；离线 |
| v7b | 头再下沉 1.8 cm（脖子） | 用户：「肩膀也比原来宽？脖子也比原本长一点」；离线 |
| v7c | 肩部压扁 0.5、大腿 / 小腿加粗 1.10 / 1.06 | 用户：参考 03 处理肩膀，「像是男性健壮的体格了」，「腿好像也比模型本身更细」；离线。03 其实没有处理肩膀，见 [重定向与比例](../RETARGET_AND_PROPORTIONS.md) §4 |
| 安装包 v7c | Full / Lite、安装器、存档工具 | 模拟环境端到端测试；快照时 v7c 还没装到用户机器上（安装时模拟器正在运行） |

v7c 的模型哈希（sha256 前 8 位）：头 `04e074eb`、上衣 `31304250`、下装 `9c712ec1`。
