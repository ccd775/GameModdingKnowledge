# 角色替换

两条路线都替换同一组 74 个资源（见[技术合同](TECHNICAL_CONTRACTS.md) §4）：可见几何在 D462 sub0（头）、651 sub10 / sub6（上身 / 下身）和 8DC sub5 / sub7，其余子网格以及 4BA / 324 / 627 全部塌缩隐藏。

## 1. 修复一个现成的 mod（Karin_Picodra 路线）

### 1.1 盘点

1. 逐文件比对 mod 与游戏原文件：是否相同、是否常量、格式 / 尺寸 / mip、存储标志。
2. 用 `ktdata.py slots` 解出每个被替换模型的槽表；运行时 alias 另查（[材质与贴图](MATERIALS_AND_TEXTURES.md) §3）。
3. 用 `ktdata.py usage` 查每张覆盖贴图还有谁在用。别人在用、Karin 可见部分不用的，恢复原字节。
4. 用 `g1m_tool.py info` / `check-binds` 看每个子网格：是否隐藏、调色板、绑定是否原生。
   - 在 G1MG 内部逐分节、逐顶点缓冲比较，比整文件哈希更能说明改了什么。

### 1.2 头部

- 用源材质的 UV 重建头模型 D462，头部效果被用户认可。
- 头部图集按正确的 tile 布局重排，mip 链保持一致，每级 mip 往返逐字节验证。
- 脸部源法线与游戏法线基本一致（最大角误差 0.216°，口腔 0.034°）。之后不要再随意改嘴部法线或位置。
- 下巴下方的暗块是图集问题：皮肤在嘴下戛然而止，下颌位置画的是白蓝色头发。只重画了 507 个下巴三角形对应的纹素。

### 1.3 上衣 UV（e 版）

- 拟合源模型的胸部 / 领口（Body_006）和外套躯干（Body_001）的几何表面，加上法线方向约束和 UV 岛连续性检查，定位原材质的 UV。
- 把这两块移到图集里没用到的两个独立区域。
- 回读确认：上衣除 UV 外的所有顶点属性、下身的全部顶点属性和材质槽都不变；背标相关的面被排除，原压缩块保留。

### 1.4 手（f 版）

- 症状：手指完全不随动画。左右手各 1880 个顶点，没有一个受独立手指骨影响，全部绑在前臂辅助骨 103 / 105 / 131 和 104 / 106 / 132 上；上衣调色板缺手腕 21 / 22 和五指 27–64。
- 拓扑映射：
  - 从指甲附近的皮肤种子出发，沿三角形邻接找回整只手；两侧各 3080 面、1549 个焊接顶点完整匹配，零冲突；
  - mod 的两只手都是源模型左手的镜像，不能直接套用源模型右手的三角化。
- r1：在 651 独占的上衣调色板里补入 32 根原生手腕 / 手指骨，绑定矩阵从原版 4BA 复制（先核对骨架一致）。
  - 只改 4770 个皮肤 / 指甲顶点的权重和索引；前臂边界按源模型 LowerArm 权重保留原有的辅助骨混合。
  - 实机：手指会弯了，但部分指尖绕错了位置。
- r2：用完整拓扑和源权重解 17 组局部仿射，估计 mod 手指的实际关节位置，再把 30 根指骨的逆绑定刚性地校准过去，不做整手缩放。用户认可。
  - 原始顶点不变，不等于渲染出的手形不变：逆绑定校准会改变手指的静止姿态。
- 20260916a 右手：
  - 左手已经改善，右手掌心仍是原生绑定，而指根经过了校准，两者在关节处相差 3.4–5.2 个单位；
  - 用两侧加权仿射拟合加原生骨架的镜像关系，把左手的局部绑定传到右手掌心和 15 根指骨，左手逐字节保持。
  - 用户尚未验收。
- 不要用整手仿射或 ICP 最近点混合不同手指，那个实验误差很大，已删除。
- 8DC 的手没有修：它的绑定约定不同，见 [AGENTS](AGENTS.md)。

### 1.5 膝盖（g 版）

- 症状：深屈膝时出现几何尖刺。
- 原因一：下身权重之和在 0.7356–1.2381 之间。
  - 整腿归一化后实机变暗，没有采用；
  - 最终只在 y −37…−57 内完整归一化，−27…−37 和 −57…−70 平滑过渡，区间外字节不变。
- 原因二：4BA / 324 / 627 / 651 / 8DC 里共有 60 个原版 3 顶点占位面，仍引用不同顶点、带不同权重，动画下可能有面积。
  - 塌缩成同一个索引后，近景、深屈膝和站立的下身亮度都恢复了，说明额外的遮挡来自这些面。
  - 便携包对应 `g1m_tool.py collapse-placeholders`。

### 1.6 腿与脚（20261004a）

- 症状：跑步时两条小腿互相穿插，脚的姿态不对。
- 原因：651 下身膝盖以下全部绑在小腿辅助骨 89 / 90 上，8DC 下身则全部绑在膝骨 5 / 6 上。
  - 离线把脚踝骨弯 35°，旧版的脚位移为 0。
- 修法：`leg_weights.py`。
  1. `reference`：从原版 4BA（踝以上）和 324 / 627（踝以下）取出每个顶点的绑定位置和腿链权重。
  2. `apply`：对每个顶点，非腿部的权重原样保留（髋 2、尾巴、布料骨）；腿部的总量按最近 6 个原版顶点的分配重新分到腿链上。
     - 踝附近（y −86…−91）从基础身体平滑过渡到绑腿；
     - 新增的骨用原生绑定。
  3. 8DC 用自己的骨架：顶点先按自身权重逐骨映射到 651 空间，再查参考。
  4. `check`：只允许混合字节、调色板、MM1G / FM1G 变化；存下的权重之和为 1；新绑定是原生的；静止姿态偏移很小（651 0.002、8DC 0.0065）；弯脚踝时脚会跟着动。
- 离线姿势里有一些拉伸指标变差（8DC 深蹲最大边长倍率 8.7 → 16.3，651 走路 p99.9 4.40 → 5.28）。离线 FK 把辅助骨当成父骨的刚性子骨，而游戏会给它们单独的动画，所以这些数字只是保守的提示，以实机为准。

## 2. 从源模型构建（Karin_Original 路线）

### 2.1 输入与模板

- 模板 = Picodra 20260916a（74 项）。只换 6 个文件：
  - D462 / 651 / 8DC 三个 G1M；
  - `0x97338C5A`（头）、`0x4230A92D`（上身）、`0xC946E4AF`（下身）三张颜色图。
  - 其余 65 张贴图沿用模板，审计确认它们是常量，或属于隐藏部件。
- 源：FBX（同目录有 VRM），10 个网格、约 4.5 万个三角形，T 字姿势，身高 1.35 m。
  - 各段比例与游戏骨架差别很大：腿约 ×152，手臂 ×121–134，躯干 ×200。
- 在 Blender 4.0.2 后台导出：形态键按预制体里的值应用，按 corner 的法线，8 骨权重，内嵌贴图。
  - 这台机器上同步盘里的 4.2.23 便携版缺 DLL，无法运行。

### 2.2 贴合与权重

- 每根映射骨建立一个「源静止帧 → 游戏绑定帧」的仿射：
  - 用最小旋转对齐骨的方向，沿骨轴按段长缩放，截面统一缩放；
  - 没有映射的骨跟随最近的已映射祖先；
  - 按源权重做 LBS 混合。
- 映射：人形骨映射到游戏主骨（髋 2、脊柱 9、胸 10 / 11、颈 12 / 13、头 14、肩 15 / 16、上臂 17 / 18、前臂 19 / 20、手 21 / 22、五指链、大腿 3 / 4、小腿 5 / 6、脚 7 / 8、脚尖 25 / 26）。
  - 头发和耳朵 → 14，尾巴 → 2；
  - 裙摆按髋和大腿混合；
  - 身体截断到 8 个影响、头截断到 4 个，再归一化。
- 之后再把腿部权重按原版分到辅助骨上（§1.6 的同一方法，在构建脚本里完成）。
- 8DC 用它自己的骨架单独贴合。
  - 8DC 身体锚定在「651 的骨 12 + 8DC 骨 14 相对 651 的偏移」上，这样同一个按 651 做的头在两套身体上都能接上。
- 实机反馈中学到的几条：
  - **袖子只能跟前臂。** 套头衫有三分之一的权重在手骨上，袖子被手腕扭转，长屋里的「绑腿」其实是这个。
  - **挂脖绳（underwear 网格）** 要和身体、套头衫用同一个颈部场，否则会脱离。
  - **裙摆**跟随 0.75 + 下摆外扩 1.5。离线姿势会低估实机跨步时的穿出。
- 写回：
  - 权重量化到 2^-11；
  - 切线 w 按 Picodra 模板的约定：顶部原点的 UV 中，w·cross(N,T) 指向 −v。原版 D462 的 T 沿 −v 存储；
  - 651 和 8DC 的部件顶点顺序不同，合并时的键里要加上贴合后的法线。

### 2.3 分件与贴图

- 头 = 脸 + 头发 + 狐耳；下身 = 裙子 + 长袜 + 鞋 + 尾巴 + 下半身皮肤；上身 = 其余部分。
- 每件收集 UV 岛，带边距装箱到 2048 的图集。
- 颜色图用 texconv 编成 BC1 + 全部 mip，再排成 64 KB tile，套用模板 G1T 的头，只改尺寸和 mip。最后解码回读核对。
- BC1 没有透明通道：带 Alpha 的部件先检视，再决定保留还是删掉。
- 已认可的模板头部贴图左右两半不同，这也说明「折叠不变量」是误读。

### 2.4 头部：玩家的头始终在

- 原版 D462 是包在玩家捏脸头外面的头巾。新头必须把头巾表面前后都包住（包括眼洞），否则会露出真脸或后颈。
- Karin 的颅骨深 24，头巾深 26。只往前移能盖住脸，但后颈会露出来。
- 加深 1.3 倍再前移 4（20261001b）在实机里显得「被拉长、头扁」，后颈仍然可见，被否决。
- 度量：从 24 个视角统计玩家头露在 Karin 外面的面积。
  - 20261001b 为 748，其中脖子占 714；
  - Picodra 模板为 58（长发盖住后颈）；
  - Karin 原头为 2165。
- 最终出两个变体，用户要求两个都做：

| 变体 | 做法 | 代价 |
| --- | --- | --- |
| hidehead | 清空女性捏脸头 `0xB24CAC84`（`g1m_tool.py hide --all`），Karin 头颈保持原样 | 不戴头巾时没有头；男性角色要清空 `0x1249DB5D` |
| wrap | 保留玩家的头；头等比放大 1.1、前移 3.5、下移 1.5，脖子按玩家脖子的位置外推（y 44–58，余量 0.4，最多 4.7） | 头大约 10%，脖子明显变粗；露出面积 651 为 0.4、8DC 为 2.0 |

- 两个变体都经过 agent 实机自测：装备界面正面和游戏中的背后视角都看不到原角色。

### 2.5 已知限制（两条路线共有）

- 没有表情和眨眼。
- 头发、尾巴、裙摆是刚性的，没有物理，大动作时可能和腿穿插。
- 局部刀柄穿模。
- 进室内时小腿出现原版绑腿：怀疑是脱鞋后的腿部装备 `0x8D74E8C2`，需要游戏数据才能清空并实测。
- Original round 1 时胯部有一条蓝白带子，不在这 6 个模型里。怀疑是装备部件，未解决。
