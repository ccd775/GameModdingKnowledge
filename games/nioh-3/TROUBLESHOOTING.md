# 排障手册

除标注外均为本项目在 v2.0.0.2 上的实测。buildN 指 [Karin 案例](cases/KARIN_ORIGINAL.md) 的版本，lenkoN 指 [Lenko 案例](cases/LENKO.md)，ichelN 指 [伊切尔案例](cases/ICHEL.md)。

## 1. 物理

| 症状 | 原因 | 处理 |
| --- | --- | --- |
| 标题画面里耳朵、裙子被重力拉歪但几乎不动，关卡里完全没有物理（build9f、build11） | type-4 条目没有对应的 MESH_LOD 类型 2 网格组 | 每个条目 k 一个类型 2 组（NUN id `0x2710 + k`），指向这个条目自己的网格（[物理](PHYSICS.md) §2） |
| 放进类型 2 组的部件（裙子、耳朵、双马尾、尾巴、丝带）在标题画面和关卡里都不显示（build12） | 类型 2 子网格和原部件共用顶点缓冲 / 调色板 | 每个条目一个独立网格：自己的顶点缓冲、属性集、调色板、索引缓冲、子网格 |
| 独立网格 + 注册表，仍然不显示（build13–15） | 每材质计数没有覆盖新的类型 2 网格 | 计数等于实际子网格数；不要把原版子网格挪到别的材质 |
| 部件都显示，完全没有物理（build19） | 注册了条目，但网格是类型 0 | 类型 2 组、独立网格、注册表、计数四样都要有 |
| 忍者裙子只显示一半，武士完整（build20） | 计数按子网格下标顺序分段；新网格追加在原版材质 1 / 2 的子网格之后，右半边裙子落进了材质 1 的段 | 新网格插在最后一个原版材质 0 子网格之后，每个材质的子网格连续（build21） |
| 尾巴沿重力耷拉在两腿之间；武士裙子沿重力下垂，臀部和大腿穿出裙片（build20） | 用了腰带垂饰的参数模板，是纯摆锤 | 改用头发模板，保持建模时的形状（build21，[物理](PHYSICS.md) §3.3） |
| 前倾弯腰下劈这类大动作时，身后臀部的皮肤略微穿出裙片（build23） | 借来的腿部碰撞组按原版身体做，Karin 的臀部更高更翘，留了约 4 cm 空档 | 裙摆单独一组碰撞体，加两个按 Karin 臀部拟合的椭球（build24，待实机，[物理](PHYSICS.md) §4.3） |
| 忍者裙摆不显示（build9f 第一、二版） | 放在子网格 1，那是戴手甲时隐藏的空手；改 MESH_LOD 组名也没用 | 换到子网格 2（原围巾布料）；build20 起裙子是新子网格 |
| 短裙正前方鼓起一块（lenko1） | 借来的 `legs` 组按原版身体做，比她大得多，前片裙链静止时就在椭球里（r 0.64–0.66），被推出去 | 按角色重新拟合整组碰撞体（[物理](PHYSICS.md) §4.4） |
| 领带始终翘起悬空（lenko1） | 腰带垂饰模板是纯摆锤，领带从领结竖直下垂；借来的 `torso` 组有个约 25 cm 的大球，在她肚子前鼓出十几厘米，领带搭在上面 | 头发模板保持建模形状，碰撞换成按她拟合的组 |
| 长发整块在动（lenko1） | PMX 长发每节约 12 cm，用的是短发参数，静止时还卡在 `head` 组的长条椭球里 | 每节切到 ≤ 4.5 cm、权重按位置重分，换原版长发参数和上背椭球（[物理](PHYSICS.md) §3.5） |
| 外层布（外套）下摆被内层布（短裙）穿出，静止时两层隔 1.7 cm 以上（lenko2） | 两层各用一套链，游戏不计算布和布之间的碰撞 | 外层不要自己的链，取内层最近表面点的权重（[物理](PHYSICS.md) §5.1） |
| 外套背后臀部附近鼓起一块（lenko3） | 不是物理：模型本来的静止形状（背面离短裙 4–7 cm，臀下再往外跨一级），外套放长后露出来 | 先按截图角度渲染贴合后的静止姿势确认；背面按格往里收到最里层离短裙 1.5 cm（[物理](PHYSICS.md) §5.2） |

## 2. 崩溃

| 症状 | 原因 | 处理 |
| --- | --- | --- |
| 主菜单载入角色时崩溃 0xC0000005（build9p 第一版） | FM1G 的 type-4 统计（+276 … +332）留了 0 | 按条目、点、链、LLOC 列表、挂接块填统计（[物理](PHYSICS.md) §1.3） |
| 载入角色即崩溃，`Nioh3.exe` RVA `0x195297`（build16–18） | 每材质计数比实际子网格多 1–2 个，读到空的槽位指针 | 计数等于实际值（[技术合同](TECHNICAL_CONTRACTS.md) §5） |

## 3. 材质与贴图

| 症状 | 原因 | 处理 |
| --- | --- | --- |
| 改了颜色贴图没变化（build2 / 3） | 运行时用的是染色变体 `0x411dc165`，`0x8b541440` 启动时根本没被读 | ETW 追踪确认读了哪张，再改（[材质与贴图](MATERIALS_AND_TEXTURES.md) §2） |
| 武士流派仍显示盔甲花纹（build8 第一版） | 只改了静态 KTID 和两张变体，运行时用的是第三张变体 | ETW + `find_variant.py` 找当前 COLOR → `alias_ktid.py --tex` → `raw_ref.py` 找变体 KTID |
| 手臂是紫色网眼袖子的贴图（build4） | 子网格只改了 shader / material，没改 +12 的运行时材质组 | 三个字段一起改 |
| 嘴部出现「牙齿框」和边缘虚线（build5 / 6） | 原版 DIRT（AO 图）按 Karin 的 UV 采样；改静态 KTID 无效 | 在变体 KTID 里把 DIRT 指向白色默认贴图 |
| 武士流派裙摆整片橙红，忍者正常（build11 起） | 未查清（顶点数据逐字节相同） | 未解决，见 [材质与贴图](MATERIALS_AND_TEXTURES.md) §6 |

## 4. 几何与权重

| 症状 | 原因 | 处理 |
| --- | --- | --- |
| 袖口被拉长（build4） | 合并手指权重到前臂时按骨号奇偶判断左右，**左手手指是偶数**，474 个顶点并到了另一侧 | 按骨架父子链判断左右，跨侧检查强制为 0 |
| 大腿上的袜子漏肉（build21） | 袜子里面的大腿皮肤在大动作下穿出 | 用源模型的换装形态键把袜子里的皮肤收进去 |
| 袜子末端能看见锥形（build22） | 整个 `kisekae_UppeLeg 2` 应用后，袜口那一圈（z 0.523–0.525，袜口 0.524）也被收进去了；袜口上方 0.543 那圈不动，露在外面的皮肤成了往袜子里收的锥形 | 按源模型高度遮罩：z ≥ 0.515 权重 0，z ≤ 0.49 权重 1，中间线性（build23） |

教训：换装形态键可能一直作用到衣服的开口处。**开口那一圈永远不能动**，只收开口以内、被衣服完全盖住的部分。

## 5. 工具与测试机

| 症状 | 原因 | 处理 |
| --- | --- | --- |
| `ktdata.py` 解某些模型报 "metadata differs" | 类型 `0x563BDEF1` 的部分记录在 `root.rdb` 里记的是压缩后的大小（都是坐骑 / 道具） | 改用 fdata 条目头里的大小（`extract_many.py`） |
| 上传后文件出现在 `build2$(basename …` 这样的目录 | 远端路径里的反斜杠加 `$` 被 shell 转义成字面量 | 远端路径一律写正斜杠 |
| 截图或大文件传输后，所有远程会话卡住几分钟 | 远程隧道带宽很小，单次传输超过约 2–3 MB 就会卡住 | 截图在远端转 JPEG 再拉回；大文件分块传 |
| 桌面动作被别的窗口抢走（`focus Nioh` 抢到了别的游戏的资源管理器窗口） | 标题片段不唯一 | 用 `focus Nioh 3` 这样唯一的片段 |
| 改好的存档进游戏后没生效；游戏退出时提示「尚未保存的游戏进度将会遗失」 | 退出游戏不存档 | 神社菜单按 K「保存」或快速旅行后再退出（[存档与外观设置](SAVE_AND_APPEARANCE.md) §6） |
| 参拜神社、照镜子按 E 没反应 | 游戏内交互要按住，瞬时按键不认 | `down e` → 等约 600 ms → `up e`；菜单里单击就行 |
| 打包脚本中途报错，发布目录被清空、手写的 README 丢了（Lenko 时两次） | 脚本先 rmtree 整个发布目录；有个 shell 的工作目录还在里面，目录本身删不掉，报错时内容已经删光 | 只清空目录里的内容，不删目录本身；先把手写文件备份到目录外；看完发布目录就把 shell 的工作目录移出去 |
| 远程桌面里 Win+R、Ctrl+V 这类组合键不起作用，单键和鼠标正常（ichel1 那天） | 原因未查 | 用临时计划任务在用户会话里启动程序（[伊切尔](cases/ICHEL.md) §5） |
| 分块上传到一半，分块不见了 | 另一个会话也在用这台测试机，分块上传共用同一个远端临时目录，对方的上传把它清掉了 | 每个会话用自己的远端临时目录，等对方传完再传 |
| 用 sed 批量改脚本里的版本路径，结果某个变量指向了错的目录 | 连续替换互相影响：先把 2 改成 3，再把行尾的 3 改成 4，旧包路径也被改掉了 | 改完逐行核对关键变量；脚本开头先检查源目录存在 |

## 6. 存档与外观

| 症状 | 原因 | 处理 |
| --- | --- | --- |
| 换了护甲以后 Karin 不见了，只剩一件衣服（或缺头缺身体） | 画面按外观设置显示；胸甲的外观不是 Karin 所在的那两个模型 | 换装器 `apply`，或在镜子「整理仪容 → 外观设置」里选回（[存档与外观设置](SAVE_AND_APPEARANCE.md) §4） |
| 改了背包物品 +2（transmogItemId）后画面不变 | 这个字段不决定画面 | 改外观设置记录 `0xCE1DB6CF` |
| 改了背包 +0xE8 / +0xEC 的装备位，进游戏装备还是原来那套 | 那是缓存，载入时按装备表 `0x6B52DB66` 重建 | 不要靠改存档换装备；外观用外观设置 |

## 7. 表情

| 症状 | 原因 | 处理 |
| --- | --- | --- |
| 眨眼时上睫毛线往下掉，眼睛没盖住（用户说成「眉毛落下」，lenko1） | 源模型的まばたき要把下眼睑往上合，游戏的下眼睑骨几乎不动，非负拟合做不出 | 拟合前把闭合线下移到下缘原来的位置（[表情](FACE.md) §2.2） |

## 8. 已被否定的假设

- 「双马尾跑动时向后飘，物理在跑」（build9f 时 agent 的记录）：低分辨率跑动截图里的是动画。物理当时只在标题画面模拟。
- 「部件不显示是因为 type-4 id 太大（100–121）」：build14 把 id 改成小而连续的一段，build15 仍不显示；真正的原因是计数（build20 证实）。
- 「计数调高到覆盖类型 2 网格就能显示」：调高后载入角色就崩溃（build16–18）。
- 「臀部穿出裙片是蒙皮问题」：臀部皮肤 80–90% 绑在胯骨上，屈髋时线性蒙皮只会往里收；原因在碰撞体（build24）。
- 「角色必须穿射手装束胸甲 / Irregular Troop's Cuirass，Karin 才会显示」：决定画面的是外观设置，测试存档本来就设了外观（2026-11-02，[存档与外观设置](SAVE_AND_APPEARANCE.md) §1）。
- 「背包物品 +2 的 transmogItemId 就是幻化」：游戏保留这个值但不按它显示（第一版换装器写的就是它）。
- 「静止时两层布隔开 2 cm 就不会穿插」：两套链各自摆照样穿（lenko2）。
- 「关卡里眨眼闭不上是背面剔除、构建写错或图集 UV 越界」：三项都离线排除了（lenko2 → 3），差别在闭眼姿势组。
- 「外套背后鼓起是物理把它推出去的」：静止形状本来就这样（lenko3 → 4）。
- 「背后鼓包来自连着蝴蝶结、长丝带的两条长短裙链」：这两条只带外套左侧（方位 20–100°），背后跟的是普通裙链。
