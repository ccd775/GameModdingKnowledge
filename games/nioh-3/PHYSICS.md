# 次级物理（NUNO type-4 骨链，v2.0.0.2）

读：`nuno4.py`；写：`n3build/n3_g1m_physics.py`（由 `n3_build_g1m.py --physics --collide` 调用）；外部资源：`n3build/n3_registry.py`。
格式是在原版头发、额饰、腰腿流苏、铠甲样本上逆向出来的。gust_stuff 解析 ONUN 时跳过 type 4。

## 1. 格式

### 1.1 ONUN

- `[I]` ONUN = NUNO，版本 `0036`。子块 `0x30004` = 骨链（头发、流苏、腰带垂饰、藤蔓都用它），`0x30005` = 布料（gust 能解），`0x30006` = 未知（每个带物理的模型都有）。
- `[I]` type-4 条目（字节偏移）：

| 偏移 | 内容 |
| --- | --- |
| +0 | 挂接骨号 |
| +4 / +8 | 点数 / 链数 |
| +12 | A（1 或 2，后面 LLOC 组下标的个数） |
| +16 / +20 | 点数 / 链数（重复） |
| +24 | id |
| +28 … +196 | 固定参数块（42 个字，直接抄原版模板，见 §3.3） |
| 之后 | 每条链的起点下标；每条链的根坐标系（3×3，第 0 行 = 链方向）；每个点 `(xyz, 1)`、`链号 \| 0x80000000（链根）`、沿链归一化位置 t、到上一点的距离；A 个 LLOC 组下标；每点 `(点号, 骨架存储序号)`；每条链的挂接块 `(起点, 3 \| ((16 + 8n) << 16), 4, n, n × (骨号, 权重))` |

- `[I]` 多链条目：相邻的链共用顶点时放进一个条目（原版头发每个条目 1–8 条链，挂接骨相同）。每条链有自己的起点、根坐标系和挂接块；t 在每条链上从 0 到 1。
- `[I]` type-4 的 id 与 type-5 布料的 entryID 在同一个命名空间（武士上衣的布料已占 2、3）。远端 430 个原版模型里 type-4 id 0–25、在每个模型内连续，type-5 id 0–50。
  `[C]` 本案例用忍者 21–43、武士 4–26，避开模型自己的 type-5 id。

### 1.2 关节（SM1G）

- `[I]` 物理关节是普通 SM1G 关节，全部直接挂在挂接骨下：世界位置 = 链上的点，局部 x 轴指向下一点（最后一个关节沿用前一个的朝向）。
  调色板像普通骨一样引用它们，MM1G 用原生逆绑定。骨号接在模型已有的骨号空间之后（原版头发 953–1300）。
- `[I]` SM1G 头：`+16 u16 1, +18 u16 0, +20 u16 关节数, +22 u16 骨号表长, +24 u32 组数`。骨号表之后是组表（u16：基础组最后一个存储序号，然后每个 type-4 条目的点数 − 1，
  与条目顺序一一对应），对齐到 4 字节后是关节（48 字节：缩放 3f、父 i32、四元数 xyzw、位置 3f、1.0）。

### 1.3 FM1G 统计

`+12` = 组数（1 + type-4 条目数，与 SM1G +24 相同），`+16` = 关节数，`+136` = 骨号空间，`+96 / +100` = LLOC 组数 / 碰撞体总数。type-4 统计（三个原版样本全部吻合）：

| 偏移 | 内容 |
| --- | --- |
| +276 | 条目数 |
| +280 / +292 | 点数 |
| +284 / +328 | 链数 |
| +288 | LLOC 列表的字数 |
| +320 | 156 × 条目数 |
| +332 | 挂接块字节数 |

`[I]` 这些统计留 0 时，主菜单载入角色就崩溃（0xC0000005，build9p 第一版）。

## 2. 让骨链在关节里真的模拟

四样东西缺一样都不行。这是 build9 → build21 用 12 个构建换来的：

1. **模型里的 type-4 条目、关节和 FM1G 统计**（§1）。只有这一项时，**只有标题画面在模拟**，关卡里完全不动（build9f、build11）。
2. **每个 type-4 条目 k 有一个 MESH_LOD 类型 2 网格组**，NUN id = `0x2710 + k`（k 是 ONUN 里的顺序，不是条目 id），指向这个条目自己的网格。
   - 原版（头发 18 组、额饰 4 组、腰腿 2 组）每组的子网格都有**自己的**顶点缓冲和调色板。调色板只含本条目的全部关节（含无权重的末端）和普通骨。
   - 和别的部件共用顶点缓冲 / 调色板的类型 2 子网格完全不画（build12：裙子、耳朵、双马尾、尾巴、丝带全部消失）。
   - 一个三角形的角上有链权重时，归到加权和最大的那个条目。
3. **装备的物理注册表**列出全部 type-4 条目（[技术合同](TECHNICAL_CONTRACTS.md) §5）。
4. **每材质计数和模型完全一致**，每个材质的子网格连续。
   - 计数不够：类型 2 网格不画（build13–15）。
   - 计数多了：载入角色即崩溃（build16–18）。
   - 原版子网格挪到别的材质：留下被计数却没有子网格的材质，同样不行。
   - 只注册、网格仍是类型 0：完全不动（build19）。

`[C]` 原版有一件同款、带类型 2 物理的上衣 `0xa2fd65db` 可以对照：材质 0 = 布料（类型 1）+ 主体 + 两个类型 2 网格，计数 (4, 1) 与实际相等，注册表的 type-4 是 (0, 30) (1, 31)。

build20 起的做法（[技术合同](TECHNICAL_CONTRACTS.md) §3.4）：原版子网格全部保留，Karin 的部件和 23 个物理条目都作为新子网格插在材质 0 的末尾，计数等于实际值。
build20 关卡里第一次有物理；build21 修正了子网格的连续性，用户实机确认。

## 3. Karin 的骨链

### 3.1 从 VRM 弹簧链生成（build11 起，`n3_physics.py` 默认模式）

- Karin 的 VRM 里有 39 条 `VRMC_springBone` 弹簧链（由 PhysBone 转换），导出的 `source.json` 有全部骨骼和权重
  （VRM 节点名里的 `.` 和空格在 FBX 里变成 `_`）。用了 37 条，跳过脸颊的 2 条（会和表情冲突）：

| 部位 | 链数 × 点数 | 挂接骨 |
| --- | --- | --- |
| 双马尾 | 2 × 7 | 头 12 |
| 侧发 | 2 × 4 | 头 12 |
| 刘海 | 3（3、2、2 点） | 头 12 |
| 头上的丝带 | 2 × 3 | 头 12 |
| 耳朵 | 2 × 3 | 头 12 |
| 尾巴 | 1 × 7 | 胯 2 |
| 裙摆 | 16 × 4（合成一个多链条目） | 胯 2 |
| 吊带丝带 | 2 | 胸 10（父骨是 Neck，也挂胸） |
| 上衣丝带 | 2 × 2 | 胸 10 |
| 袖口丝带 | 4 × 2 | 前臂 17 / 18（袖子本来不跟手） |
| 鞋标 | 2 × 2 | 脚 7 / 8 |

- 链上的点 = 每根弹簧骨的骨骼头 + 末端。用这根骨自己的顶点（权重 ≥ 0.3）做「源 → 贴合后」的仿射拟合（顶点分布太扁时退回相似变换），把点映射到游戏空间，所以贴合时的变形也被跟随
  （尾巴、袖口误差 0；裙摆因贴合外推，下摆误差 ≤ 0.26 cm）。
- 权重：第 i 个关节取第 i 根弹簧骨的源权重；顶点剩下的权重按贴合后的游戏骨等比保留。
- 挂接骨 = 链根的父骨对应的游戏骨。
- 关节一共 130 个，超过 85 的调色板用 u16 骨骼索引（主体 107 项）。
- `--geometry` 模式（build9）按几何形状推出 11 条链（双马尾、尾巴、8 片裙摆），已被 VRM 模式取代。

### 3.2 碰撞组分配（`n3_physics.RIG`）

| 部位 | 模板 | 碰撞组 |
| --- | --- | --- |
| 双马尾、侧发 | 头发 | head + torso |
| 刘海、头上的丝带 | 头发 | head |
| 耳朵 | 头发 | 无 |
| 尾巴 | 头发 | torso + legs |
| 裙摆 | 头发 | skirt（build24：legs + 两个臀部椭球） |
| 吊带丝带、上衣丝带 | 腰带垂饰 | torso |
| 袖口丝带、鞋标 | 腰带垂饰 | 无 |
| 脸颊 | — | 不生成 |

### 3.3 参数模板

参数块（+28 起的 42 个字）直接抄原版条目：头发模板 = `0xd5d385f9` 条目 0，腰带垂饰模板 = `0xfed6b90c` 条目 0。原版 45 个 type-4 条目对比：

- 流苏 / 腰带垂饰：第 21 个字 = `0x1000000`，第 22 / 23 个字 = 0，是纯摆锤。
- 头发：第 21 个字 = `0x101`，第 22 / 23 个字 = 0.4 / 0.2。用头发模板的耳朵在关卡里能立住。
- 向上飘的长飘带（`0xfeeb56b1`、`0xc66fe623`）：第 7 个字 = 0.09–0.1（头发是 0.95，`hypothesis`：重力系数），第 21 个字 = `0x1010101`，第 22 / 23 个字 = 60–80 / 40–45。
- build20 尾巴和裙子用流苏模板：尾巴直垂耷拉在两腿之间，武士裙子沿重力下垂，臀部和大腿穿出裙片。build21 改用头发模板后保持住了建模时的形状。

## 4. 碰撞体（LLOC）

### 4.1 格式

- `[I]` LLOC：`(magic, version, size, 1)`，子块 `(0x20001, size, 组数)`，每组 `(u32 标志 0x1, u32 n, n × 112 字节碰撞体)`。type-4 条目的 A 个下标指向这些组。
- `[I]` 112 字节 = 28 个字：

| 字 | 内容 |
| --- | --- |
| 0 | 形状：5 椭球，6 球 |
| 1 | 骨号 |
| 2 | −1 |
| 4–6 | **半轴**（不是直径） |
| 8–10、12–14、16–18 | 旋转矩阵三行（中间的字为 0） |
| 20–22 | 骨空间里的中心 |
| 23 | 1.0 |

- 半轴的证据：原版身体对 `torso` 组的胯球 / 脊椎椭球的归一化半径中位数 0.9–1.06；`legs` 组的大腿椭球把原版大腿整段包在 r < 0.94 以内。

### 4.2 可复用的原版组（[C] 本案例的命名）

| 名字 | 来源 | 覆盖 |
| --- | --- | --- |
| head | 头发 `0xd5d385f9` 组 0 | 胸、颈、锁骨、头、上臂 |
| torso | 忍者上衣 `0x5548953f` 组 0 | 胯、脊 ×2、胸、锁骨、上臂 |
| legs | 额饰 `0x6a0d18db` 组 1 | 胯、两腿、两膝（5 个椭球） |
| skirt | legs + `KARIN_HIPS` | build24 新增 |

`n3_g1m_physics.lloc_entry_bytes` 在原版组后面追加自定义椭球：克隆组里第一个碰撞体（必须是形状 5），改骨号、半轴、旋转（单位阵）和中心，再把 n 加上。

### 4.3 臀部椭球（build24）

- 现象：前倾弯腰下劈这类大动作时，身后臀部的皮肤略微穿出裙片。
- 原因（离线测量）：`legs` 组按原版身体做的。Karin 的臀部更高更翘：绑定姿势 y 100–104 处皮肤 / 内裤到 z −12.9 / −13.3（原版 −11.6），
  y 104–108 处 −12.8（原版 −8.9）。胯椭球（中心 (0, 108.1, 1.6)，半轴 (16.4, 11, 16.4)）和大腿椭球之间在臀部留了约 4 cm 空档，大动作时裙片掉了进去。
  - 蒙皮不是原因：臀部皮肤 80–90% 绑在胯骨上，屈髋时线性蒙皮只会往里收。
  - 静止时裙片离皮肤只有 1–2 cm（y 104–110）；裙摆第 1 层链点离皮肤 1.9–2.3 cm，第 2 层 3.9–8.5 cm。
- 做法：两个挂在胯骨上的椭球，世界中心 (±6, 97, −9)，半轴 x 11 / y 13 / z 7，骨空间旋转为单位阵。
  拟合（`checks/fit_butt3.py 2.0 0.3 104`）：y 88–102 处 `legs` 盖不住的背面皮肤和内裤都在新椭球内且留 2 cm；16 条裙摆链的非根点在静止姿势都在椭球外至少 0.3 cm
  （最近的约 0.7 cm）。约束要用链上的点，不能用裙子的全部顶点：碰撞只作用在链点上，而裙子网格静止时就贴着皮肤，按顶点约束无解。
- 与 build23 比：两件上衣只有 LLOC（多一组）、FM1G +96 / +100、ONUN 里裙摆条目的碰撞组号变了。`offline-accepted`，等用户实机。
- 也考虑过用换装形态键把内裤下面的皮肤收进去，没有采用：内裤本身仍会穿出，开口处还可能出现锥形（[排障手册](TROUBLESHOOTING.md) §4）。

## 5. 实机判断

- **看关卡里静止时**耳朵、裙摆、尾巴有没有在重力下垂、停下后有没有回摆。主菜单在模拟不代表关卡里在模拟。
- 低分辨率的跑动截图分不清动画和物理：build9f 时 agent 记录的「双马尾跑动时后飘」后来证明是误判。
- 离线：`checks/swing.py <built.g1m> [角度]` 把每条链整体绕根部转动，核对只有它自己的顶点在动（build20：37 条链里只有袖口丝带各 1 个极小权重顶点低于阈值）；
  绑定姿势漂移 < 1e-4 cm。

## 6. 未做 / 可调

- 各部件的软硬手感没有专门调；耳朵、刘海暂用头发模板。
- 标题画面里耳朵、裙子被重力拉歪（关卡里正常）。
- 很快的动作下链点仍可能穿过碰撞体之间的空隙；下一步可以把椭球再放大，或者让后片裙摆更硬。
