# 排障手册

## 按症状定位

| 症状 | 先查 | 本项目的原因 / 修法 |
| --- | --- | --- |
| 身体前后有接缝：前面粗糙布纹，后背光滑 | 两个材质的类型 3 法线与类型 49 遮罩 | 法线是别的服装的图集布局，遮罩把平铺布纹铺满了一个材质 → 法线换平法线，遮罩清零，再烘焙源模型的法线 |
| 外套看起来脏、斑驳 | 同上，再加颜色与法线是否对位 | 同上 |
| 脸暗、发红 | 脸的 t2 / t21 / t39 / t49 / t62 解码后按 UV 叠到脸上看 | 附属贴图是另一张脸的布局（额头上有倒置五官，下半脸开着颈部皮肤层）→ 皮肤区设常量，保留眼睛岛，t49 L1 清零 |
| 脸在顶光下下半部偏暗，或发白有斑块 | 法线、t62、刘海的投影 | 柔化法线、t62=255 有所改善；斑块随复用的脸一直存在，未根治。Original 版截图里同样能看到 |
| 某块衣服贴图发糊 | 那个 UV 岛内的纹素密度（雅可比） | 翻领被挤在大岛里，密度差 7.7 倍 → 切开、ARAP、按统一密度重排、重烘 |
| 烘焙结果有闪点 | 采样方式 | 随机抖动采样 → 改成对最近三角形精确投影 |
| 针织条纹出现摩尔纹 | 源贴图有没有按 LOD 采样 | 用雅可比最大奇异值选 mip，三线性采样 |
| 白色小部件变成粉色 | 投影是否打到了别的衣服层 | 加颜色一致门，按 UV 岛判断用源颜色还是保留原颜色 |
| 平法线看着有偏斜 | 解码值 | texconv 默认的 BC1 会编成 (132,130,255) → 用 BC7 或手写块 |
| 写回后某个子网格消失或错位 | 对应的 vb/ib 是否存在且不为空，fmt 与同一 VB 里的其它子网格是否一致 | gust 会剔除没有 ib/vb 的子网格。同一 VB 的子网格格式不一致时，导入器会跳过 |
| 导入时报 "sanity check failed" | vgmap 的名字和调色板 | vgmap 要用 `bone_<boneToBoneID[j]>`，值为下标乘 3，并与 metadata 里的调色板一致 |
| 自己的解析器读原版 VB 报错 | 是不是分段复合缓冲 | 原版有带 0x80000000 的复合缓冲，要经过 gust 导出再读 |
| 姿势测试里脸被拉成尖刺 | 权重和 | 复用的脸有顶点的权重和小于 1，测试时要归一化（游戏本身没问题） |
| 坐着时卫衣下摆和裙腰之间有白色碎片 | 腰部皮肤和内衣 | 只在旅馆坐姿下看到，未定位，`hypothesis`：腹部皮肤或内衣在坐姿下穿出 |

## 自动化与环境

| 症状 | 原因 / 处理 |
| --- | --- |
| 读同步目录里的文件时进程卡死 | 百度网盘的占位文件（`.baiduyun.p.downloading`）→ 从本地副本复制；结束卡住的任务 |
| texconv 报 FileNotFoundError | 用绝对路径调用 |
| g1t_layout 对 1×1 的非 BC 贴图报 `KeyError: 4` | 跳过这类贴图 |
| 读取列表里的高亮跑到了「商店」 | 主菜单丢了一个 Enter → 每一步截图确认；脚本校验高亮，不对就停 |
| 旅馆菜单方向键没反应或乱跳 | 鼠标悬停抢了焦点 → 改用点击 |
| 发了 WM_CLOSE 后进程很久不退 | 需要等 90–120 s，不要强杀 |
| AUTO 存档被改了 | 读档本身就会触发自动存档 → 自测前备份存档目录 |

## 已被否定的捷径

- **网格拓扑有问题导致接缝**：`rejected`。接缝来自贴图布局。
- **不切开直接对整岛 ARAP 修翼领**：`rejected`。重叠 39%，插值后仍会重叠。
- **脸上的眼睛遮罩是作者画的**：`rejected`。实际来自虹膜和睫毛的 UV 岛。
- **复用 PicodraTech 版的身体给 Original**：`rejected`。两者的身体基础网格不同（Chiffon 和 Karin），只有脸相同。
- **把脚趾挂到游戏趾关节 15/16**：`rejected`。游戏的趾关节在鞋尖前方 6 cm，弯趾会扯坏鞋子，所以整只鞋跟随踝关节。
