# 验证与发布

## 离线闸门（按顺序，任一失败就停）

1. **gust 往返**：模板导出后不做修改直接导入，G1M 应逐字节相同。不同就说明 gust 版本或模板有问题，不能用它写回。
2. **只改该改的块**：写回后 SM1G / MM1G / ONUN / LLOC / RTXE 都应与模板逐字节相同。报告里列出改动的块，应该只有 FM1G 和 GM1G。
3. **独立回读**：用自己的解析器（不经过 gust）读每个目标子网格，和构建数据核对：
   - 位置误差 < 1e-3。
   - UV 误差只有半精度量化（约 2.4e-4）。
   - 权重逐个相同，和为 1。
   - 关节号一致，骨索引都是 3 的倍数。
   - 索引缓冲完全一致。
4. **绕序**：几何法线与顶点法线同向的三角形比例，应与模板相近（≥0.94）。
   - 方向相反的少数三角形，要确认是衣服下被压扁的皮肤。
   - 坐标轴换算 (x, z, −y) 是一个旋转，不会翻转绕序。
5. **贴图回读**：每张 G1T 都解码回读。
   - 颜色的平均误差 < 0.2 级。
   - 平法线解码应为 (129,128,255)。
6. **静止渲染**：用 G1M 里的 UV 加原贴图渲染正面、侧面、背面，检查脸和颈的接缝、贴图是否错位、隐藏件是否露出。
7. **姿势测试**：在游戏骨架上用世界空间旋转摆出走路、深蹲、举手、转头四个姿势（辅助骨跟随父骨），然后统计边长拉伸并渲染。
   - 大拉伸只允许出现在衣服遮住的地方（裆部、膝窝、腋下），或复用部件本来就有的位置（脸的下巴内侧）。
   - 测试时要把权重归一化：复用的脸有 62 个顶点的权重和小于 1，游戏能容忍，但不归一化会让测试误判。

## 打包

- **内容**：`DWOPATCHER/root/` 下 29 个文件，加 `README.md` 和 `SHA256SUMS.txt`。
- **不放进包里**：
  - `dinput8.dll`、`DWOPATCHER.ini`、`Patches/`（加载器自己的文件）；
  - 被替换前的旧文件。
- **README 必须写明**：
  - 需要先装加载器；
  - 与同一服装的其它 mod 互斥；
  - 卸载时按 SHA256SUMS 列出的文件名删除。
- **发布前核对**：把 zip 解压，逐文件与已部署的游戏目录比对哈希。

## 部署

1. 先比对游戏 `DWOPATCHER/root` 与工程里上一版快照的哈希，确认可以回滚。
2. 复制文件后逐文件核对哈希。
3. 一次只部署一个版本。版本快照存在工程的 `_versions/` 下，每个快照附 README 和 SHA256SUMS。

## 读档自测流程（agent 可独立完成，`[B]`）

- **环境**：1920×1080 无边框，按键按住 150 ms、用扫描码发送，中文输入法先关闭。每一步都截图并读图确认。
- **截图方式**：只截客户区，进程要声明 DPI 感知。截图时不要启动会弹出控制台的子进程，否则会抢走焦点。

1. 用 `steam -applaunch 2384580` 启动，约 15–30 s 出现「按下任意键」。
2. Enter 进入主菜单，「继续游戏」已经高亮；再按 Enter 打开读取列表（AUTO、1–8）。
   - **截图确认已进入读取列表**：Enter 会丢。脚本一次失败就是因为丢了 Enter，接下来的 Down 把光标移到了「商店」。
3. 按两次 Down（间隔约 0.6–0.8 s，太快会丢），截图确认 2 号高亮，再按 Enter。不到 5 s 就进入襄阳旅店。**这时游戏已自动存档到 AUTO。**
4. 旅馆菜单里，方向键会被鼠标悬停抢走焦点。改为点击「战斗准备」（x 0.12，y 0.553），再按 Enter，进入「装备」页。
   - 这里有固定的影棚光和正面头到大腿的构图，适合版本之间对比，是最好的正面图。
5. 背面全身：在装备页按 K（试用武器）。确认框默认选「否」，先按 Left 再按 Enter。
   - 进场后按 Backspace 关闭菜单，再用 Ctrl、Space 关掉教程，然后立刻截图（约 10 s 后敌人会冲上来）。
6. 照相模式：战斗中按 Esc 再按 F。WASD 移动镜头，按住左键拖动旋转，K 复位；镜头一开始在头里，按住 S 后退。
7. 退出：向游戏窗口发 WM_CLOSE，大约 90–120 s 进程才退出，不要强杀。

## 证据口径

- **离线闸门全过**：`offline-accepted`。
- **读档后在旅馆、装备界面看到正确外观**：`runtime-load-pass`。这一级不覆盖：
  - 战斗动作；
  - 过场；
  - 头发、尾巴、裙摆的穿插；
  - 不同光照下的脸。
- **用户实际游玩认可**：`runtime-confirmed`，要写明用户看过的场景。
