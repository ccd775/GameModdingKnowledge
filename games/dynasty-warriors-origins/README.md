# 真三国无双 起源（DYNASTY WARRIORS: ORIGINS）

## 范围

本目录整理 Steam《DYNASTY WARRIORS: ORIGINS》（App `2384580`，光荣特库摩 KT 引擎）的角色替换方法，资料来自 2026-10-01 → 10-02 的工作。
所有 mod 都替换主角的服装「鸾翼将装」。这套服装的模型自带头部、脸和头发，所以替换它就等于整个人换成别的角色。

| 交付 | 内容 | 最高证据级 |
| --- | --- | --- |
| Karin PicodraTech → 鸾翼将装，v20261001a | 修复他人制作的 mod：身体前后接缝、外套"脏"。法线换成平法线，细节遮罩清零 | `runtime-confirmed`（用户实机认可） |
| 同上，v20261001b / c | 法线和颜色从源模型重新烘焙到 4096。外翻领 UV 切开、ARAP 后按等密度重排。脸部附属贴图修正，脸部法线柔化 | `runtime-confirmed`（用户验收：外套好了，脸"还可以"） |
| Karin_Original → 鸾翼将装，v20261002a | 从 FBX 源模型完整构建身体、服装、头发和尾巴。脸复用 PicodraTech 版（同一网格），只换贴图 | `runtime-load-pass`（agent 读 2 号存档，在旅馆和装备界面截图）；用户未验收，实际战斗未测 |

所有哈希名、关节号、缩放和偏移都是 `build-sensitive` 或 `case-derived` 快照，只对 build `21711288` 有效。

### 与 KT 引擎其它项目的关系

本作和《浪人崛起》（Rise of the Ronin，本库暂未收录）共用以下格式：
- `_DRK` 资源表 `root.rdb/rdx`；
- IDRK fdata；
- KTID / kidsobjdb；
- G1M / G1T。

浪人项目的解析器（`parse_rdb` / `read_fdata_entry` / `parse_kidsobjdb`）在本作原样可用，加载器也是同一作者的同类 DLL。
骨架、材质槽和贴图语义是本作自己的，不能互相套用。

## 主要结论

- **mod 由按哈希命名的散装文件组成**：一个 G1M 加若干 G1T，放进 `DWOPATCHER/root`。
  - 骨架 SM1G、逆绑定 MM1G、布料 ONUN（NUNO）、LLOC 都保持原版字节。
  - 只改网格块 GM1G 和计数块 FM1G。
  - gust_stuff 的导出 → 导入往返逐字节一致，可以直接作为写回通道。
- **贴图语义靠材质的贴图类型号判断**：
  - 类型 24 是 256 px 的平铺细节法线数组。
  - 类型 49 是细节遮罩，记录每个位置用哪张细节法线、权重多少。全零就关闭细节。
  - 别的服装或别的脸的遮罩、法线、皮肤层贴图套到新 UV 上，就会出现"前后接缝""衣服发脏""脸发暗发红"。
  - 布料与皮肤的着色、AO 等贴图在已知材质上是常量，可以原样保留。
- **原版从不直接蒙皮到大腿以下的 11/12、锁骨 17/18、前臂 21/22**：
  - 而是蒙皮到它们的子辅助骨，例如前臂 94/96/98、小腿 114/116/118、肩 80。
  - 新模型按 Karin 的分段权重，再按原版在该段上的分布分给辅助骨。
- **法线约定**：G 正方向为图像上方。切线 T = +dP/du，`cross(N,T)·w` 指向图像上方。
  - BC7 加 G1T 头偏移 0x1C 的标志 3，可作法线贴图，原版也有这种用法。
- **两个 Karin 版本共享同一张脸网格**：Original 版可以直接复用 PicodraTech 版调好的脸，只做相似变换并换颜色贴图。

## 核心方法

- **先诊断再改**：从 KTID 解出 63 个贴图槽，把 mod 文件和原版文件逐槽对照。
  - 再把每张贴图解码，按 UV 叠到网格上看。
  - 本项目的接缝和发脏，都是贴图沿用了别的布局造成的，而不是网格问题。
- **从源模型重建时**：先用均匀缩放让髋、膝、踝落在游戏骨上，再用源模型自己的权重做 LBS，把手臂摆到游戏的 A 字姿势，手掌和五指也对齐。
  - 贴图按源贴图分组，UV 保持原样，不重排、不重采样。
- **每一步都要验证**：每次写回都先用独立解析器回读，再在游戏骨架上做离线姿势测试，最后读档实机截图。

## 证据纪律

沿用本库五级：`reference-inferred` / `offline-accepted` / `runtime-load-pass` / `runtime-rejected` / `runtime-confirmed`。
- PicodraTech 修复的实机结论来自用户反馈。
- Original 版的实机结论只来自 agent 读档后的旅馆和装备界面截图，标 `runtime-load-pass`。
