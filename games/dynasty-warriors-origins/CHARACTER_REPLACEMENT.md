# 角色替换

## A. 修复现成 mod（Karin PicodraTech 版）

### A1. 诊断

1. 从 KTID 解出 63 个槽，逐槽列出"原版哈希 / mod 是否替换 / 贴图类型"。
2. 把每张 G1T 解码成 PNG，按 UV 把贴图叠到 mod 的网格上，生成渲染图和 UV 叠图。
3. 结论（`case-derived`）：网格没有问题。
   - 法线贴图用的是别的服装的图集布局。
   - 类型 49 遮罩又把原版的平铺布纹铺满了整个材质。
   - 结果是身体前半（材质 3）有粗糙布纹，后背（材质 1）光滑，形成一条接缝；外套看起来发脏。

### A2. 先止血（v20261001a，用户认可）

- 三张法线贴图换成平法线，两张类型 49 遮罩清零（细节关闭）。
- 用户确认接缝消失。
- 这一版作为后续改动的基线，单独备份。

### A3. 把源模型的细节烘焙回来（v20261001b）

mod 的网格是：源模型 T 字姿势 → 摆成 A 字 → 减面 → 重新展 UV。烘焙流程：
1. **姿势拟合**：用源骨架做 LBS，只旋转 Shoulder / UpperArm / LowerArm。优化目标是到 mod 顶点的距离，加上肩部角度罚项（不加罚项时，右肩被拟合到 192°）。
2. **最近点投影**：对每个 mod 纹素，在姿势化的源网格上精确求最近三角形上的点（Ericson 算法），并要求法线方向一致。
   - 随机抖动采样会产生闪点，已否定。
3. **法线迁移**：在切线空间里迁移 XY，切线约定见技术合同。
4. **mip 金字塔采样**：用 UV 雅可比的最大奇异值选 LOD，再三线性采样。不这样做时，针织的条纹会出现摩尔纹。
5. **颜色一致门**：
   - 先检查源模型颜色与 mod 原颜色是否一致。不一致的地方（作者自己加的部件、投影到了错误的衣服层），保留原颜色并用平法线。
   - 最终做到按 UV 岛判断：一个岛的中位差 ≤14 就用源模型颜色，否则保留原颜色（按旧 UV 重采样）。
   - 层选择要参考颜色，否则会投影到内衬上。
6. 输出 4096 BC7，带完整 mip。

### A4. 翻领发糊（v20261001c，用户验收）

1. **原因**：mod 自己的 UV 把外翻领挤在外套的 5 号岛里，岛内纹素密度相差 7.7 倍。
2. **ARAP 不能直接用**：直接 ARAP 后有 39% 的面积重叠；只做插值 ARAP，α=0.1 也会重叠。
3. **切开再 ARAP**：
   - 沿源模型的外层 / 内衬分界切开 5 号岛，新增 25 个重复顶点，插在 sub6 末尾。
   - sub7 的索引和偏移随之平移，VB / 分节 / 块 / 文件的大小都要改。
   - 每片单独 ARAP，再重建切线。
4. **重排与重烘**：
   - 按统一纹素密度做 MaxRects 装箱：不旋转，4 px 对齐，12 px 留边。
   - sub6 和 sub7 各占一张 4096 图集，因为它们各有自己的贴图槽。
   - 重排后重新烘焙。

### A5. 脸发暗、发红

1. **原因**：脸的附属贴图（t2 / t39 / t62 / t21 / t49）是另一张脸的布局。
   - 额头上有倒置的五官。
   - 下半脸开着颈部专用的皮肤层。
2. **修法（"候选 C"）**：
   - 皮肤区设成原版脸颊的常量。
   - 眼睛所在的 UV 岛保留原值（来自虹膜和睫毛的岛，不是作者画的）。
   - t49 的 L1 清零。
   - 新增一张平法线 `0x975EF248`。
3. **v20261001c 追加**：
   - 用椭球加权柔化 VB10 的脸部法线：下半脸权重最大，向外用 smoothstep 渐变到 0。椭球的中心、半径和过渡带都是本案例的常量，见项目脚本。
   - t62 设为 255。
4. **结果**：用户认为"还可以"。在部分光照下仍略暗，下半脸会发白发斑（读档截图里可见）。

## B. 从源模型构建（Karin_Original，v20261002a）

### B1. 源与可复用部分

- **源模型**：FBX（Unity 骨骼命名）加 VRM。共 10 个网格：
  - Body（脸）、body_2（身体）、hair、kemomimi（狐耳）、tail（尾巴）；
  - pullover（卫衣）、skirt（裙子）、underwear、knee_socks（过膝袜）、shoes（鞋）。
- **贴图**：
  - 4096：Karin_Costume、Karin_Hair。
  - 2048：Karin_Face、Karin_Body。
  - Hair_Clipping 的最小值是 199，等于不透明，头发不需要透明裁切。
- **脸可以直接复用**：
  - **对照结果**：PicodraTech 的 VRM 里，Karin 的脸网格（Body）和 Original 的是同一个。ICP 比对：缩放 0.9998，旋转 0.09°，只差平移，残差 p99 约 1.7 mm。Karin_Alpha 部分完全相同。
  - **做法**：PicodraTech 版的脸子网格（10/11/14，包括调好的附属贴图和法线）原样复用，只做相似变换，k = 150.1/153.5 ≈ 0.978。
  - **贴图**：颜色换成 Original 的红眼贴图，UV 布局相同。
  - **颈部补片**：PicodraTech 的颈部补片 sub12 塌缩成一个退化三角形，由 Karin 自己的 body_2 颈部代替。
  - PicodraTech 的身体用的是另一个基础模型（Chiffon），不能复用。

### B2. 贴合（`case-derived`）

1. **均匀缩放 150.1**，偏移 (0, −0.7, 1.93)：
   - 大腿、膝、踝落在游戏骨上，误差 ≤0.5 cm。
   - 偏移的 y 比让踝对准时高 1.5 cm，让厚底鞋只陷进地面约 1 cm。PicodraTech 版陷 1.3 cm。
2. **手臂**：用 Karin 自己的权重做层级 LBS。
   - UpperArm 指向游戏的肘（误差 0.6 cm），LowerArm 指向腕（1.0 cm）。
   - Hand 先对准"腕到中指近节"的方向，再绕这根轴扭转，让食指到小指的连线与游戏手骨一致。
   - 每根手指从近节到末端，对准游戏对应手指的方向。
3. **已接受的差异**：
   - 肩关节比游戏窄 7 cm，与 PicodraTech 版相同，抬臂时腋下会拉伸。
   - Karin 的头关节比游戏低 6 cm。

### B3. 权重（`case-derived`，方法可复用）

- **段内用原版分布**：Karin 的权重决定顶点跟哪一段。段内按原版在该段上的分布，分给主骨和它的子辅助骨。
  - 分布按沿骨段的参数 t 分 16 个箱统计，统计时只用离骨段 15 cm 以内的原版顶点。
- **躯干**：Hips / Spine / Chest 按原版的高度曲线分给 2/3/4/5。
- **颈与头**：Neck 按高度在 6→7 之间线性过渡。头、头发、耳、眼、发带都给 8；尾巴给 2。
- **脚**：Foot 和 ToeBase 都给 13 / 14。脚趾不单独弯，因为游戏的趾关节在 Karin 鞋尖前方 6 cm。
- **袖子**：卫衣上挂在 Hand 和 Ribbon_hand 的权重改给前臂段，避免手腕转动时带着整个袖子扭。
- **裙摆**：先按躯干规则分配，再按深度 t 与大腿混合，下摆处的混合系数为 0.75。左右按 x 坐标用 sigmoid（宽度 2.5 cm）分。
- **颈部接缝**：离复用的脸顶点 ≤0.5 cm 的身体顶点，直接复制脸的权重（包括脸部骨）。0.5–2 cm 之间线性过渡。共 98 个顶点。
- **收尾**：只保留前 8 个影响，丢掉小于 0.01 的，再量化到 2^-11。用到的关节共 71 个，每个都已有 MM1G 绑定。

### B4. 分件与写回

- **按源贴图分组，UV 保持原样**：
  - sub6（材质 3）：卫衣、裙、内衣、袜、鞋，以及头发网格里用服装贴图的发饰。
  - sub7（材质 1）：身体皮肤，手除外。
  - sub13（材质 2，皮肤着色）：手。
  - sub15（材质 8，头发着色）：头发、狐耳、尾巴。
- **丢掉隐藏的皮肤**：kisekae 形态键会把衣服下的皮肤压扁，面积 < 1e-4 cm² 的三角形直接丢掉（body_2 有 4414 个）。
- **去重**：按（顶点、UV、法线）去重。切线按约定重算。
- **写回**：gust 导出模板 → 替换 6/7/13/15 的 vb/ib/vgmap 和对应调色板 → 导入。只有 FM1G 和 GM1G 会变。
- **贴图**：
  - 颜色贴图直接用源贴图，编成 BC7 带完整 mip。
  - 法线槽放 256 px 的平法线 BC7（标志 3）。
  - 着色、AO、常量槽和遮罩槽（已清零）沿用 PicodraTech 版。

## C. 换第三个 Karin 变体时

- 先用 ICP 确认脸网格是否相同。相同就沿用 B1 的复用方式，不同就要连脸的附属贴图一起重做（见 A5）。
- 新服装的身体如果和 Original 的 Karin 身体相同，B2 的贴合参数可以直接用；否则重新拟合髋、膝、踝。
- 有裙摆的服装沿用 B3 的混合；有长发或尾巴的，在没有物理的前提下保持刚性。
