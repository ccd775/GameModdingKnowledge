# 案例：Karin_Original 替换奎托斯与芙蕾雅

> **范围：** 用 Karin_Original（FBX 加 VRM）替换奎托斯（`r_heroa00.wad`）和同伴芙蕾雅（`r_freyavalkyrie00.wad`）。模型穿套头衫、短裙、过膝袜，有狐耳和尾巴。不做服装差分，不含芙蕾雅的女武神翅膀形态。
> **证据边界：** Steam build `18979360`，Blender 5.0.1，Python 3.14.0（numpy 2.5.2、scipy 1.18.0、lz4、etcpak、texture2ddecoder）。
> **状态：** `runtime-load-pass`。两版都由 agent 在游戏里自测过；用户在实机里看过修正 wad 后的芙蕾雅，反馈了膝盖穿模，膝盖修复版用户尚未单独确认。

## 版本轨迹

### 奎托斯

| 版本 | 改动 | 实机结果 |
| --- | --- | --- |
| 二分阶段（测试 B–M） | 见 [排障手册](../TROUBLESHOOTING.md#卡死与崩溃的二分记录) | 定下容量、每组非空、退化三角形、单组 lodpack 四条规则 |
| v1（wad `201fe4de…`） | 组 230 的 LOD0–4 原地写入 Karin，其余定义隐藏；自己的贴图包 | agent 自测：启动、读档、在丛林里行走和转视角，正面和背面的模型与贴图正确 |
| v2（wad `c8b43fc4…`） | 用烘焙了 `kisekae_Knee` 的源模型重新拟合、重建；贴图包不变 | 逐顶点回读通过，已装进游戏；膝盖修复后的实机检查以芙蕾雅为主 |

### 芙蕾雅

| 版本 | 改动 | 实机结果 |
| --- | --- | --- |
| v1（`r_freya00.wad`，`2c86d894…`） | 替换 `r_freya00` 的组 49 / 48 / 46 / 3 | 拒绝（用户实机）：两个存档里芙蕾雅都没有变化。依赖表显示没有资源引用 `r_freya00` |
| v2（`r_freyavalkyrie00.wad`） | 改为替换同伴用的 wad；组 36 / 14 / 13 / 27 | agent 自测时先后看到一大片乱掉的深色面片和翻到背后的尾巴，排查后修了三处（见下），修完后读档正常 |
| v2 定版 | 同上，含三处修正 | agent 自测：狐耳、发型、双马尾、上衣、裙子、尾巴、过膝袜和鞋位置正确，跟随行走动画正常。用户实机反馈：膝盖皮肤穿出袜子 |
| v3（wad `f003da61…`） | 用烘焙了 `kisekae_Knee` 的源模型重新拟合、重建；贴图包不变 | 屈膝模拟从 30°–90° 时穿出 1–4 个顶点降到 0；agent 自测：背面、侧面、俯视，以及约 6 m 外的正面（脸、红眼、上衣徽章正常），没看到膝盖皮肤 |

v2 自测中的三处修正：

1. **零块位置：** 隐藏定义的零块从 wad 内 gpu 条目移到头颈 LOD0 缓冲区的空闲尾部。放在 gpu 条目里时，引擎画出了那块区域原本所属网格的三角形，就是那片乱掉的面片。
2. **骨骼格式：** 头颈组 (9,2,4)+(10,2,2) 改为 8 个 u16 写入。之前按 11 bit 打包，整组绑错骨骼。
3. **蒙皮骨骼：** 骨盆、肩、髋、膝改为原版蒙皮里的子骨（14、842/836、59/66、82/91），不再用 FK 控制骨（38、141/138、43/44、55/62）。之前绑在 38 上的裙子和尾巴整体翻到背后。左膝镜像会选到不带蒙皮的 86，手工改为 91。

三处修正各自对应哪个画面，是按机理和修正前后的截图认定的，没有逐个单独回退验证。

同时修了两处工具问题：`skin_of` 把 R10G10B10A2 权重按 snorm 解码（应为 unorm）；槽位规划遇到连最粗一级都放不下的次要定义时直接失败（加了回退）。

## 已知限制

- 头发、双马尾、尾巴、裙子没有次级物理：头发和狐耳随头，尾巴随骨盆，裙子按骨盆和大腿的混合权重跟随。
- 没有表情和眼动，脸整体随头骨运动。
- 去掉了 VRM 里半透明的腮红和眼睛高光层。
- 奎托斯版鞋底比奎托斯的脚底低约 4 cm，个别动作可能轻微陷地。
- 奎托斯版俯视时头顶、耳尖、肩上有黑斑，平视没有；未处理（猜测是皮肤的灰尘层）。
- 奎托斯的右髋绑在 167，这根骨在原版蒙皮里没出现过；实机行走没看出问题，没有专门检查。
- 芙蕾雅的翅膀等形态部件已隐藏，翅膀形态下只显示 Karin 本体。
- **未检查：**
  - 奎托斯：战斗、斯巴达之怒、过场动画、远景 LOD 的实际切换、其他地图；
  - 芙蕾雅：正面近景（测试时镜头无法水平转动）、战斗、女武神翅膀形态、过场动画、远景 LOD。
