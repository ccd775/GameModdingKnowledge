## 2. 本项目的复现与偏离（Karin_Original）

源：`Karin(Clone).vrm`（VRM1，34,304 顶点，39 条 spring；去掉脸颊鼓包骨后成链 37 条）。

| 项 | 里昂 | 格蕾丝 |
| --- | --- | --- |
| 脸 | `10_00`：原生 285 骨面部骨表，只绑 `Head_0` | `10_00`：原生 287 骨 |
| 头发（含猫耳） | `20_00` | `20_00/02/03` |
| 身体（含服装、尾巴） | `40_00/01/02/03/50/51/70/71` | `40_00/01/02/03/04/50/51/70/71` |
| 屏蔽件 | 31 个（含参考 mod 漏掉的 `41_00` 腰带） | 23 个（含 `14` 耳机、`15` 眼镜、`48` 毯子） |
| mdf2 | 39 份（每个被替换网格的全部变体） | 32 份 |
| 身体/头发骨表 | 原生 `01_71`（408 骨）+ KC 链骨 | 合并 `45_00`、`50_00`、`01_00`、`02_00` 四个原生骨表（没有单个网格含全部身体骨）+ KC 链骨 |
| 缩放（肩高对齐） | ×1.466 | ×1.385 |

偏离配方的地方与理由：

- **缩放按肩高（`L_Arm_Upper` ↔ VRM `leftUpperArm`）**，与 PRAGMATA 的结论一致；参考 mod 的约 ×1.557 更大，
  用户若想要参考 mod 的体型，只需改这一项。
- **屏蔽件**用 4 顶点零面积三角形、各部件**自己的**原生骨表和原生首材质名（原生 mdf2 继续可用），不再统一借用 408 骨表。
- **clsp 不动**；改为让 Chain2 用 chain2 自带碰撞体（CollisionTarget = Self）。
- 所有 mdf2 变体都写；所有材质 NRMR 指向平图。

## 3. refskel 路线（invariant 做法，case-derived 值）

- 几何 = 一次相似变换（肩高对齐、脚踩地面）。
- 移到源模型关节上的：手臂（含锁骨 `X_Arm_Clavicle`）、手、手指（VRM1 拇指 metacarpal/proximal/distal →
  `ThumbF_1/2/3`）、腿、`X_Leg_Ankle` ← VRM `foot`、`X_Leg_Toes`、`Neck_0` ← `neck`、`Head_0` ← `head`，
  `Neck_1` 取颈与头的中点。
- 保持原生的：`root`、`C_Prop_Root_A`、`Hip`、`Spine_0/1/2`。其余原生骨（辅助骨、扭转骨）随父骨刚性移动。
- 关节坐标系 = 原生坐标系 × **父骨携带的最小摆动**（子骨先随父骨转，再做最小对准），见
  [PRAGMATA 角色替换](../pragmata/CHARACTER_REPLACEMENT.md) §2。
- 脚部权重绑到 `X_Leg_Foot`（`Leg_Ankle` 的子骨），与参考 mod 和原生鞋子的做法一致。
- `ch01.refskel.8` / `ch02.refskel.8` 各改 49 个关节；验证器要求 refskel 与所有网格的 rest 在位置 1e-4、旋转 1e-3 内一致，
  所有部件之间共享关节的 rest 偏差为 0。
- **refskel 是整个角色号共用的**：里昂、格蕾丝的其它服装（`ch0150–0153` / `ch0250–0253`）也会按 Karin 比例变形，
  参考 mod 同样如此。

## 4. 几何细节

- 每种 mod 材质合成一个 submesh（脸 2、头发 2、身体 3 个），每顶点 ≤ 8 个权重。
- 链骨 `KC_<链名>_<NN|end>` 只存在于网格骨表；链权重只给本部件负责的链（头发部件 = 双马尾、侧发、耳朵；
  身体部件 = 裙、缎带、尾巴），别的部件里同一批顶点绑到链的锚点骨。
- 源模型自带的 `kisekae_*` 收肢形态键在蒙皮前烘焙（`kisekae_UppeLeg 2` 只烘焙袜口以下），做法同 PRAGMATA。
- 身体网格同时用在里昂 8 个、格蕾丝 9 个变体里，几何完全相同。

## 5. 材质与「乳胶感」（runtime 发现）

- 皮肤与脸用 `Ch_Skin_Detail`，衣服与头发用 `ChWp_Default` + 双面，镂空贴花加 AlphaTest 和 ACOT 镂空图
  （模板与标志位见 [技术合同](TECHNICAL_CONTRACTS.md) §5）。
- v1.0 实机：所有表面像乳胶一样反光。原因是 NRMR 槽用了 `NullNormal`，alpha（粗糙度）= 0。v1.1 起所有材质指向
  平法线、粗糙度 1 的 NRMR，展柜里变成哑光。
- 同一问题也在参考 mod 里：`Face_Mat`、`Body_Mat`、`Karin_Hair_Mat`、`Karin_Mat` 直接用 `NullNormal`，`ClothA_Mat` 的
  `ClothA_Blue_NRMR` 是 NullNormal 的 8×8 副本。修法：只把这 5 条的 NRMR 路径改到新的平图（39 个 mdf2 + 1 张贴图，
  其它文件不动；改前每个 mdf2 先过写出往返闸门，改后只允许这些路径变化）。参考 mod 其余的 NRMR alpha ≈ 255，
  各材质 UV 覆盖区的 ALBD alpha 也 ≈ 255（不是金属度问题）。
- 怪物猎人荒野记录的是同一类问题的另一种形态：引擎 NullNRRO 粗糙度 0.5，布料出现集中高光
  （[MHWs 技术合同](../monster-hunter-wilds/TECHNICAL_CONTRACTS.md)）。RE Engine 作品里留空的粗糙度贴图都要先解码看值。

## 6. 已知限制

- 无表情与眼动（脸绑 `Head_0`，与参考 mod 相同）。
- 设置里开启 GPU 发丝（StrandsEnable）时，`21` 号 strands 部件会显示原发，未处理。
- 其它服装受 refskel 影响变形；切割死亡套件的观感未看。
