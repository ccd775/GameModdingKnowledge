# 排障手册

## 症状 → 定位表

| 症状 | 原因 | 处理 |
| --- | --- | --- |
| 皮肤、衣服像乳胶一样反光 | NRMR 槽是 `NullNormal`（或它的副本），alpha = 粗糙度 0 | 指向平法线、粗糙度 1 的 NRMR；参考 mod 自带的 NRMR 也要解码看 alpha |
| 某些场景/套件里显示原模型 | 只替换了部件的一个变体 | 按路径表替换该部件号的全部变体 |
| 某些场景里材质错乱或缺失 | 少写了 mdf2 变体，或 mdf2 缺网格的材质名 | 写全部 `<mesh>_NN.mdf2.51`，验证器核对材质名 |
| 展柜里头发会动、裙子和尾巴静止 | 基础 montage 的身体 `40_70` 原生没有 Chain2 | 给所有显示完整身体却没有 Chain2 的 prefab 注入 |
| 格蕾丝在展柜里身体链完全不动 | 展柜对 `40` 喂专用动画并关闭其 Chain2 | 游戏行为；进实际游玩检查 |
| 裙子挡不住大腿、双马尾穿进躯干，但静止间隙闸门全过 | Chain2 `CollisionTarget = 1 (Extern)`：只碰 clsp，chain2 自带碰撞体被忽略 | 所有加载自带 chain2 的 Chain2 设 `0 (Self)` |
| 在 `Hip` 上加测试碰撞体，节点毫无反应 | 同上 | 同上；先用探针读 CollisionTarget |
| 里昂的腰带还显示在 Karin 身上 | 参考 mod 漏了 `41_00` | 加屏蔽件 |
| 开启 GPU 发丝后出现原发 | `21` strands 部件未处理 | 已知限制；需要 strands 屏蔽方案 |
| 里昂/格蕾丝的其它服装比例怪 | `chXX.refskel.8` 被整个角色号共用 | 已知限制，报告里写明 |
| 分析脚本说 ALBD alpha 全是 0（或全是 255） | raw 模式 UV 是 u16 半精度位，被当成整数用，所有顶点采到角落 | `np.asarray(uv, '<u2').view(np.float16)` |
| 游戏「突然退出」 | 主菜单长按方向键连跳到「退出游戏」并被确认 | 鼠标悬停选择；按键按下/松开分开发 |
| 换 Fluffy 包后游戏目录里仍有旧文件 | 手工部署过，或没在 Fluffy 里先停用 | 按 `installed.ini` 与清单比对，停用 → 替换 → Refresh → 启用 |

## 已被证伪的捷径

- 只把 chain2 表头 `wilds_unkn0` 与 Default 标志改成原生值就能让碰撞生效。
- 以展柜截图判断碰撞是否生效（以探针读到的节点与碰撞体坐标为准）。
- 用整张贴图的 alpha 统计判断材质是否金属（不用的区域会误导）。

## 反复出现的元错误

- **在 Bash heredoc 里写含反斜杠的 Python 字符串**：`'\\'` 被吞成 `'\'`，曾导致语法错误，还把一个真正的 NUL 字符写进源码。
  路径改用 `as_posix()`，或把脚本写成文件再运行。
- **共用桌面**：另一个会话在同一台机器上测别的游戏时，两边的键鼠会互相干扰。先约好屏幕，用完明确交还。
- 把离线结论（闸门、预览）或 agent 自己的展柜截图写成用户验收。
