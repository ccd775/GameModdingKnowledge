# 表情

Karin 的下颌、上眼睑、眼球用「绑定偏移杠杆」蒙到亚诺的头部骨架 `CN_U_Arno_Head_Rig`（Heads 列 14，保留）上，游戏驱动亚诺的骨，Karin 的网格跟着动。
方法和脚本来自奥德赛项目（`games/assassins-creed-odyssey/FACE.md`）；大革命只换了骨映射。**用户没有单独评价过表情**：v4 起每个版本都带着它，
证据级只到 `runtime-load-pass`。

## 1. 从原版权重认出头部骨架

头部骨架的骨大多没有名字（工具列表里只有数字 ID）。`head_bones.py <glb> <网格名> [--min 0.3]` 列出亚诺头部 LOD0 每根骨的父骨、受影响的顶点数、
骨的世界位置和这些顶点的重心 / 范围，按高度排。读出来的（`build-sensitive`）：

- `Fx_Jaw` = 脸的根；`Fx_LowerJaw`（枢轴约 (0, −0.001, 1.675)）带着下巴和下唇的骨；
- 两只眼的中心约 (±0.035, −0.072, 1.725)，各挂 5 根眼睑骨（左：`833439594`、`1569786522`、`2303269748`、`264934646`、`2752950822`）；
  中间那根上眼睑骨左 `2303269748`、右 `1933977111`；
- `Fx_Eye_Left` / `Fx_Eye_Right` 转动单独的眼球网格（Arno_Head / Heads 列 16，这个网格被去掉，Karin 的眼睛在她自己的网格里）。

## 2. 骨映射与参数

`face_rig.py` 的 `GAME_BONES`（影的面部骨名 → 大革命）：

| 影 | 大革命 |
| --- | --- |
| `FB_Jaw_M` | `Fx_LowerJaw` |
| `FB_EyelidTop_L_02` / `_R_02` | `2303269748` / `1933977111` |
| `FB_Eyeball_L` / `_R` | `Fx_Eye_Left` / `Fx_Eye_Right` |

v7 用默认参数，报告（`face_f1.json`，`case-derived`）：

- 下颌：形态键 `kuchi_A` 拟合到 24.5°，`explained` 0.58，376 个顶点；
- 眼球：k 0.5，枢轴在虹膜后 6.5 cm，每只眼 411 个顶点；
- 眨眼：40°，杠杆 0.28 m，`explained` 0.98，每侧 252 个顶点。

纯数字的骨名按原始 ID 导入（[技术合同](TECHNICAL_CONTRACTS.md) §7）。

## 3. 未经评价、待确认

- 眨眼是否闭满、常态是否半闭、嘴的幅度：都没有用户反馈，也没有录像测量。奥德赛的教训是每根眼睑骨同时被眯眼、睁大、视线跟随等十几个姿势带动，
  只靠蒙皮时常态稳定和完整眨眼只能取舍（`games/assassins-creed-odyssey/FACE.md`）；大革命是不是这样没有测过（`hypothesis`）。
- 对话 / 过场的口型、头部特写都没有看过。要调时先请用户录 10–20 秒的脸部特写，逐帧量眼睑。
