# 排障手册

除标注外均为本项目实测（5.0.1048522）。

## 1. 加载与打包

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| mod 装了没有任何效果 | mod 文件夹里只有 `blob0.bundle`，没有 `metadata.store` | `w3metadata_write.py <mod>\content` |
| 同上，store 也在 | 路径多套了一层（`mods\modX\mods\...`）；`EnabledLocal` 被关；别的 mod 覆盖同一批模板 | 查 `<游戏>\mods\<名>\content\` 下两个文件；`dx12user.settings`；一次只装一个改杰洛特外观的 mod |
| 部署时复制失败 / 文件被占用 | 游戏刚退出，bundle 句柄还没释放 | 进程消失后再等约 2 秒（`pipeline.ps1 -Deploy` 这样做） |
| WolvenKit CLI 起不来（.NET 版本） | `.exe.config` 要 4.8.1，机器只有 4.8 | 把 sku 改成 4.8（`prepare.ps1`） |
| bundle 清单里找不到某个模板 | 清单是旧的（游戏更新后） | 重跑 `prepare.ps1` |

## 2. 隐形与外观

| 症状 | 原因 | 处理 |
| --- | --- | --- |
| Karin 完全不显示（dangle 物品里的网格隐形），其它正常 | dyng 的骨名是 WolvenKit 写的 `StringAnsi`（或经 WolvenKit 往返丢了 `name`） | `fix_cr2w_skeleton_names.py`；原版 dyng 往返一次就能复现 |
| 自己拼的物品模板整个隐形 | 丢了 / 改名了组件、改了块的布局 | 在原版模板 JSON 上做最小修改 |
| 杰洛特的身体还在 | 有遗漏的模板路径（例如 DLC 目录下的） | 用全量 bundle 清单铺满 `geralt_items`（含 `dlc\*\data\items\...`） |
| 物品全换掉后颈部还剩杰洛特的过渡网格 | 它是玩家实体自己的组件，不是物品 | 用同路径的 0.1 mm 存根覆盖 |
| 脖子太长 | 颈部拉到 `man_base` 全长（约 ×2.0） | 只沿轴 ×1.5 |
| 上身显胖 / 肩很宽 | 全身同一个 1.675 缩放；少女挂在杰洛特 ±0.208 m 的肩关节上 | 胸、腰单独缩放；上臂挂在肩关节内 5 cm 的支点上 |
| 待机时上臂根部有一道缺口 | 肩部偏移按假设的下垂角转回绑定姿势；`shoulderRoll` 在待机里几乎不转 | 在杰洛特的待机姿势里拟合，再经最终权重解回绑定姿势 |
| 跑步摆臂时上臂根部凹陷 | 上臂根部权重去掉了 `shoulderRoll` | 保留 `shoulderRoll` |
| 动漫脸 / 白色衣服发亮 | 纯白漫反射在 W3 角色光照下过亮 | 漫反射 ×0.82 |
| 物品栏里脸上的阴影很硬 | 物品栏界面的灯光 | 已知，未处理 |

## 3. 物理

| 症状 | 原因 | 处理 |
| --- | --- | --- |
| 双马尾和裙子一直偏向一侧 | 原版发型约束 wind 3.0（0.4 也一样） | wind 0 |
| 头发 / 尾巴总是垂着，原模型保持形状 | 约束有重力；源模型的 spring 没有 | gravity 0 + 刚度 2 |
| 甩动幅度小 | 节点 `distance` 上限太小 | 加大上限（会牺牲保形，§5 的权衡） |
| 链停下来外翻（刚度 10 也不回去） | look-at 把子节点的刚度目标转走，父节点是模拟节点 | 模拟节点直接挂动画锚点 |
| 链停下来扭曲 / S 形 / 打结 | 父节点是模拟节点；或滚转不对；或上限内没有恢复力 | 挂锚点；look-at 按滚转规则建、非 look-at 平行移动；小上限 + 刚性形状链接 |
| 静止时发卷朝外翻、侧发从脑后支出 | look-at 节点的绑定滚转差约 175° | 按「X 对准目标、Z 保持父节点 Z」建朝向（`rule_check.py` 目标 0°） |
| 尾巴是捏扁的 S 形 | 非 look-at 的链在中段换了参考轴，两根骨翻转 180° | 平行移动建坐标系 |
| 双马尾急停后一直外翻 | 梢部上限 0.42 m（可能挂在上臂碰撞上） | 0.18 m |
| 停下后整条抬着几秒才回去 | 上限偏大（尾巴 0.04 + 0.05/节停在抬高约 20°） | 0.035 + 0.04/节 |
| 一条链停在外翻、另一条回去了 | 质量大（×3） | 质量回到 1.0 → 0.6 |
| 加 dampening 后停在奇怪的形状 | 0.985 摆得更多，停下时更随机 | 不设 |
| 跑步时刘海 / 侧发穿进脸 | 头发离脸 0.5–3 cm，上限 2–10 cm，头上没有碰撞体 | 头部碰撞代理 `head_c`，最小距离 = 静止距离的 98 % |
| 头发和背后 / 剑鞘穿插 | 背部代理只挡双马尾；剑鞘不参与碰撞 | 已知（剑鞘挂点沿用杰洛特的背部） |
| 歪头的待机动作里双马尾甩到接近水平 | 双马尾跟着头保持形状 | 已知；可以试着锚在 `torso3` |
| 耳尖静止时塌下 | 耳的中段也是模拟节点 | 根和中段钉住，只放开梢 |
| 抬腿时大腿从裙子节点之间穿出 | 碰撞只作用在节点上 | 髋关节以下的裙子部分蒙到大腿上 |
| 整条裙子塌到臀部、露出皮肤 | 裙子上部也在模拟 | 腰圈和第一段钉住 |
| 裙腰扭了 | 分叉的根节点 look-at 着其中一个子节点 | look-at 只用在单子节点链上 |
| 走路时髋侧 / 大腿外侧穿出裙子 | 髋高一圈往里漂，上面钉住的段 look-at 着它转进臀部 | `snug_depth`：这一圈保持静止距离的 98 % |

## 4. 表情

| 症状 | 原因 | 处理 |
| --- | --- | --- |
| 自由活动时看不到眨眼 / 表情 | 玩家的游戏内表情很少运行 | 用开场过场测 |
| 对话时嘴张得小 | W3 口型只用部分权重驱动下巴 | `POSE_GAIN`：下巴 ×1.3、唇 ×1.2 |
| 新写的 w3fac 要不要修骨名 | WolvenKit 写 w3fac 的两个骨架时同样用 `StringAnsi` | 本项目每次都过 `fix_cr2w_skeleton_names.py`（骨和轨道）；不修时的表现没有单独测过 |
| 瞳孔放大几乎没变化 | 纯平移表示不了缩放 | 已知 |

## 5. 测试与工具

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 自动化测试中菜单按键错位，进了世界地图 | 残留的按键脚本进程还按着键 | 测试前结束残留进程；冲刺脚本后一定跟松键 |
| 主菜单「继续」读到了序章 | 新游戏测试留下的检查点存档成了最新存档 | 从「读取游戏」列表按位置选档；先看存档目录 |
| 正面 / 背面截图里形状看起来对，用户说不对 | 尾巴、双马尾的扭曲和折叠只在侧面看得出来；凭记忆判断「模型原来就是这样」 | 加侧面和用户视角，和 `idle_view.py` 的目标形状并排比 |
| 离线裙子检查在待机就报穿 | 用了最近面的有符号距离（百褶的法线交替） | 沿皮肤法线射线检查，过滤 12 cm 以上的命中 |
| 离线裙子检查复现不出用户看到的穿模 | 没有模拟 look-at 把漂移传给钉住的段 | 把 `_002`、`_001` 按 look-at 转向漂移后的节点 |
| 离线渲染里裙子脱离身体 | 姿势脚本没传递非网格骨（`Skirt_root`）的锚点变换 | 沿 dyng 父链传递锚点的变换 |
| 重建的 bundle 哈希和发行版不同 | 身体 w2mesh 的顶点顺序每次不同；xbm 写着源 PNG 的绝对路径 | 按内容比较（`cmp_w2mesh.py`；xbm 归一化路径后只差头部字段） |
