# 案例：Karin_Original 替换魂（2026-10-29 → 10-31）

源模型 Karin_Original（VRM），比例 1.30（约 175 cm，骨盆高 83 cm），少年魂 1.32。用户授权：可下载 UE 编辑器和相关工具、启动游戏测试；
要求带物理和表情。每一轮由用户在自己机器上实机反馈。

| 轮次 | 改动 | 用户反馈 / 结论 |
| --- | --- | --- |
| r1 | 身体 32k 顶点、三个槽；面部 43 个 CTRL 形变；链骨 + RigidBody 覆盖物理资产；隐藏原版部件 | 链骨方案拉长侧发、双马尾、裙摆 → 改 Chaos 布料（`rejected`） |
| 布料 1 | 双马尾 / 尾巴驱动 0.4 → 0.12，耳朵 0.7 → 0.18，裙摆驱动 0.5 → 0.25 | 尾巴、双马尾摆得太少、耳朵几乎不动、走路时大腿穿裙 → 调参 |
| 布料 2 | 裙摆只固定腰带、碰撞体第 85 百分位、耳朵不碰撞 | 站立 / 跑动仍穿；刘海没物理；下半截裙子像湿的 |
| 布料 3 | 单面裙、裙子上部跟皮肤权重、刘海与侧发成布料、求解器 3 / 2、湿润参数清零 | 刘海会动但有暗斑；裙子有光泽；跑动穿模；耳朵好了 |
| 布料 4 | 刘海删内层面；backstop + CCD + 面法线；服装 ARMMatte | 暗斑没了、不再穿模；沿褶线有光泽 |
| 布料 5 | 平滑外壳做裙摆的模拟网格 | 光泽没了（`runtime-confirmed`） |
| 脸 1 | 脸在头上，眼睛跟原版眼根 → 斗鸡眼；改成眼睛跟头 | 成年脸发暗（少年正常） |
| 脸 2 | 脸并进身体网格 | 脸色正常，但平时不眨眼 |
| 脸 3 | 脸放睫毛片 + `Hun_CopyPose` 眨眼循环 | 会眨眼、脸色正常；发行包 v1（2026-10-30） |
| 脸 4 | 34 个 ARKit 别名 | 受击没有嘴部动作、平时嘴不动（原版也没有） |
| 脸 5 | 找到发暗原因（槽 0 被换成动态材质实例），脸回到头的槽 1；不再自带 `Hun_CopyPose` | 过场有脸，但平时又不眨眼 |
| 脸 6–8 | 在 `Hun_CopyPose` / `Hun_CopyPose_Head` 里按组件标签、按类名门控眨眼 | 都不眨 → 平时游玩的头不跑这两个动画蓝图 |
| 脸 9 | 两张脸：睫毛片的脸平时眨眼，头上的脸缩到 90% 只在过场由 `KarinFaceShow` 放大 | 「这次看起来都好了」；发行包 v2 |
| v3（10-31） | 另一位用户反馈：醉剑的剑消失、没有攻击判定 → 身体补回原版的 4 根 `*_child` 武器骨；安装脚本会删除 PicodraTech 包 | 读回 264 根骨；未进游戏复测 |

被证伪的假设（保留以免重走）：领导者是 `Hun_Invs`；平时游玩的头跑 `Hun_CopyPose`；模板组件上的标签会带到运行时；头的脸发暗是光照 / 模板 / 外观表覆盖 / 形变法线问题；
导入后改形变的切线能进 cook；体积缩到 5% 的脸法线可用。

发行：v2 由用户自己重新打成「`~mods` 文件夹 + 说明」的 rar 分发；v3 同时给了带安装脚本的 zip 和同样布局的 rar。
