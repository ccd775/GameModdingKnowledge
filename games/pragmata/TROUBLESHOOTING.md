# 排障手册

## 症状 → 定位表

| 症状 | 原因 | 处理 |
| --- | --- | --- |
| 替换后躯干太短，原生 `Spine_2` 落在脖子处 | 按臀高缩放 | 按肩高（上臂关节）对齐缩放 |
| refskel 路线下前臂出现扭转 | 每根骨独立求最小对准旋转 | 分层：子骨先随父骨转，再最小摆动 |
| VRM 转出的模型整体错位/缩放不对 | 对蒙皮网格应用了节点变换 | 只用 joint 世界矩阵 × inverseBindMatrix |
| 读形态键时报 `bufferView` 缺失 | morph target 是稀疏 accessor | 读取器支持 `sparse`（零底 + 补丁） |
| 重名骨导致映射错乱 | VRChat 导出重复节点名 | 保留第一个，其余加后缀 |
| 空 spring 导致链构建越界 | 优化版把整条 spring 的骨删光了 | 跳过关节全被移除的 spring |
| 膝盖附近素体从袜子里露出 | 素体在袜子下仍是原尺寸 | 烘焙作者的收肢形态键（`kisekae_*` / `*_OFF`） |
| 烘焙后袜口上方出现一道折痕 | 形态键作用范围超过袜口 | 按绑定姿态高度加遮罩，只烘焙袜口以下 |
| mdf 写出后被截断/字符串错乱 | 编辑器按陈旧 `GPUBufferOffset` seek；AlphaTest 排在 Emissive 后 | 拷来的条目偏移清零；alpha 条目排前 |
| 解析原生 mesh 失败 | 缺流式 mesh | 同时提取 `natives/stm/streaming/...` |
| mesh 头部某个计数异常（例如索引数巨大） | 按固定偏移拷了参考 mod 的头部 | 只拷 `lodGroupNameHash`（`0x0c`） |
| RSZ 里 Mesh 等类型读出来错位 | 用了 demo 版 rsz 类型库 | 换正式版 `rszpragmata.json` |
| 物理在某些形态/服装/场景里消失 | 身体 mesh 还被别的 prefab 引用 | 全量扫描所有 prefab，全部注入 |
| 注入后运行时引用错对象 | 插入实例后未平移对象表索引 | 平移 `parentId` 与 `GameObjectRefInfo` |
| 长链/布料**移动中**高频乱颤 | 插入的 Chain2 `UpdateTiming` 为 3（布料部件的值） | 用 4（原生头发的值） |
| 跑动时头发不甩、没有跟随 | `reduceSelfDistanceRate` 过高 + 速度触发的第二档回拉 | 长链约 0.25、布料约 0.45，去掉第二档 |
| 开了 `EnabledCollision` 却什么都不碰 | group `0x840B` 不含 CollisionCharacter，文件里又没有模型碰撞体 | 在 chain2 里拟合自己的模型碰撞体 |
| 站立时大腿根从裙片两侧漏出 | 碰撞关闭/没有碰撞体 | 大腿 + 骨盆胶囊，静止间隙闸门 |
| 走动时迈出去的大腿从裙片中间/侧面穿出 | 节点只按球碰撞，两节点之间的布不受挡 | 裙链中间节点 `collisionShape = 2` |
| 物理一开就抖/炸开 | 某个节点或胶囊段静止时就在碰撞体里 | 静止间隙闸门：先缩节点半径，再缩碰撞体 |
| 发行包里混进旧文件 | 输出目录未清空 | 构建前清空 |
| 分析脚本读权重越界 | 同一进程里别的模块把 mesh 解析切到了 raw 模式，权重变成 16 字节记录 | 按 raw 记录解码，或显式指定解析模式 |

## 已被证伪的捷径

- 臀高缩放 refskel 路线的角色。
- 直接复用参考 mod 的 mdf 或 mesh 头部字节。
- 复用原生角色 `.clsp` 给替换模型当碰撞。
- 用调高 `reduceSelfDistanceRate` 治「移动中乱颤」（会连带杀掉跟随）。
- 怀疑 `settingsAttrFlags` 导致乱颤（抖的链与不抖的链标志位相同）。
- 裙根摆角 30° → 40°（离线步幅估计里反而更差）。

## 反复出现的元错误

- **一版里改多个变量**，实机结果无法归因。phys3 同时改了 UpdateTiming 与 reduceSelf；v0.2 同时加了碰撞体、
  改了摆角和半径。能拆就拆；拆不了就在记录里写明「未归因」。
- **审查中改被审文件**，导致外部审查席因快照不符直接 BLOCK，整轮作废。
- 把离线估计（步幅估计、预览渲染）写成实机结论。

## 环境相关

- 本机访问 GitHub raw 很慢（有时 10–20 KB/s）：大文件用 `curl -C -` 断点续传。
