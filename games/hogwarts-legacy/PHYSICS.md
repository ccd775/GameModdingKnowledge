# 物理

## 1. 原版怎么做

- 原版头发和裙子多数是 Chaos 布料（网格里的 `ClothingAssetCommon` + `ChaosClothConfig`）。
- 骨架里的 `dress_01..04_*`（8 个方向）、`HoodDyn`、`LegDyn` 是 AnimDynamics 骨：合并服装（`*_Dynamics`）的部件数据资产带 `AnimClass`
  （`CopyPoseFromMesh`），网格的 `*_PP` 后处理蓝图里跑单骨 AnimDynamics，模拟空间 Component。
- 披风（`Back` 槽）用 `ABP_Robe_ClothJoints`：`CopyPoseFromMesh` + LookAt / Constraint 驱动布料关节。
- 没有 `AnimClass` 的部件跟主姿势走，网格上的后处理蓝图不运行（[技术合同](TECHNICAL_CONTRACTS.md) §6）。

## 2. 本项目的宿主

- 上衣和两个发型的部件数据资产注入 `AnimClass` → `ABP_Karin_<G>_Body` / `ABP_Karin_<G>_Hair`（编辑器插件生成）：
  `CopyPoseFromMesh（bUseAttachedParent、bCopyCurves）→ 局部转组件 → AnimDynamics × N → 组件转局部 → 输出`。
- 两个网格引用自带的 `SK_Karin_<G>_Skeleton`（`CopyPoseFromMesh` 要求网格骨都在骨架里）。
- 身体：裙片、尾巴、衣服丝带；头发：双马尾、侧发、刘海、兽耳、头上丝带。最终构建身体 58 个节点、头发 24 个。

## 3. AnimDynamics 语义与集中杆模型

UE 4.27 源码（`AnimPhysicsSolver`、`AnimNode_AnimDynamics`）里与调参有关的事实（`invariant`）：

- **不用链模式。** 链模式的连杆限制围绕「上一节的直线延长」，链的角弹簧目标是固定的模拟空间 X 轴：撑不住外张的裙摆和向后翘的尾巴。
  改成单骨节点、父骨在前（与 HL 自己的做法相同）：每个刚体围绕它被动画的骨框架限制和回弹，而这个框架已经带着模拟后的父骨。
  所以相对偏转会沿链逐级累加。
- 弹簧：`AngularMomentum += -k · angle · dt`。阻尼：`momentum *= (1 - d)^dt`，线动量和角动量都乘，而且在**绝对模拟空间**里，
  所以父骨转动时子骨也会滞后。`d` 在 float32 下必须 < 1（取 0.99999 上限），等于 1 时动量每步清零。
- 角色运动输入：`acc = clamp(-vel · VelScale - acc · AccScale, ±clamp)`；速度项在跑动时是恒定的拖拽。
- 扭转始终锁住。`BoxExtents` 是全尺寸。质心 = 骨位置 + R ·（−`LocalJointOffset`）。
- 限制的符号：`Swing.Y < 0` 表示刚体 X 向框架 +Z 倾，`Swing.Z > 0` 表示向 +Y 倾。
- `CustomSphere` 的 `Outer` 球形限制把刚体挡在球外，会减去刚体自己的碰撞半径。

`dyn_params.py` 的集中杆模型（每个节点代表「从这个关节到链尾的剩余发束」，长 R，质心在 `com_frac · R`，质量 1）：

| 输入（`dyn.json`，按类别） | 换算 |
| --- | --- |
| `defl`：1 g 侧向加速度下整条链的静态弯曲（度），平均分到各节点 | 总刚度 `k_tot = 980 · D / rad(defl / n)`；弹簧 `K = k_tot - k_hang`（扣掉重力自己的回复刚度 `980 · gravity · D · cosφ`） |
| `freq`：摆动频率 | 转动惯量 `I = max(k_tot / ω², R²/12 + D² + 1)`，用盒子截面实现：`b = sqrt(max(12 (I - D²) - R², 4))` |
| `zeta`：阻尼比 | `d = 1 - exp(-2 ζ ω_act)` |
| `sim_every` | 长链只模拟每第 n 根骨，中间的刚性跟随，减少逐级滞后的累加 |
| `vel` / `acc` / `gravity` | 直接写进节点 |

## 4. 限制与碰撞

- 裙片：重力 0（有重力时后片静止就压进臀部），外张上限 40°、内收上限 3°、侧向 20°；框架约定见 [角色拟合](CHARACTER_FIT.md) §5，
  外张对应 `MinY`、内收对应 `MaxY`。
- 碰撞球的半径 = min(上限, 静止时到身体的距离 − 刚体半径 − 0.3)，小于 2 cm 就不放；保证起始时不在球内、静止形状不被推开。
- **大腿球放在大腿骨段的固定位置**（t = 0.1 / 0.25 / 0.4 / 0.55，半径上限 9），随腿前后摆；最初取「离裙片静止质心最近的点」，
  那正好是髋关节，抬腿时球不动，跑步时大腿穿出裙子。
- 裙片的质心放在靠近下摆处（`com_frac` 0.85），下摆才受碰撞保护。
- 双马尾：躯干、肩、上臂、颈的胶囊式球组；和前臂、手没有碰撞（已知限制）。

## 5. 调参轮次（用户实机反馈）

| 版本 | 设置 | 反馈 / 结论 |
| --- | --- | --- |
| v9 | 第一版：弹簧约 2 Hz、阻尼比约 0.1、速度 / 加速度比例 1；裙子重力 0.4 对 12° 限制 | 「马尾和尾巴轻轻一动就大幅度快速甩动」；裙片穿进臀部和大腿 |
| v10 | 集中杆模型；按类别给 defl / freq / zeta；长链隔骨模拟；裙子重力 0 + 内外限制；静止距离封顶的碰撞球 | 「整体物理效果又太弱」；跑动时大腿仍穿出裙片（碰撞球在髋关节） |
| v11 | 大腿固定位置球、`com_frac` 0.85、侧向限制 20；加强：defl 双马尾 110 / 尾巴 90 / 裙子 60，ζ 0.3–0.4，vel / acc 0.4–0.6，逐骨模拟 | 「大腿不会穿出裙子了」；「摆动过于软了，回正极慢，可以再加一点 bouncy」 |
| **v12** | 双马尾 / 尾巴 1.2 Hz、裙子 1.7 Hz，ζ 0.45–0.48，隔骨模拟，vel 0.3 / acc 0.45（裙子 0.25 / 0.4）；头发 22° / 2.2 Hz，兽耳 8° / 2.6 Hz | 「这次的挺好的了」→ `runtime-confirmed` |

v11 → v12 的诊断：6 个 0.75 Hz 节点串联，整体表现像频率更低的系统，所以又软又慢。用 `feel_sim.py` 网格搜索后选了 v12。

## 6. 离线工具

- `feel_sim.py`：平面串联模型，模拟起跑（0.25 s 内 0 → 600 cm/s）、跑 2 s、0.2 s 内停下；输出链尖峰值角、跑动中的拖尾、停下后的峰值、
  过中心次数、回到 3° 内的时间。参考值：v10 双马尾 32° / 2.0 s（太弱），v11 64° / 3.5 s 内不收敛（太软），v12 36–43°、过中心 4 次、
  1.2–1.8 s 收敛（用户接受）。ζ < 0.3 会过中心 8–10 次；同样的 defl 下提高频率反而峰值更大（短促的推力传得更完整）。
- `swing_check.py`：把大腿摆到 55° / 70°，解裙片节点，报最大穿透：v10 5.9 cm，v11 起为 0。

## 7. 已知限制

- 骨骼动力学不是布料：裙片各自摆动，相互之间没有碰撞；坐下、踢腿这类大动作时大腿仍可能穿出。
- 拉起兜帽时双马尾可能穿模。
- 参数是 Karin 的案例值；换模型要按链长和质量重新算，并用 `feel_sim.py` 对齐手感参考值。
