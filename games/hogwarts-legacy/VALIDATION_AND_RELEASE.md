# 验证与发布

## 1. 离线闸门

构建日志与读回：

- 导出：每个网格一行 `EXPORTED <名字> all bones` / `game bones only, N removed`；只有身体、头发、`Skeleton` 是 all bones。
- UE 导入日志：Karin 骨架改名成功、头部形变数（56）、两个动画蓝图的节点数（身体 58、头发 24）、`ALL DONE`。
- cook：`Error:` 计数 0。
- HLMeshProbe `patch`：`verify ok (N meshes)`（女版 21 个网格）。
- **骨集合**：引用 `Biped_Skeleton` 的网格不能有游戏骨架之外的骨（名字表里查不到 `Ear_L`、`Tail` 等）；引用 `SK_Karin_*_Skeleton` 的可以有。
- 材质：每个槽非空，指向宿主材质实例；女版包里不应引用男版材质实例或贴图。
- 数据资产：CUE4Parse 读回 `AnimClass`、发型 `MeshOverrides`、装备外观的袜子 / 鞋引用。
- retoc：`to-zen` 后 `verify` 通过。

预览（agent 看图判断）：

- 上半身正面对比图（按脸高归一化，原模型 / 上一版 / 这一版）：比例、肩、颈。
- 形变组合渲染：左右、撕裂、凹陷。
- 物理候选：`feel_sim.py` 的峰值 / 过中心次数 / 收敛时间与已接受的 v12 比较；`swing_check.py` 的大腿穿透为 0。

## 2. 实机闸门

1. 首次前备份存档；游戏关闭时把三件套放进 `~mods`，用户原来的包先备份。
2. 存档要用替换目标的脸型 / 发型预设；测试女版用女性存档。
3. 装备界面看全身（换成黑魔法套装）→ 野外走、跑、冲刺看裙子 / 尾巴 / 双马尾 → 和 NPC 对话看眨眼和口型 → 戴帽子 / 拉起兜帽看头发。
4. **至少连续玩 10 分钟，包括任务流程**；结束后查 `Saved\Crashes` 有没有新的转储（v1.0 的崩溃发生在启动后 1–5 分钟）。
5. 收尾：关游戏，恢复用户原来的 mod 布局，删除截图。

## 3. 发行包

```text
Karin_DarkArts_Witch_v<版本>.zip
  README.md
  zzz_KarinDarkArts_F_P.pak
  zzz_KarinDarkArts_F_P.ucas
  zzz_KarinDarkArts_F_P.utoc
```

README 写：版本和适配的游戏版本、需要什么（豪华版的黑魔法包服装）、安装（三个文件放进 `Phoenix\Content\Paks\~mods`，没有就新建）、
从旧版升级（覆盖）、卸载（删三个文件，存档不受影响）、**创建角色时选哪个脸型和发型**（序号按游戏列表从 1 数；脸型之后改不了，
发型可以去霍格莫德发廊改）、换装说明（哪些槽位变成空模型、袜子 / 鞋、帽子和兜帽下的头发）、功能、已知限制、更新记录、版权与原作者。
旧的测试版包名不同（`zzz_KarinDarkArts_P`），要先删掉，不要两个版本同时放。
