# 角色拟合

`fit.py` 在 Blender 里把源模型摆到 HL 骨架上，输出各部件网格和扩展骨架。下面的数值是 Karin 的案例值（`case-derived`），
原理是 `invariant`。

## 1. 两步：重摆姿势 + TPS

1. **重摆**：用源模型自己的骨架（numpy LBS）把 T 姿势摆成 HL 参考姿势的 A 姿势方向。
2. **TPS 变形**：在源模型和 HL 骨架之间放约 390 个对应点，薄板样条把重摆后的网格整体变到 HL 关节上（控制点残差约 1e-4）。
   - 四肢、躯干、颈：沿骨段放「环」（`seg_pts`：两端关节、半径、若干个 t），环上的点按截面放大系数 `g_perp` 外扩。
   - 头、手、脚：刚性点云（`rigid`），只做相似变换，分别乘 `g_head` / `g_hand` / `g_foot`。
3. 拟合后网格的关节位置与 HL 逐骨一致（导入后读回差 0.0），所以动画不需要重定向。

## 2. 比例：用户三轮反馈换来的规则

| 反馈 | 原因 | 规则 |
| --- | --- | --- |
| 头特别小、尾巴根附近的腰被拉长 | 躯干按 Hips→Hips 对齐；Karin 的髋关节在她 Hips 骨下方约 11 cm（HL 男约 6 cm），腰被拉长 2–3 倍；头没跟着身体放大 | 躯干锚在「两髋关节中点 → 颈」；头、手、脚随身体放大（男约 1.5，女约 1.38） |
| 脖子太长；肩膀太宽，脖子像圆柱插在水平的锁骨上 | HL 的肩关节比动漫身材宽（女 1.7 倍、男 2.1 倍）且位置低 | `shoulder_in` 0.6：手臂根部往 Karin 自己的肩宽收；`head_offset` 下移约 3.5 cm；颈部的环用 `g_head` |
| 脖子到锁骨还是有点塌陷 | 颈根下移的同时肩抬高，中间塌下约 4 cm | 颈根不下移（女 `neck_offset` 0，男 −0.02）；只用 `head_offset` 缩短脖子；肩、颈权重与 `Spine3` / `Neck` 混合 |

最终参数：女 `g_perp` 1.3、`g_head` 1.38、`g_hand` 1.2、`g_foot` 1.3、`skirt_leg` 0.65、`head_offset` (0, 0, −0.035)、`shoulder_offset` 0.02、`shoulder_in` 0.6；
男 1.4 / 1.5 / 1.3 / 1.4，`head_offset` −0.03，`neck_offset` −0.02，`shoulder_offset` 0.03，`shoulder_in` 0.6。

- 手臂必须绕 HL 的肩关节转，肩线只能收一部分；手臂大幅抬起时肩部会轻微挤压（发行说明里的已知限制）。
- 体型（男 / 女）在创建角色后改不了：男存档上的 Karin 只能是男骨架的比例。
- 每轮进游戏前先渲染一张按脸高归一化的上半身正面对比图（`cmp_upper.py`：原模型 / 上一版 / 这一版），用户是按眼睛对比原形象判断的。

## 3. 权重

- 源模型骨 → HL 骨组的映射；HL 有扭转骨和 `InHand` 等细分，组内的分配取最近的原版顶点（参考网格）的比例。
- 组的例子：`Hips` → [`Hips`, `Spine`, `Spine1`]；`Neck` → [`Neck`, `Neck1`, `Spine3`]；肩 → [肩, `Spine3`, `Neck`]。
- 裙子在 `Hips` 与大腿之间混合（`skirt_leg` 0.65）；有动态骨后，裙片的权重留在自己的动态骨上。
- 每顶点最多 4 个影响，归一化。
- 头部网格只绑 `Head`（每个顶点 100%）；表情全部来自形变（[表情](FACE.md)）。

## 4. 法线

TPS 和 LBS 会改变表面方向，只重算法线会丢掉源模型作者为动漫着色调过的自定义法线（鼻子、嘴周围出现写实阴影，用户说「面部脏兮兮」）。
`fit.py` 把每个 loop 的法线按 `n' ∝ (J_tps · J_lbs)^(-T) n` 带过去：`J_tps` 用中心差分（h = 1e-3）求，`J_lbs = Σ w R_b`。
Blender 4.0 在 `normals_split_custom_set` 之前要 `use_auto_smooth = True`（4.1 起没有这个属性）。导入 UE 时用「导入法线」+ MikkTSpace 切线。

## 5. 动态骨

- 源模型里名字以 `Skirt_`、`Tail`、`Hair_tail_`、`Hair_side_`、`Hair_front`、`Ear_`、`Ribbon_` 开头的骨（不含 `_end`）保留为真实的骨，
  挂到对应的 HL 骨下（Hips → `Hips`，胸 → `Spine3`，头 → `Head`，手 → 手）；`Skirt_root`、`Hair_front_root` 和手上丝带的根只做固定点。
  Karin：95 根，35 条链（身体：裙片 16 条 × 3、尾巴 6、衣服丝带；头发：双马尾各 6、侧发 3、刘海、耳朵 2、头上丝带 2）。
- 骨的朝向：X 沿链，Y = up × X（水平切向），Z = X × Y（向外 / 向上）；up 取世界 Z，除非 X 几乎竖直（|x_z| ≥ 0.999）。
  物理的非对称限制依赖这个约定（[物理](PHYSICS.md) §4）。
- `skel_ext.json` = 游戏骨的参考姿势 + 动态骨相对游戏父骨的局部变换；HLMeshProbe 用它写回网格参考姿势。
- 动态骨只能出现在引用 `SK_Karin_*_Skeleton` 的网格里。导出时会变形到它们的网格（身体、头发）保留，其它网格去掉
  （[构建流水线](BUILD_PIPELINE.md) §5）。
