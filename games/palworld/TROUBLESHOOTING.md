# 排障手册

| 症状 | 原因 | 处理 |
| --- | --- | --- |
| 读游戏资产时属性错乱或报错 | unversioned cook，usmap 缺失或版本不对 | 换与 build 对应的 usmap（本快照 `Mappings_1.0.5`） |
| 进游戏看不到 Karin 的身体、头发 | 穿着身体护甲（替换的是默认服装）；或角色是男性 | 换初期装备，或用古典式化妆台把外观设为「初期装备」（[技术合同](TECHNICAL_CONTRACTS.md) §7） |
| 男性角色没有头发 | 发型网格不分男女，隐藏发型的包对所有角色生效 | 只玩男性时不装 `Karin_HideHair_P.pak` |
| 编辑器里链在动，游戏里不动 | Kawaii 按 USkeleton 建链，网格独有骨不被模拟 | 链改名落到游戏骨架的配件链上，父骨一致（[Kawaii 物理](KAWAII_PHYSICS.md) §1） |
| 物理「偏硬」，耳朵几乎不动 | 跑动时世界跟随的滞后把链压在角度限制上；耳朵 stiffness 0.3、限制 20° | 离线模拟看 FLARE 平均值是否贴着限制；提高 world_loc、降低 stiffness 和 damping、加递减曲线、放宽限制 |
| 跑动时大腿根从裙片之间穿出 | 大腿胶囊比肉细（8.0 对 9.4 cm）；角度限制在碰撞之后把关节拉回腿里；冲刺时前片滑进两腿之间；两条链之间的布切过抬起的大腿 | 两段大腿胶囊 9.5 / 12.0、裙关节半径 1.0、限制 65°、world_loc 0.95；先在 `kawaii_sim.py` 上复现再改 |
| 加环形 BoneConstraints 后裙子穿模更多 | XPBD 柔度在厘米尺度下近乎刚性，环不能变宽 | 不用环形约束 |
| 静止时裙子或尾巴根一圈鼓起 | 胶囊比身体大，静止关节每帧被推出 | 胶囊半径按 bind 姿势下的被模拟关节拟合（≥ 关节半径 + 0.5 cm） |
| 动作里四肢扭曲、方向不对 | 网格骨的 bind 朝向和原版不同（动画写绝对局部旋转） | 朝向逐骨等于原版，只改位置 |
| 皮肤从衣服里透出 | 源模型的「穿衣」形态键没烘进去 | 重摆前把 `kisekae_*` 烘进基础网格 |
| 从下面看裙子是空的 | 源 VRM 单面 | 复制反向面并取反角法线 |
| 网格重导入后材质槽错乱、多出旧骨 | 重导入保留旧数据 | 先删资产再导入 |
| AnimBP 脚本断言 `AddFunctionGraph` | 动画层图不能当普通函数图加 | 插件用 `AddDomainSpecificGraph` |
| cook 日志显示 0.1 分钟，怀疑没 cook | iterate cook 只重 cook 了改动的包 | 看 `Packages Cooked` 和 `Success - 0 error`，再读回 pak 核对参数 |
| 导出工具读到的还是原版资产 | 导出工具只读给定目录，不加载 `~mods` | 指向自己的 pak 目录，或用 `PALX_EXTRA` |
| Git Bash 里 `/Game/...` 参数变成 Windows 路径 | MSYS 路径转换 | `MSYS_NO_PATHCONV=1` |
| 从 SSH 启动的游戏不出现在屏幕上 | SSH 会话在 session 0 | 从桌面会话启动（`steam://rungameid/1623730`） |
| 头发偏淡紫 | 未查明：贴图本身偏粉，父 MI 色调或发色设置是否叠加未查 | 待查（`hypothesis`） |

## 已被证伪的假设

- 「r3 的裙子穿模是大腿胶囊不够大，单纯加大就行」：只是原因之一。离线模拟显示角度限制把推开的关节拉回腿里、
  冲刺时前片滑进两腿之间同样重要。r4 是胶囊、关节半径、限制、world_loc 一起改的，没有逐项归因。
- 「两腿之间加一个中心胶囊能挡住前片」：离线模拟零效果。
- 「环形约束能让裙摆像布一样不穿模」：更糟（21 → 131 个顶点）。
- 「穿护甲时要把 Karin 的头发挪到发型槽才能保留形象」：游戏自带幻化可以让身体和头部外观一直显示初期装备，不必改槽位。
